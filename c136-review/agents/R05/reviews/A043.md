# A043 复盘（squad10 拆盘局，Vb，输；复盘员 R05）

## 一句话结论

这是一局拆盘：大厅把十个号分进同图同种子的两个并行实例。录像那一盘（下称 X 盘）只有 ryan_m 和 sora_w，加两名路人组成 T3，对四支 4 人队：T3 1500 拍 10.1% 五队垫底，峰值 17.0%（4890 拍），7505 拍团灭；录像结束时（8067 拍）T1 58.4% 领先。另一盘（Y 盘，没有录像，只有日志）是两队对抗，8 个号所在的队 2100 拍时这 7 个活着的号占 24.6%，峰值 30.9%（3600 拍），359–4587 拍全部阵亡，结束时对手 99.1%。

输在四处。① 选点串台：两盘共用一台协调器和同一个 matchKey，10 个号被当成一个十人编队。X 盘两个号拿到十人扇形阵里的两个位子，sora_w 落在外墙位，1200 拍起被队友和图边围在 7,731 格，全程没打过真人；Y 盘 8 个号按 68 格间距挤成一团，2400 拍 7 个号里 6 个被自己人围住，握着 86–94% 的兵。② X 盘只有 ryan_m 一个号有前线：路人队友 L OVNI 3323 拍被吃掉（捐兵名单里只有我方号），之后 ryan_m 同时挨着三支队伍的三个号。它 3600 拍是全场最大的号，但出兵只有一个节奏——价格门关着攒兵，存兵一过 100×地 就不看价格放一轮：3400 拍邻居要价是估值的 1.14 倍不买，3815 拍 1.87 倍照买；每轮同一条指令在落地前被重复下 2–3 次。4800 拍起它每 600 拍对真人净丢 1,100–6,800 格。③ X 盘终盘：它磨了 3,000 拍的 Uzb Timur 垮掉时，2.7 万格的空壳有 1.73 万格进了 T5 的口袋；随后 350 拍存兵低于留底不出手，T1 的 yavux 三条 4.7M 把它吃掉。④ Y 盘兵流不动：被围的号 128 条捐兵日志只成 19 条——3213 拍前单笔要的配额是上限的 1.3–3.2 倍，3213 拍后主要受赠方 209 点额度里的 167 点已被旧价的一笔用掉。

名词：密度 = 存兵 ÷ 地；软上限 = 100×地，硬上限 = 150×地；被围 = 邻格里没有敌人、机器人和中立地；留底 = 出兵后必须留在手里的兵；价格门 = 目标每格的报价 ≥ 估值就不买（估值 = 0.90×max(自己密度, 0.85×其他真人密度中位)）；放行 = 存兵 > 100×地 时不看价格；配额 = 每个受赠方累计能收的捐兵点数，只增不减；SRC / SPAWN / SIM = 策略、选点协调器、引擎源码。
