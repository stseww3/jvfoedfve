# H03 挨着白给的内置 AI 不出手：留底里的 AI 仇恨项取了编队友的余额，互锁

- 现象的证据等级：**E2**（规则照抄到 16793 个样本上；逐局符号检验 74/87，p=1.6e-11，过门槛）
- 「值多少地」的证据等级：**E2 偏弱**——原始相关是 0，扣掉卡顿之后才显出来（偏相关 -0.41，p=0.0002，过门槛）；只看不卡的局方向一致但局数少（-0.35，p=0.14）。要 E4 定量
- 对应模式：NEW-EC-05（贴着白给的人机不出手：sb 互锁）

## 一句话

1500 拍前买内置 AI 的地，规则要先留一笔「别让 AI 把我当成最弱的邻居」的底（sb）。这笔底取的是「那个 AI 别的邻居里最弱的那个的余额」。
编队的号出生在一起、共用同一批 AI、余额又差不多，于是 A 的底是 B 的余额、B 的底是 A 的余额，两个号都出不了手，AI 被旁边的野人吃走。

## 可证伪的陈述

1. own 挨着「白给」的内置 AI（按策略自己的公式，打垮它只要余额的 10% 以内）的样本里，四成被 sb 这一项单独挡住。
2. 挡住的样本里，sb 取的那笔余额四分之三是本编队另一个号的。
3. 同样的处境套同一把尺子，野人被「挡住」的比例只有 own 的一半，而且他们照样出手。
4. 不卡的局里，被留底挡住的占比越高，出手率越低。

## 机制（c110 行号；别的档对应行见 `out/_cross/codemap.txt`）

1500 拍前（`coreFrom = dpEnd = 1500`）买非真人邻居走的是这条路：`Policy.act` L4781 起 → `V17.act` → `V13.act` → `General.act` L804-846 → `Style.pickTarget` L1180-1214。
对每个挨着的 AI q：

1. 槽位：还没在打 q、且在打的非无主地目标数到了 `maxTargets = 4` 或没有空槽 → 跳过（L1192）。
2. `allow`（`V13.allow` L2147-2156）：`botPx(q) = 2 + 1.78·兵_q ÷ 地_q` 不超过 `winWorth = winR·t·兵_我 ÷ 地_我`（`winR = 0.002`），且 `price(q) ≤ botMax = 60`；或者自己的兵密度 ≥125。
3. 留底（`V13.floorFor0` L2270-2276 → `Policy.winFloor` L4542-4550）：`avail = 余额 − max(地价项, dpKeep, sb)`。
   - 地价项 = `botPx(q)·地_我 ÷ (winR·t)`；
   - `dpKeep`（L2491-2496）= (最强的邻居真人的余额 + 它压在我身上的兵 − 1.5·地_我) ÷ 1.78；
   - `sb` = `safeFinite`（`V13.safeFinite` L2532-2542）：对我挨着的每个非真人邻居 q（有空槽、没在打我、不挨着它没在吃的无主地），
     取 `threatOf(q).minOther`（`Strategy.threatOf` L464-491）= q 的**别的邻居**里 `余额 + 压在 q 身上的兵` 最小的那个；再在这些 q 里取最大，减掉我压在 q 身上的兵。
     `threatOf` 数「别的邻居」时不分敌我：编队友、同队真人、野人、空壳、别的 AI 都算。
4. 门槛（L1197）：`avail ≤ minShare·余额` 就跳过，`minShare = minSend = 0.2141`。也就是余额要高过 sb 的 1 ÷ (1 − 0.2141) ≈ 1.27 倍才放行。

五个策略文件里 `threatOf`、`safeFinite`、`winFloor`、`dpKeep`、`minShare`、`allow` 的正文逐字相同（`codemap.txt` [CM-C]），参数也相同
（`dump_params.mjs`：`winR`、`minSend`、`botMax`、`maxTargets`、`feeK`、`idleCap` 各档一致）。两档只差两处：
c110 的邻居表不含受保护的编队友（`analyze` L440，影响 `dpKeep`，不影响 sb）；c110 的 `pickTarget` 多一行 L1200（已经在打的 AI 跳过，见 H04）。

互锁怎么来：两个编队号 A、B 挨着同一个 AI q，余额相近。A 算 sb 时 q 最弱的别的邻居是 B，sb_A ≈ 余额_B；B 那边 sb_B ≈ 余额_A。
谁的余额都不到对方的 1.27 倍，两边同时被挡。野人没有这条规则，旁边路过就把 q 吃了。

- sb 单项：偏相关 × R1500 是 -0.33（p=0.0034），× AISHARE 是 -0.43（p=0.0001，过门槛）；不卡的局里 -0.38 / -0.36。

- 两层交叉（77 局，GATE 以中位 0.48 分、B 以中位 0.20 分）：门槛轻 × 卡得轻 12 局，R1500 中位 0.61、AISHARE 0.58；门槛轻 × 卡得重 27 局，0.46 / 0.36；
  门槛重 × 卡得轻 27 局，0.62 / 0.60；门槛重 × 卡得重 11 局，0.41 / 0.27。按局看，分出结果高低的是卡顿那一层；门槛这一层的作用要到扣掉卡顿之后才看得见。
- GATE 和扎堆（CLUSTER = own 的号里最近的真人是机器号的比例）正相关 0.30，sb 单项 0.38：出生越扎堆，互锁越多。

## 反证和混杂

- 被 sb 挡住的样本里仍有 41% 在 90 拍内出了手（不卡的局 53%）。这把锁是一阵一阵的：邻居的余额一动、或者自己攒过了 1.27 倍，就开了。它拖慢出手，不是封死。
- 不卡的局里也有门槛很重、结果不差的：A038（GATE 0.61，R1500 0.85）、A014（0.63，0.86）、A075（0.69，0.80，赢）。
- 野人套同一把尺子也有 22% 的样本「该被挡住」，说明「AI 最弱的别的邻居比我富」这个处境本身常见；own 多出来的那一截（40% 对 22%）主要来自编队友（76%）。
- 类别是互斥的、按最大的那一项归；被 sb 挡住的样本里有一部分同时也被别的项挡着（6742 个里只差 sb 一项的 6022 个）。
- `rule_eval` 不重算打分、不重算 `expandNeutral` 和打真人的分支；「放行」只说明规则这一拍会对某个 AI 发兵。
