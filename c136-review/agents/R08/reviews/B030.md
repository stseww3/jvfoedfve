# B030 复盘（squad20 / 自由混战 / 胜 / 113679 拍，录像到 t=37561）

复盘人 R08。数据来自 `bundles/B030/`（自带录像到服务器拍 37561，占全场 33%）和 `src/`。在真引擎里重演，214 条快照（地、兵）全部逐兵一致；t>37561 只有赢家自己的日志。对局包混了三个房间，另外两个房间的 10 个号没有任何局内数据，本文只写录像所在的房间 0。

**读数口径**：「执行拍」是录像里的服务器拍，「决策拍」是号自己的拍。「影子」= 在全场真值的每一拍上跑干净策略源码、只记不发。「逐报价重走」= 影子照抄 `Policy.buyLand` 的每一关，对每个邻居给出被哪一关挡住。「吃光所需」= 策略自己的估算（1.78×对方兵 + 1.5×对方格）。「minCmd」= 余额的 4.69%。兵/格 = 真值交战账里的耗兵 ÷ 拿到的格数。日志标签中途换名（玩家号 4 用过 77 个名字），本文一律用录像头里的名字。

## 结论

1. **赢了，但赢面在 t=2730 就定了，却打到 t=113679（6386 秒）。** 自由混战房间里只有我们的号在打：5 个编队账号进场，2 个 t=168 就离开，3 个在线号 t=2730 合占 74.99%，25 个内置 AI 合计 4.6 万兵。之后两个号被编队友打死（第 22、23 名），Landsknecht 独自又用了 10.8 万拍（101 分钟）才收官。
2. **吃到 75% 以后三个号同时停手。** t=2700 到 t=9709 编队从内置 AI 手里一格没拿。最富的 Landsknecht 被最小指令门槛挡：人机报价小于自己余额的 4.69% 就跳过，余额越多、人机越小越过不了；另外两个被防人机留底 sb 挡（sb = 共用人机邻居的编队友的余额）。t=3300 以后连「把所有人机邻居一次吃光」的总花费都不到门槛（88/88 个点）。
3. **超过软上限后，过得了门槛的只有编队友。** t=4000 Landsknecht 跳过 10 个人机报价（每格 14.9~68.7 兵，吃光合计 13.3 万兵），把 365.5 万兵按每格 499 兵打向 Luxembourg；房间里没有野人，编队保护从第 0 拍起就不生效。1636 拍里 16 条互打的陆攻烧掉 4167 万兵换 12.3 万格，同期人机从编队手里拿走 4.1 万格。
4. **Luxembourg 被锁 2583 拍。** 对真人的留底同样取 sb，而且不封顶：它的留底 = Landsknecht 的余额，高过自己全部余额。t=2422~5005 一条指令没发，t=4000 的 1298 万兵 / 9.1 万格被打到 t=4995 的 420 万兵 / 3.4 万格。只有目标「正在流血」时留底才封顶放行——Nader Shah 跟打、Luxembourg 临死反打走的都是这条分支。
5. **独号以后顶着 150 倍硬上限和人机拉锯。** 录像期 Landsknecht 有 27370 / 36080 拍密度 ≥149。人机新开进攻的第一圈白拿（引擎规则），号每丢一格掉 231~239 兵：整个录像期编队被人机拿走 49.9 万格，人机花 3069 万兵，编队余额被打掉 1.057 亿。号只在人机长到比自己还大时才打回去，全场 5 次，每次一条指令。
6. **t=9840 的收官窗口没有收。** 全场只剩 3 个内置 AI，合计 13.2 万格、0 兵，吃光要 19.7 万兵；Landsknecht 有 2197 万兵，全部跳过。刚打坍的 AI101 因为有一条船在海上没被除名（引擎规则），t=10039 带着 1 格地回来，也没人打。到 t=21500 号又只剩 35.5%。
7. **日志尾段：第一次打到 100% 之后又拖了 6 万拍。** t=53010 只差 74 格，随后 405 拍没有搜过一次水路，t=53370 冒出一个敌邻；之后 59670 拍一条指令没发，领土掉到 41.2%，t=112680 才打回去，t=113679 获胜。
8. **做对的**：人机期 262387 格每格只花 3.1~3.7 兵；执行层干净（时延中位 9~17 拍，影子的单条指令 308/327 配上，isNoFullSend 从未置位）；打人机的两手都一击见效（每格 6.0 / 7.5 兵）。

## 三、转折窗口

**① t=2730~4010：吃到 75% 后停手，囤兵 565 万 → 3795 万（74.99% → 65.91%）。**
- 最小指令门槛（`buyLand` L5363-5368）：对非真人邻居 `want = 1.25×吃光所需 + 3×接壤格数`，`x = min(avail, want)`，`x < minCmd` 就跳过（L5367）。minCmd 随自己的余额涨（L521-523），人机却是越小越便宜。Landsknecht t=3000：11 个人机报价（66160 格 / 22982 兵，吃光合计 139239）全部小于 minCmd 197488；t=3600：10 个（78955 格 / 0 兵，吃光 117996）对 604896。
- 留底 sb（`safeAt` L4524-4541 → `safeFinite` L2532-2541 → `threatOf` L464-490）：取人机邻居眼里「除我以外最弱的邻居」的余额。三个号共用人机邻居，较穷的两个 sb = 较富者的余额，可用兵 ≤0；非真人目标到密度 88 才封顶（L5323-5326），封顶以后又撞上 minCmd。t=2100~3000 的 231 个 sb 点全部由编队友的余额定出。
- 不还手：`counterAttack`（L871-887）跳过内置 AI，counterK=0 时本身也不发。引擎里守方没有兵压在人机身上时，人机新开进攻的第一圈必赢，不够的兵记欠账（game.js `expandAttack` L1016-1020）。t=2790~4010 人机拿走 36038 格只花 177080 兵，编队余额被打掉 4329046。

## 七、赢家与同房对比

- 赢家是本编队的 Landsknecht。t=4000 它是三个号里最富的（1806 万兵对 1298 万、691 万）：留底 sb 取的是别人的余额，所以只有它不被锁、第一个出手。
- 人机吃不死一个顶着硬上限的号：号越小 minCmd 越低（上限处 = 7.03×自己的领土），人机越大 want 越高；丢到 29%~43% 时门槛翻过来，一条指令打回 62%~98%。全场 5 次（t=9709、21511、39510、52290、112680）。收官靠的是最后一个人机被一次打坍、且没有船在海上。
- 没有同房的另一支编队，也没有在线的野人。和人机比：录像期编队从人机手里拿 521705 格只花 2710704 兵（5.2 兵/格）；人机从编队手里拿 499182 格花 30691948 兵，编队余额却被打掉 105722158。
