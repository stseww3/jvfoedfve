## 读这些数要带上的三条

1. **对手是开环的。** 其余真人只照录像出手。630→3213 两个窗口里，他们的陆攻在 C0 / C1 臂下有 11%–13% 改打或作废（C2 臂 7%）。我方变强以后对手怎么应对，这里没有，C0 / C1 的好处偏乐观。
2. **实录阶梯在落后最深的地方有空档。** 阶梯只收唯一定位的配对。日志流水号给了一条独立的下界（6,335 条配对违反 0 条）：有下界的 354 个日志点里，阶梯够得着 264 个。这意味着落后波那一段可能偏小、残差偏大；正在用「加上定位不唯一的配对 + 日志下界」的上、下界口径重跑受影响的窗口。
3. **「规则」这一段不是「规则亏了多少」。** 它只是历史规则在即时通道下从断面走到窗口末的变化。历史版本之间的差（Va / Vb / Vc 在同一断面互换）还在跑。
