## 读法

- **证据等级**按 `PLAN.md`：E1 = 单局个例；这里的「11 局普查」是 11 个 E1 并排，仍不是 E2。标了「E2（日志替身）」的是把日志里数得出来的替身量放到 123 局发现集上机械数过，并在 11 局上对过替身与重放精确值的秩相关。验证集没有碰，E3 留给裁判。
- **两种数**：兵、地、成交指令是真值重演的精确值；「冻结」「被围」「报价高于 worth」这类决策拍分类来自影子重跑，依赖离线模拟器的保真度（H03、H09 两张卡受影响最大），验收标准见 `reports/COUNCIL-PROPOSAL.md` 的 G0 一节。
- **卡与卡的关系**：H01 是 t=0 的量；H02 是 630→1500 拍的合计账，H03、H04、H05 是它下面的三条来路；H06、H07、H08 是 1500 拍起调度这一层的三张卡（没成交 / 成交了没打 / 成交了利息不增）；H09 是出手这一层；H10 是 4284 拍断面；H11、H12 是两张反证卡；H13 是房型个例。
- **每张卡的「还缺什么」**都指向同一类离线工作：在 0 / 630 / 1500 / 4284 拍断面上做反事实重放，把记账变成归因。它们回答的是历史对局里某条机制占了多少，不是做法。
