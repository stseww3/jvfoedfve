# H01　一个决策拍只落地一条指令：买地被无主地扩张挤掉

> R04 假设卡｜来源：13 局复盘 + 全量对局包｜只写事实、机制和怎么证伪。

**陈述（可证伪）。** 线上同一个号在同一个决策拍里发出的第 2 条指令不会落地。策略在一个决策拍里先调无主地扩张、再调买地，所以只要身边还有无主地，被挤掉的总是买地（打真人 / 内置 AI）的那一条。

**模式。**

- `NEW-IO-ONECMD`（同一个决策拍出两条指令，后一条不被受理（无主地扩张挤掉买地））：11 局出现、11 局判错 —— A013 E、A015 E、A022 E、A029 E、A038 E、A047 E、A078 E、A081 E、A083 E、A099 E、B034 E。

**机制。** 两句调用之间没有「本拍已经发过」的守卫；适配层每个决策拍只受理一条。

代码位置（`NEW-IO-ONECMD`）：Policy.act L4941（expandNeutral）→ L4942（buyLand），两句之间没有「本拍已发过」的守卫（L4962~4963 的调度和闲置发船有 this.cmds === cmdsBefore）；L4817 的注释写明线上一拍只能发一条；1500 拍前走 L4850 super.act；Strategy.send L479~487（g.attack 不受理时返回 false，本拍不再重发）

**13 局的证据。** 影子策略同一个决策拍想发两条的 399 个号·拍里，第 2 条落地 0 次：确定没落地 173 次，分不清（两条参数相同）226 次。1500 拍以后确定没落地的 109 条，想出的兵 516.6 万。

- **A022 D16**（365~600、1675~1680 拍；ryan_m、alex_k、sora_w、noah88、zexos1、leo_tx；判错）：同一个决策拍先发无主地扩张、再发另一条陆攻的有 8 个号·拍，第 2 条一次也没被受理：录像里确认没落地 7 次，另 1 次同参数的意图 2 条落地 0 条；真实日志的发令计数比影子少的 8 段里 7 段正好对应这 8 条。开局 6 次是打内置 AI 的小单（340~2,212 兵，合计 4,706 兵）。leo_tx 1675、1680 两拍：pct 47 的无主地扩张（各 1.3 万兵）先发，对真人 Yor（密度 19，不到 leo_tx 的两成）的两条（各 12.8 万兵，余额的 45%）没发出去。
- **A013 D09**（1600 拍；kaito9；判错）：同一个决策拍下了两条：先是 1.3 万兵的无主地扩张，后是对 QAZAQSTAN 的 14.5 万兵（当时对方 17,523 格 / 8.3 万兵）。后一条没落地。全场同拍出两条的 80 个号·拍，第 2 条落地 0 条；1500~2999 拍 9 条，想出 17.6 万兵。

**全量上的机械计数。** 数不了。这个模式要知道「策略这一拍想发什么」，只有影子策略在真引擎状态上重跑才有；录像里只有落地的指令。

**什么结果算证伪。** 任何一局里找到「同一个号同一个决策拍的两条不同参数的指令都进了录像」。13 局 399 个号·拍里没有一例。

**混杂与边界。**

- 226 个分不清的号·拍是两条参数完全相同、录像里落了一条，分不出落的是哪一条；不影响「第 2 条落地 0 次」，但被挤掉的兵量（516.6 万）只按确定的那部分算，是下界。
- 「想发两条」来自影子策略；真机日志的发令计数增量和它对得上的程度各局不同（各局复盘的自检里有）。
- 被挤掉的那一条如果落地会怎样，没有重放。

**要量的（模拟器 / 反事实断面）。** 模拟器的指令通道如果每个决策拍只受理第一条，13 局里被挤掉的买地指令数应当回到 399 / 173 / 109 这个量级；受理两条的通道跑同一批录像断面，可以直接量出这 109 条落地与不落地的领土差。
