# 新工具：影子策略（逐拍复现我方每个号「想发什么、为什么」）+ A022 的第一批结论

## 结论

1. 我做了一个「影子策略」：把真引擎重放出来的每一拍状态原样喂给部署版的 `Policy`，让它照常决策，但指令只记不发。它能逐拍复现线上那一局里每个号的决策，并打印走到了哪个分支、卡在哪条底线。
2. 保真度（三个版本各验一局，全局）：

| 局 | 版本 | nb/neut 快照一致 | 调度（拍号+对象+比例）一致 | 发令数增量一致 |
| :-- | :-- | :-- | :-- | :-- |
| A022 | Vb | 757/757 | 545/545 | 739/747（另 7 段差 1） |
| A038 | Vb | 730/730 | 88/89 | 710/721 |
| A029 | Vb | 731/731 | 395/395 | 710/721（其余差 1） |
| A013 | Va | 361/361 | 19/19 | — |
| A099 | Vc | 553/553 | 92/92 | — |

3. 用它在 A022 上确认了五件事（都有拍号和代码行，详见 `agents/R04/reviews/A022.md`）：
   - **队友互锁的底线**：核心期前打内置 AI 要过 `winFloor`，其中 `safeFinite`（L2500~2510）取「这个 AI 的其他邻居里最弱者的余额」，不排除队友、也不看 AI 自己有没有兵。圆盘出生下那个「最弱邻居」就是队友。实例：1260 拍 ryan_m（11.1 万兵）和 noah88（13.1 万兵）夹着一个 573 格、**0 兵** 的 AI，互为底线，都不动。全局这样的空转 3910 号·拍。
   - **指令落地率**：影子想发的陆攻 942 条，进录像的 465 条。630~1499 拍落地率 38%、中位晚 361 拍；3000 拍以后 100%、晚 12 拍。
   - **客户端落后有独立旁证**：`in_game.log` 的行序号显示 630~1700 拍有 8 个号比最快的两个队友落后 180~540 拍；两个离场号正是落后最多的。A038 同版本全队不落后、落地率 97%。
   - **`isNoFullSend` 误锁**：10 个号全部上锁（372~1225 拍）。团队局引擎没有那个 25% 限额（只在 `aE.lC==10` 的模式里有；A022 是 lC=2）。它的效果是节流：全局拦掉 32 次出兵，zero_7 占 18 次、265 万兵。
   - **配额**：3000~4283 拍陆攻 29/29 落地，调度 14/250 落地，所以这一段没落地的调度是被配额拒的。收款人的配额每次落地后都是满的；4284 拍前总共只到账 191 万，4284 拍后 102/102 落地、到账 1330 万。

## 怎么做到的

- 引擎侧用上次的无界面重放（`engine_host.cjs`）。每拍把玩家数组、进攻槽、船、配额抄进仓库模拟器的 `Game` 对象；地块归属每 5 拍抄一次并按模拟器同样的规则重建边界/海岸。
- 策略侧直接 `import` 部署文件（只改两行 import 路径），`g.attack / donate / boatTo` 换成「记一笔、返回是否合理」。
- 为什么能对上：联机是锁步的，落后的客户端决策时看到的仍是它自己那一拍的真实状态，只是指令晚到。所以「想发的」可以精确复现，「落地的」看录像，两者之差就是执行层的损失。
- 一个坑：调度的相位用 `window.__tsbSquadSlot`，要从日志的 `[HL-SPAWN…] me= slot=` 里取，不设的话调度拍号全错。

## 用法（都在 `c136-review/agents/R04/scripts/`，只读对局包和仓库源码）

```
bash scripts/engine_truth_all.sh A022                 # 真相表 → tmp/truth/A022/（每局 5~15 秒）
bash scripts/shadow_all.sh A022                        # 全队影子 → tmp/shadow/A022/{intents.tsv,rows.tsv,logs.txt,check.json}
node scripts/shadow.mjs A022 --bots ryan_m,noah88 --to 1300 --at 900,1260   # 指定拍的分支诊断（winFloor 拆解、buyLand 报价、调度、发船）
python3 scripts/exec_gap.py A022 [--bot 名字 --list t0 t1]   # 想发 vs 落地，按时段的落地率与延迟
python3 scripts/client_lag.py A022                     # 只用日志行序估每个号落后多少拍
python3 scripts/idle_scan.py A022                      # 贴弱 AI 不出手 / 封死 / 无海岸 / 顶硬上限 各多少拍
python3 scripts/truth_query.py A022 cmds|bal|gain|team …   # 逐条指令、余额轨迹、窗口得失
python3 scripts/match_digest.py A022                   # 一局的复盘底稿（10 节）
```

node 的命令请套 `bash c136-review/tools/run-heavy.sh`。B 组对局用引擎编号代替名字（`--bots 38,27,…`）。

## 局限

- 影子只复现决策，不复现「如果这条指令落地了，后面会怎样」。
- 指令丢在浏览器、网络还是服务器，录像里看不出来；只观察到每次追帧最多落地 9 条。
- `client_lag.py` 的落后量是相对最快的队友，精度 ±90 拍，是下限。
