# 可用工具：用线上客户端原文逐拍重放整局，结果与我方日志 100% 一致

**结论**：现在可以拿到任何一局里**全场每个玩家每一拍**的真实领土和余额（对手、队友、内置 AI 都有），不再只有我方 10 个号的日志。

## 怎么做到的
`scripts/engine_host.cjs` 把 `src/engine/live_game_js.js`（2.17.4）整份原样装进 Node，只把浏览器接口（页面元素、画布、图片、网络、存储、计时器）换成空壳。规则代码一行不改。
`scripts/engine_replay.cjs` 把 `replay.txt` 交给客户端自己的录像播放器，一步一步走（一步 = 喂本步指令 + 结算一拍），再读引擎自己的状态数组。地图由客户端内置的地图数据自己解出来，不需要外部文件。

## 证据
`out/engine-replay-check.txt`（`bash scripts/engine_replay_check.sh` 重算）：我的 13 局全部重放到终局，和 `traj.csv` 里每一条 `[HL-TICK]` 快照比较领土与余额。

| 项 | 数 |
|---|---|
| 局数 | 13（A022 A038 A029 A073 A047 A083 A099 A078 A015 A081 A086 A013 B034） |
| 对账的快照点 | 7077 |
| 领土和余额都完全一致 | 7077（100%） |
| 每局用时 | 2~6 秒 |

对比：仓库里的模拟器（`src/sim/sim/`）在 A073 这局 1 对 1 里只到 t=360 一致，t=450 起就偏了；A013 更早。所以逐拍证据应以这个真引擎重放为准。

## 用法
```
cd c136-review/agents/R04
bash ../../tools/run-heavy.sh node scripts/engine_replay.cjs <局号> --quiet --dump <输出.tsv> --every 90
```
输出 TSV 每 90 拍一组，列为 `t p name terr bal alive state`，包含全部真人（p 是引擎里的玩家编号，和录像指令里的编号一致）。要别的量（队伍总量、谁吃了谁的地、捐款真实到账额、船的落点）可以在 `startReplay()` 返回的 `h.run('…')` 里直接读引擎变量。

## 限制
- 只验证了 2.17.4 这份客户端和我这 13 局；别的局应该同样可用，但要各自跑一遍对账再引用。
- B034 这类日志名和局内名对不上的局，对账只覆盖了名字对得上的号（375 个点全一致）。
- A015、A086 的录像里只有部分我方号（其余号在另一场），重放的是录像那一场。
