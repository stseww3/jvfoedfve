# R04 议会提案（RFC-001）：模拟器怎么才算真，超级版本先改哪八处

> 作者 R04。依据：我复盘过的 13 局（A013、A015、A022、A029、A038、A047、A073、A078、A081、A083、A086、A099、B034；真引擎逐拍重放 + 影子策略），和四份对发现集 `bundles/` 的机械计数（落地指令流、日志和快照、两者的局间相关、同局真人的指令画像）。
> 这是议会提案，不是补丁：仓库里的策略源码和参数我一行没动。文中的公式用符号写，具体取值留给模拟器和断面测试去定。
> 数字都出自脚本产物（文末列了出处），正文没有手算的数。行号是 Vc（`v27-team-c116.js`）的，c110 的另外标出。

## 先说清楚这份提案的证据到哪一级

- **看到了什么（E1~E2）**：13 局里每一条结论都能指到局、号、拍和代码行；其中能机械计数的，在发现集的 99 局录像 / 122 局日志上数过。
- **没有做的（E4）**：反事实一概没有做。下面每一项「改了会怎样」都是推断，不是实测。这正是议题一要解决的。
- **验证集** `validation_bundles/` 我没有碰。

## 一页结论

**议题一（模拟器）**

1. **底座已经够真，不用重写引擎。** hub 的纯 JS 重放（`c136-data/src/tools/resim.mjs`）在我的 12 局组队局上，6,823 行日志快照的领土和余额全部一致；线上客户端原文在 Node 里跑的那一版 13 局 7,077 个快照点全部一致。失真不在引擎，在引擎外面的三层：**指令通道、对手、房间结构**。不分队的 A073 纯 JS 版只对上 254 行里的 9 行，这一种局先不要用它。
2. **指令通道用「时变延迟队列」建模就够。** 线上是锁步同步：一个落后的客户端在本地第 τ 拍看到的，就是服务器第 τ 拍的状态（13 局的日志快照和重放逐点一致，支持这一点）。所以「客户端卡顿追帧」等价于「按真实状态决策、指令晚 D(τ) 拍到」，卡顿期间下的指令在追上的那一拍一起到。不需要存旧状态。再加三条硬规则：每个决策拍只受理第一条；只在 7 的倍数拍执行；同号同拍最多执行 9 条、新的先执行、多出来的丢掉。
3. **通道要先过「旧代码复现旧签名」这一关，才有资格评新代码。** 把 Va / Vb / c110 的原文放进去，必须跑出线上量到的那几个数：全量上成摞占比按时段 1% / 51% / 66% / 12%；13 局里重复单占出征兵 47%~56%（c110 的 B034 是 14%），同拍第 2 条落地 0 次，装满的批后面丢单 46%，调度落地按配额四档 2% / 10% / 28% / 92%。跑不出来，模拟器就是错的。
4. **对手用录像里量出来的画像，不用想象的强敌。** 同局别的真人 3,965 个号的落地指令我数了一遍（§1.5）：开局四分之一的陆攻是整仓；600~1499 拍 72% 打内置 AI；1500~3212 拍打真人的一发中位是余额的 13.4%，同一个号两发之间中位隔 84 拍；63% 的人发过船。按这个分布写脚本对手，再叠加我 13 局里见到的七种打法。
5. **断面重演要做，但必须带「零假设检验」和「有效期」。** 从真局的 0 / 630 / 1500 / 4284 拍接手，先用当时那一版策略原文续跑，续跑结果要和历史对得上；对不上的断面不计分。别人的指令照录像放，放到「别人的录像指令还有多少能执行」掉下来为止。
6. **门禁看五族指标，胜率只做最后确认。** 基线胜率 12.3%（122 局赢 15 局），要分辨 12.3% → 20% 每组得跑 357 局；所以主门禁放在和输赢相关、又量得准的中间指标上：1530 拍占地比（赢的局中位 0.69，输的局 0.55）、调度被拒比例（42% 对 76%）、打薄后出局、整队崩盘。在赢的局里反而更多见的三个标记（封死、小船、小额单）不许当门禁。

**议题二（超级版本）**，按「不修它后面都白修」的顺序：

| 序 | 改什么 | 一句话证据 |
| :-: | :-- | :-- |
| 1 | 通道层：一拍一条的仲裁 + 本机在途账本 + 按需要量封顶的连发 | 重复单 2,763 条 33,708.6 万兵，占出征兵 52%；同拍第 2 条 399 次落地 0 次 |
| 2 | 留兵底线的参照物不许是队友 | 核心期前（630~1499 拍）的 19,662 个号·决策拍里，37% 被「别的邻居的余额」那一项底线顶住没出手，其中 75% 参照的是本编队的号 |
| 3 | 出生：间距按座位数算、看得见队友和敌人、确认落地 | 113 个号里落在最后一轮点上的 73 个；阵型间距和 1530 拍占地比的秩相关 +0.55 |
| 4 | 调度按反喂养配额算账 | 调度发出 → 落地：2142 拍前 259 → 6，2142~3212 拍 697 → 73，3213~4283 拍 678 → 189；策略里没有一处读配额 |
| 5 | 后排留底按「敌人够得着多少」算；弃子规则换成能检验的做法 | 弃子时段 108 段里 84 段 300 拍内出局；捐到三成密度后 400 拍内没地的后排号 24 个 |
| 6 | 过了 100×领土 之后的出手要看地比和密度比 | 去掉 A073 的 12 局：过线出手每万兵 18 格，没过线 73 格；过线且地比对方少的 247 轮里 75 轮净得地为负 |
| 7 | 封死号的出口：按到岸能站住多少发船，同一落点不重发 | 7 局里封住的号·行动拍 18,630 个，有海岸的 10,992 个里 8,806 个密度不到 68、发不了船；全量上 4284 拍后我方的船 73% 比例不够船费 |
| 8 | `isNoFullSend` 的锁要能解；认队友按队伍不按名字 | 113 个号里 108 个上过锁、之后拦掉 914 次；锁只有置真、没有复位 |

每一项后面都写了「在哪一局哪一拍会反咬一口」和要加的护栏。**最重要的一条护栏放在这里**：这八项不能逐项单独上线验收，因为它们互相掩盖。历史上重复单把一发 9%~17% 余额的脉冲放大成一串 22%~41%（c116 的 11 局组队局），配额拒单把后排的兵留在了家里。只修重复单，出手变轻；只修配额，后排更早被掏空（A081 的 3213 拍之后就是这样）。要成对地开关、成对地看。
