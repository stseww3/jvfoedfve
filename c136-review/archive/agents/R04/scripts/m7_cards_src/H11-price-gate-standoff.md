# H11　核心期的单价闸：贴着真人对峙不出手，等余额过线

> R04 假设卡｜来源：13 局复盘 + 全量对局包｜只写事实、机制和怎么证伪。

**陈述（可证伪）。** 核心期（1500 拍后）报价单按单价从低到高，单价高于自己的估值、又不够「便宜」、余额也没过 100×领土，就整轮不出手。两个真人接壤对峙时，没过线的一方要自己的密度是对方的两倍半以上才出手；被我方围住的敌方孤岛停在这道闸上，直到有号余额过线；只贴着一个健康真人的号过了线还要等到 128×领土，中间靠捐款把兵放掉。过了线就转到 H10 的「过线就打」，闸门两侧没有过渡。

**全量上的机械计数。** 判定要影子，全量上只有快照侧的间接量：`scripts/bundle_patterns.py` 的 FLAT600（1500 拍后领土不动、几乎不发指令持续 ≥600 拍的段）116 局里有，共 1,871 段、2,414,700 号·拍，段末余额已过 100×领土 的 629 段。它分不清「停在单价闸上」和「封死没有邻居」（H09）。

**什么结果算证伪。** 停在闸上的那些决策拍里，按当时双方的地和兵，出手其实换不到地（对方比我密、比我大）——那闸门就是对的。13 局里有判不明的（A047、B034 的对峙；A083、A086、A099 的单邻居）：不出手的那一段对方也在攒兵，换一种打法的结果没有重放。

**混杂与边界。**

- 「对峙」里判错的三局（A073、A078、A081）依据是对峙期间的账：A081 里 2400 拍我方 392.1 万兵对 316.8 万，3300 拍 1,350 万对 1,670 万；A073 里余额从 50 万涨到 616 万、领土不动。
- 闸门的读数来自影子；客户端落后的时段偏新。
- 没有 13 局统一口径的「停在单价闸上的号·拍」合计表（各局用 `core_gate_tally.py` 单独算过，时间窗各局不同）。

**要量的（模拟器 / 反事实断面）。** 在 1500 拍断面上，对「接壤的真人」按密度比分格，量没过线时在不同密度比出手的净得地；对手要有「也在攒兵」和「先过线先打」两种行为。验收线是 13 局里没过线出手的 86% 正收益。
