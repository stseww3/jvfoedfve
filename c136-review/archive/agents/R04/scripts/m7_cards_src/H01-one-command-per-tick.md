# H01　一个决策拍只落地一条指令：买地被无主地扩张挤掉

> R04 假设卡｜来源：13 局复盘 + 全量对局包｜只写事实、机制和怎么证伪。

**陈述（可证伪）。** 线上同一个号在同一个决策拍里发出的第 2 条指令不会落地。策略在一个决策拍里先调无主地扩张、再调买地，所以只要身边还有无主地，被挤掉的总是买地（打真人 / 内置 AI）的那一条。

**机制。** 两句调用之间没有「本拍已经发过」的守卫；适配层每个决策拍只受理一条。

**13 局的证据。** 影子策略同一个决策拍想发两条的 399 个号·拍里，第 2 条落地 0 次：确定没落地 173 次，分不清（两条参数相同）226 次。1500 拍以后确定没落地的 109 条，想出的兵 516.6 万。

**全量上的机械计数。** 数不了。这个模式要知道「策略这一拍想发什么」，只有影子策略在真引擎状态上重跑才有；录像里只有落地的指令。

**什么结果算证伪。** 任何一局里找到「同一个号同一个决策拍的两条不同参数的指令都进了录像」。13 局 399 个号·拍里没有一例。

**混杂与边界。**

- 226 个分不清的号·拍是两条参数完全相同、录像里落了一条，分不出落的是哪一条；不影响「第 2 条落地 0 次」，但被挤掉的兵量（516.6 万）只按确定的那部分算，是下界。
- 「想发两条」来自影子策略；真机日志的发令计数增量和它对得上的程度各局不同（各局复盘的自检里有）。
- 被挤掉的那一条如果落地会怎样，没有重放。

**要量的（模拟器 / 反事实断面）。** 模拟器的指令通道如果每个决策拍只受理第一条，13 局里被挤掉的买地指令数应当回到 399 / 173 / 109 这个量级；受理两条的通道跑同一批录像断面，可以直接量出这 109 条落地与不落地的领土差。
