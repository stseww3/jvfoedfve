# H11 船：手续费的三分之二花在小船上，五分之一的船上兵落在自己人的岸上，被围时发船多数换不到地（BT-boxed-no-gain / BT-boxed-breakout / FE-tiny-cmd-fee / BT-hit-squadmate / BT-gift / DF-sea-landing）

**假设**：c110 的船有三个问题。(a) 对无主地发的小船不看手续费，余额大的号每条船交的费是载兵的几十倍。(b) 船最后靠在哪由引擎按到岸那一拍决定，保护名单管不到：相当一部分兵落在异队我方号的岸上（按进攻结算）或交给了同队。(c) 被围的号发船是唯一的出路，但发船的门槛高、多数换不到地；对面从海上登陆时没有对应的防守。

**定义**（录像真值，`boatflow.py`）
- 船 = 我方号生效的发船指令，按引擎里的船编号配到靠岸或消失。手续费 = 发船那一拍余额的 32/1024（3.125%），跟船上带多少兵无关。
- 小船 = 船上的兵不到发船时余额的 5%；空船 = 千分比 0（引擎按余额的 1/1024 装船）。
- 被围时发的 = 发船那一拍影子策略眼里 nb=0 且 neut=0。
- 日志侧：被围时发船的相邻间隔并成一段；突围 = 之后 500 拍领土到过 ≥1.5 倍；没换到地 = 最高领土 <1.05 倍。
- 大登陆（`foeprofile.py`）= 外人的船登上我方在场号的岸，船上兵 ≥ 目标兵的一半且 ≥2 万。

**脚本**：`scripts/boatflow.py <局>`、`scripts/crossmatch.py boats|foes`、`scripts/patterns.py boxed|count`、单局 `scripts/simdigest.py <局> boats|landings|boatwar|gifts`。

**对照 / 效应**
- 小船 223 条只装了 67.6 万兵，交了 1,496 万手续费，占全部船费的 67%。去掉这些船，船费从船上兵的 53% 降到 18%（731 万 ÷ 4,170 万）。
- 被围时发船突围的比例，mine 17.2%、B·其余 8.2%：有用，但一半以上换不到地。
- 瞄准敌方真人的 202 条船，115 条（57%）靠上了那个人的岸；其余到岸时那块岸已经换了主人。

**不是什么**
- 不是船太多：8 局 823 条，73 个发过船的号平均每个 11 条；船费只占实得利息的 3.8%。问题在单条的结构（小船的费、大船的落点），不在总量。
- 「靠上异队我方号的岸」不一定是瞄着它发的：选目标时 L1104、L1953、L2304、L2345 都跳过受保护的岸；但 `searchFood` L2108 只排除已接壤的、真人和不合算的内置 AI，没有同队和保护名单检查，而且落点主人在航行途中会变。

**代码位置**
- `idleBoats` L4979-5006：收尾阶段（`isMopUp`）最多 6 条船、航程 2,500、不留底线；平时先试 `boatFood`（L4994），再要求没有无主邻格、距上次发船 ≥60 拍（`boatEvery`），有邻居时还要密度 ≥125（`idleCap = 1.25`，L4996）。
- `boatOut` L1035-1051：`max = 0.5 × (余额 − floorAt(目标地价))`；`min` = 目标是无主地时 60 兵，否则 `max(60, 4 × ⌊32×余额/1024⌋)` = 余额的 12.5%；`max < min` 不发。目标是玩家的岸：发 `max`，所以底线取到 100×领土 时要密度 ≥133.3 才发得出去。目标是无主地：发 `min(max, 3×岛的格数 + 300)`；`pct = ceil(量×1024/余额) − 1`，余额几百万时是 0。
- `boatFood` L2038-2058：对内置 AI 的岸最少发余额的 12.5%（L2050）；身边有地价不超过 `botMax` 的内置 AI 邻居时不发（L2042）。`searchFood` L2105 给无主地算效率时加了 `手续费 ÷ 格数`，`boatOut` 用的 `searchWater` 这条路径上最小量 60 兵不看手续费。
- `maxBoats = 2`（L1037），`boatFrac = 0.5`，`boatRange = 200`。
- 防登陆：捐款底线 `coastGuardFloor = 68×领土`（L4382，只管捐款）；`buyLand` 里没有针对登陆的分支，被登陆的号靠 `offers` 的报价还手（H05）。
- `Policy.act` L4922-4923：这一拍 `buyLand` 没出兵、捐款也没发，才轮到 `idleBoats`。

**证据等级**：船账 E1（8 局录像真值）；被围发船的结果在没看过的 23 局同版本对局里方向一致（突围 8.2%、没换到地 62.3%），E2。「小船的手续费」是引擎规则加一行代码的直接后果，不依赖统计。对胜负的影响 E0。

**反例与局限**
- B010、B017、B025、B038 的船费只有船上兵的 10%~25%：小船问题集中在余额大的号（B022 LeBron、B023、B021、B039 Pomerania）。
- B022 Dixie t=5096 一条 188 万兵的船靠上 GYRO 的岸，之后 111,084 → 150,835 格：大船打对了地方是有效的。
- 日志侧的「突围」只看领土，分不清是船换来的还是同时发生的别的事。
- 「被围」按影子策略在真实局面上的判断；卡顿时真实客户端看到的可能不同。

**代表实例**
- B022 LeBron：39 条船里 37 条是 0‰，各载 3,211~7,992 兵，每条手续费 10.3 万~25.6 万；船费 769 万换约 2,348 格。
