## 受影响的三处

1. **跨局汇总第 8 节（发现集日志替身，`e2census.py`）。** squad10 的 75 局里有 7 局编队分在两个房间，日志是全部号的。只留编队全在一个房间的 68 局重数：
   - 疑似被拒 95% / 91% / 75% / 7%（原 95% / 90% / 74% / 8%），被围占比四分位 19% / 39% / 58%（原 19% / 39% / 57%），几乎不变。
   - 地的倍数变得最多：上四分位 2.70 → 2.33，小房间一档输局的中位 2.93 → 2.33。去掉的 7 局多是 20 人上下的小房间。密度四分位 17.7 / 26.7 / 38.0 → 19.7 / 28.8 / 40.3。
   - 秩相关的方向和显著与否都没变，只有一对从过线变成不过线（选点间距 × 峰值÷人头，p 从 0.005 到 0.013，门槛 0.0056）。
2. **选点间距替身。** 第 8 节原来说它「不可用」（与出生份额的秩相关 +0.50，p=0.141，10 局）。其中 A025 的 0.32 是把两个房间的号放在一起量出来的假值。去掉 A025，9 局上是 +0.80（p=0.014）。现在的说法是「9 局太少，定不了」。
3. **会审报告两张表。**
   - 2.6 节历史基线签名表的最后一列换成 68 局的数，旧数留在表下。这张表是拿来和自由运行的模拟器对标的，小房间一档差得不小（2.93 对 2.33）。
   - 3.2 节「策略自己算得慢不慢」表里 A025、A071 两行，原来把别的房间的号也数进去了（9 个、10 个号），现在只数回放房间里的（6 个、9 个）。最大值没变，「不是策略算得慢」的结论没变。
