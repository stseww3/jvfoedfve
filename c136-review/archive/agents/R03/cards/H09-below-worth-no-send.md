# H09　1500~2399 拍：报价已经低于 worth，整拍仍不发令

| 项 | 内容 |
| :-- | :-- |
| 证据等级 | 11 局普查（E1×11）；决策拍分类来自影子重跑，保真度未单独验收 |
| 涉及模式 | NEW-R03-AT03、NEW-R03-AT08（相邻：NEW:AT-worth-gate、R07-EC-IDLE-RICH） |
| 范围 | 10 号编队档、策略 Vb，11 局，1500 拍起的 `buyLand` 决策拍 |
| 数字出处 | `out/cross/X8-belowworth.txt`、`X12-summary.txt` [H] [I]、`X7-decision.txt` |

## 陈述

1500 拍起 `buyLand` 的决策拍里，真正发令的只占 1~12%。1500~2399 拍，「排第一的报价是真人、报价低于 worth、整拍没发令」的拍占「低于 + 高于 worth」的 0~67%（输局中位 39%），其中约一半是 `Policy.offers` 不给脉冲档、只剩整吃档可走；2400 拍起「不给脉冲档」每局只剩 0~4 拍。

可证伪的说法：对这些「低于 worth 没发令」的拍逐拍归类（`dbg/buy-why.mjs` 的口径：单独拿掉哪一道闸会走到发令），如果单独拿掉「不给脉冲档」这一道之后仍不发令的占多数，这张卡就不成立。

## 机制

- `Policy.offers`（Vb L5291-5294）：`pulseMode` 在对方濒死或掉血时为真；否则要对方够薄或 need 超过余额的三成，并且不满足「2400 拍前、对方没在打我、need 超过余额的 35%」。也就是 2400 拍前，对着一个吃掉它要花自己三成半以上余额、又没来打自己的真人，不给脉冲档。
- 不给脉冲档时只剩整吃档（L5611-5616）：想送 1.25×need + 3×接壤格；可用的兵不够这个数、又不到余额的 chunk（本版 0.2）倍，就跳过。可用的兵由 L5424 的预算决定：(worth − 报价) × 领土 这一档差价撑得起多少兵。报价刚低于 worth 时预算很小。
- 接触惩罚（L5177-5180）：和目标接壤不到 25 格、且 0.75×对方地 ÷ 接壤格数超过 350 时，报价最多乘到 1.80 倍；贴得窄的号一直高于 worth（NEW-R03-AT08，A041 逐拍对过）。
- 几个号围着同一个真人时各算各的预算，没有哪一处把几个号的余额加起来（NEW-R03-AT03）。

## 11 局的数

- 1500 拍起 `buyLand` 决策拍：发令 1~12%（输局中位 3%，9/10 低于 10%；例外 A051）；被围 0~71%（中位 46%）；报价高于 worth 16~70%（中位 35%）；卡真人留底 0~13%；卡编队友留底 0~2%。
- 1500~2399 拍 低于 worth ÷（低于 + 高于）：输局 0~67%，中位 39%，6/10 不低于 30%；胜局 8%。
- 其中不给脉冲档的占比：输局 11~93%，中位 51%（9 局；A087 这一类是 0 拍）；胜局 71%。
- 逐局 1500~2399 拍「低于 worth 的拍（其中不给脉冲档）」：A071 533（254）、A046 513（197）、A066 281（260）、A041 279（181）、A067 216（123）、A045 165（28）、A090 147（75）、A051 120（13）、A042 87（73）、A087 0。
- 2400 拍起「不给脉冲档」：每局 0~4 拍。但低于 worth 没发令的拍还在：A041 985 拍（占低于 + 高于 的 54%）、A067 690、A042 526。

## 机械判据

`scripts/belowworth.py <局> <t0> <t1>`（只读影子缓存的逐决策拍记录）：每个决策拍只进一类——发令 / 没报价 / 过软上限 / 低于 worth / 高于 worth / 其它；「低于 worth」里排第一的报价 `pulseMode=0` 且 `nearCollapse=0` 的另记「不给脉冲档」。需要影子重跑。

## 反证与混杂

1. A087 这一段是 0 拍：它 75% 的决策拍没有报价（被围），这条机制只在有真人邻居的局起作用。
2. 没发令不等于吃亏：对方没在打自己、吃掉它要花三成半余额，这时候不打可能是对的。11 局里没有做「那一拍如果出手」的反事实。
3. 分类依赖影子重跑逐拍复现策略的内部量（报价、worth、pulseMode）；影子与线上日志的一致率在各局卷宗的 [S0]，但「低于 worth」这一类没有单独的校验量。
4. 2400 拍之后「低于 worth 没发令」仍然很多而「不给脉冲档」几乎没有，说明后一段是别的闸（等在途、留底、预算）——这张卡只解释了 1500~2399 拍的那一半。

## 还缺什么

- 1500 拍断面的反事实重放：只在历史局面上回答「这些拍如果发了令，300 拍后编队多拿或多丢多少地」，用来给这条机制定量（可能是正的也可能是负的，见反证 2）。
- 2400 拍起「低于 worth 没发令」的拍按闸分类（`dbg/buy-why.mjs` 只在个别号上跑过）。

## 代价口径

没有量出来。能给的只有拍数（上面第四条）和同一段的状态：1500 拍编队密度是其他真人的 1.45~5.09 倍（H02），兵在手里。
