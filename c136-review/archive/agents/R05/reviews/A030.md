# A030 复盘（squad10，Vb，输；复盘员 R05）

## 一句话结论

两队局（T1 22 人、T2 23 人，落子 43 人）。我方 10 个号全在 T2；T2 只在 600 拍前后领先过（11.1% 对 10.9%），630 拍起一直第二，峰值 43.5%（1920 拍）。编队占图一路涨到 25.5%（3690 拍，高于人数占比 23.3%），七个号 4053–4338 拍阵亡，sora_w 5204 拍阵亡，T1 终局 98.2%。归类：outscaled（带外因成分）。

输在三步。第一步是落子：这张图上协调器的四个「角」锚点全在内陆，十个号按 52 格间距排在大陆中央，名下只有全图 14.1% 的陆地，阵还移到了已落子的 Player 242 身边；内圈的 ryan_m、talon5、alex_k 1110–1200 拍起四周只剩队友（leo_tx 1770 拍起），四个号停在 3,500–4,500 格，alex_k 1233 拍离场。第二步是冻住的 1,700 拍（1500–3212）：五个被围的号握着编队六七成的兵，三条出口都关着——3213 拍之前的 177 条调度日志被引擎的捐兵配额拒掉 169 条，密度不到 115 不出船，四周没有敌人；有敌邻的四个号被价格门和留底按住，1800–2699 拍九个号一共落地 11 条陆攻/出船。同一段时间 T1 把 T2 的路人一个个吃掉（T1 50.0%→65.0%）。第三步是 3213 拍开闸：70 拍里 2.43M 捐到前线（2.08M 给 sora_w），编队冲到峰值，后排清到密度 24–46（敌方中位 68–79），税 484k；这时编队 5.05M 对 T1 14.18M，T1 的后排还在把兵送给四个前排（全程 15.47M）。3700 拍起西线被一条 10–38 万的指令接一条地磨掉，Troll 从 alex_k 的空壳穿进阵心。

名词：密度 = 存兵 ÷ 地；软上限 = 100×地，硬上限 = 150×地；出生份额 = 把每格陆地分给直线距离最近的真人出生点后各人名下的格数；被围 = 边界上没有敌人、机器人和中立地；留底 = 出兵后必须留在手里的兵；价格门 = 目标每格的报价 ≥ 估值就不买；放行 = 存兵 > 100×地 时不看价格；配额 = 引擎给每个受赠方的累计收兵点数上限；调度 = 策略发出的捐兵指令；过闸 = 影子策略按每拍受理 1 条算出来该发出的指令；影子 = 在逐拍重放的局面上调用线上同一份策略源码。
