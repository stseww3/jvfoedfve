# H10 挨打不还手：地在掉，一条打向进攻者的指令都没有

- 现象的证据等级：**E2**（日志口径 123 局：命中 110 局、1047 段、丢掉 11597076 格；905 个阵亡号里 736 个是在一段零指令的窗里出局的）
- 「值多少地」的证据等级：**E2 偏弱**（赢的局命中率 69%、没赢的局 93%，Fisher p=0.0135，没过 Bonferroni 门槛；机制只在我的 10 局里用影子核过）
- 对应模式：NEW-DF-01 / 01w（挨打不还手，严 / 宽口径）、NEW-DF-04（被更富的真人邻居压住，留底超过全部余额）、NEW-DF-06（挨打时价格门先截断）

## 一句话

1500 拍以后，一个号被真人推着走，地一段一段地丢，它自己一条指令都不发，直到掉过四分之一线被除名。
规则算的是「买他的地划不划算、买完留的兵够不够」，对面正在打我这件事不改变结论——划不来就整轮停手。

## 可证伪的陈述

1. 九成的局里至少有一个号，在一段完全没有新指令的时间里丢了三成以上的地。
2. 阵亡的号里，八成是在这样一段零指令的窗里出局的。
3. 这种号出局时账上往往还有大笔兵（见 H11）。
4. 赢的局里这个现象少一些。

## 机制（c110 行号；1500 拍后走 `Policy.buyLand` L5250-5534）

- 报价（`offers`，L5024-5036 一带）：对每个邻居 q，`c = (elimCost(q) + q 压在我身上的兵 − 我压在 q 身上的兵 + 手续费) ÷ 可吃的格`。
  这是「把它整个打出局」的每格价钱；对面压在我身上的兵越多，报价越高。
- 截断（L5258-5267）：`worth = maxW·winRatio(t) × 参考兵密度`；`if (c >= worth && c >= cheap && !over) break;`——最便宜的那个报价都不值，而且自己没过软上限，就整轮停，后面的邻居不看了。
  进攻者通常是兵多的人，按「打出局」报价一定贵，于是第一步就停了（NEW-DF-06）。
- 留底（L5322 → `Policy.safeAt` L4524-4540）：对健康的真人，留底不封顶；最富的真人邻居比自己富得多的时候，留底高过全部余额，`avail <= 0`，对谁都出不了手（NEW-DF-04）。
  `dpKeep`（L2491-2496）在 1500 拍前是同一个思路：`(最富真人邻居的余额 + 它压在我身上的兵 − 1.5×地) ÷ 1.78`。
- 专门的反击分支是关着的：`counterAttack`（L871-887，「对压兵最多的真人立刻回一手」）只在 `counterK > 0` 时才调用（L825），而五个策略文件生效的 `counterK` 都是 0（`out/_cross/params.txt`）。
  挨打时走的还是上面那几道买地的闸。
- 引擎（`game.js`）：对方的进攻每吃我一格要付 `2 + 3.2×我的兵密度`（`expandAttack` L958-1060），我每丢一格，余额少掉约 `1.6×我的兵密度`（L1008-1014 → `damage` L1062-1074）；
  我如果对它有一场进攻，对方要先消掉我压上去的兵（`counter`）。不还手 = 让对方按最低价吃。地掉到峰值四分之一就除名（`aliveTick` L1298-1312），余额清零。

## 和结果的关系（`xsig.txt` [XG-C]）

- NEW-DF-01：赢的局 11/16（69%），没赢的局 99/107（93%），Fisher p=0.0135；宽口径 11/16 对 100/107，p=0.0090。都没过 Bonferroni 门槛（0.00036）——赢的局只有 16 局，Fisher 检验到不了那个门槛。
- 方向和常识一致（输的局里挨打的号多），但这也可能只是「输的局里被打的机会多」，不说明还手就能赢。

## 反证和混杂

- 严口径对阵亡号偏宽：号只要在最后两条快照之间（90 拍）没发指令、之前有 ≥300 格，就算一段。很多号的最后 90 拍本来就无事可做（地已经很小）。宽口径（整段下坡 ≤1 条陆攻）更可信：459 个阵亡号。
- 「不还手」有时是对的：对面兵是自己的十倍时，还手只是把兵送掉；这时该做的是把兵捐给队友（H12）或者留着拖时间。检测器不区分「打不过」和「没想打」。
- 日志里看不到进攻者是谁；「没有一条打向进攻者的指令」在严口径下是「一条指令都没有」，宽口径下是「陆攻 ≤1 条」，都没有核对目标。逐条核对目标只在有录像的单局做过。
- 机制那两条（DF-04 / DF-06）是 c110 的行号和 c110 的影子；c116 系的 `buyLand` 没有逐行对过（`codemap.txt` [CM-C] 只说正文不同）。
