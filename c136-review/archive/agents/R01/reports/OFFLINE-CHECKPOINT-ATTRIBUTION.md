### 1.1 归因

**到 3213 拍，历史的人均相对领土只有「同一版规则跑在健康通道上」的六成不到（14 局 ×0.55–0.58，两种算法一致）；有落后的 11 局是 ×0.46–0.49，通道干净的 3 局没有差距（×1.03–1.06）。这段差距里，模拟器的通道模型（落后波 + 页面停摆/掉线）复现了 56%–84%，其余是模拟器没解释的残差，残差集中在落后重的局。历史版本之间的差：Va / Vb / Vc 在 1500 拍之前是零，之后一个窗口约 0.06 个点、方向不定；c110 与 c116 家族之间一个窗口差 0.01–0.10 个点，方向随窗口和局而变。3213 拍以后，窗口内的通道效应很小，累计数不可靠。**

### 1.2 保真度（G0 三条）

1. **物理底座：过。** R06 的引擎移植整局重放 14 局，对真引擎 71,869 / 71,869 格相同，对我方日志快照 6,249 / 6,249。
2. **历史版本在模拟器里的统计签名是否落在实盘四分位区间内：Vb 过；c110 我这两局验不了。**
   - Vb（10 局）：R06 入库的实盘区间有 15 个（窗口, 签名）格子，C2 臂的中位全部落在区间内。
   - c110（B039、B043）：14 个格子里 C2 中位只有 6 个在区间内。这两局自己的历史值也有 8 个格子在区间外，C2 跟的是这两局，不是 c110 的总体。两局太少，也都是深落后局，这一条对 c110 不成立也不被推翻。c110 的决策层在沙箱里只复现到统计量级（§4.3），c110 两局的归因数字要按这个精度读。
   - 这是「每个窗口都从历史局面起跑」的口径。更严的口径是从开局一口气放开跑、中间不回到历史（§4.6）。历史 ÷ C2 放开跑（几何均值；3213 拍及以前 14 局，4284 拍 12 局，5184 拍 10 局）：630 拍 ×1.01，1500 拍 ×0.94，2400 拍 ×0.94，3213 拍 ×0.79（通道干净的局 ×0.98，有落后的局 ×0.74），4284 拍 ×0.78，5184 拍 ×0.53（通道干净的局 ×0.65）。不重新对齐时，模拟器到 2400 拍为止离历史 6% 上下，方向是模拟的我方偏强；3213 拍起有落后的局偏得多；后半局不能用。跑到 1500 拍，活席数 14 局全部与历史相同。
3. **断面单因素反事实归因：做了，就是本文。** 闭环残差（历史 − C2）的中位数在各窗口是 0.004–0.022 个点；68 个（局, 窗口）里 64 个活席数与历史相同。残差大的窗口集中在两类：一次性的生死事件（一块空壳或一个席位在历史里被吃掉、在模拟里没有），和落后重的窗口（模拟的我方比历史略强）。

### 1.3 这些数的可信范围

1. **累计数。** 每个窗口内的通道效应是直接量出来的，最硬。累计的数要带着下面几条读：
   - 到 3213 拍，两种算法给出的「历史 ÷ 健康通道」一致，但通道模型复现的占比差得多（84% 对 56%）。真实的占比在这个范围里。
   - 对手是开环的。其余真人在每条臂里都只照录像出手，我方变强以后他们不会改主意。630→3213 的两个窗口里，他们的陆攻在 C0 / C1 臂下有 11%–13% 因为目标变了而改打或作废（C2 臂 7%）；放开跑到 5184 拍，C2 臂里是 15%，他们逐人的领土与历史相差 38%。
   - 健康通道这条反事实的水平可能偏高。有落后的 7 局 Vb，C1 的水平比真实的通道干净局（R06 的实盘区间，9 局 Vb）的中位高两成上下：1500 拍 ×1.18（连乘）/ ×1.20（放开跑），3213 拍 ×1.34 / ×1.22。来源分不开（§4.8）。不靠模拟器的反事实、拿这 7 局的历史直接比真实干净局的中位，1500 / 3213 拍是 ×0.85 / ×0.68（比的是不同的局）。
   - 3213 拍以后没有能互相印证的算法：逐窗口的通道效应很小，放开跑的模拟离历史太远。
2. **实录阶梯在落后最深的地方有空档，补上以后结论不变。** 主口径的阶梯只收能唯一定位的指令配对。日志流水号给了一条独立的落后下界，有下界的 354 个日志点里主口径够得着 264 个。把定位不唯一的配对（按最早 / 最晚放得下的决策两种配法，记作上界 / 下界口径）和日志下界都加进去，重跑阶梯差得多的窗口（§4.7）：

   14 局的对数链，主口径 / 上界 / 下界：落后波 + 页面 -0.575 / -0.589 / -0.577（×0.56 / ×0.55 / ×0.56）；其中落后波 ×0.70 / ×0.68 / ×0.69、页面/掉线 ×0.80 / ×0.82 / ×0.81；残差 -0.114 / -0.100 / -0.111（×0.89 / ×0.90 / ×0.89）。已重跑 上界 19 个、下界 11 个窗口，排着队还没跑的 上界 10 个、下界 20 个（阶梯差得小的）。
3. **落后波与页面/掉线两段的先后次序。** 本文先加落后波、后加页面。倒过来加（§3.6），整条链上落后波 ×0.70 → ×0.67，页面/掉线 ×0.80 → ×0.84，占比 51% / 33% → 58% / 25%，两段合计不变。两段之间的分法有七八个百分点的任意性。
4. **样本。** 14 局是按通道状况挑的代表局，不是随机样本；c110 只有 2 局。分组均值的区间是按局重抽样得到的，只反映这 14 局之间的散布。
5. **结果量。** 归因的是 5184 拍以内的领土、兵力和活席，不是输赢。5184 拍以后我方多数局只剩三四个活席，开环对手的假设也越来越站不住，没有往后做。

| C2 | 同 C2w | 按实录停摆、离场 | 3 |
| 历史 | 录像原样重放 | | |

- 实录的落后阶梯：每个席位一条「页面算到本机第 W 拍时服务器走到了第几拍」的不降曲线，由指令配对（影子的下令拍 ↔ 录像的执行拍）连起来。配对与 `reports/m6-data/channel_bursts.csv` 是同一套（14 局 6,486 条，逐条相同），只是换成通道模型能读的格式（`reports/ckpt-data/traces/`）。已知点之间用 R06 的 `fill=auto` 补。
- 通道模型的其余部分（每 3 个回合每席至多 9 条、先发的留下、同一回合后发的先执行、7 拍一个回合）是 R06 的 `lib/channel.mjs`，没有改。
- 种子只影响通道的随机数（基础延迟的抽样、哪几个页面偏慢）。同一档 3 个种子之间的标准差就是这一档的噪声底：C1 各窗口平均 0.010–0.042，C2 0.008–0.020。
- 只有当窗口里确实有页面停摆或离场时才单独跑 C2w，否则 C2w = C2。

### 2.3 分解与串接

结果量是窗口末的**人均相对领土** = 我方席均领土 ÷ 全体真人席均领土（已出局的席位也算人头）。1.0 就是平均线。另看兵力（余额 + 在攻兵）与活席数。

每个窗口：

```
历史 − 起点 = (C0 − 起点)      规则：这一版规则在即时通道下从断面走到窗口末
            + (C1 − C0)        基础延迟
            + (C2w − C1)       落后波
            + (C2 − C2w)       页面停摆 / 掉线
            + (历史 − C2)      残差：模拟器没解释的
```

各窗口都从历史的真实局面起跑，所以整局的账要把窗口串起来：逐局把首尾相接的窗口的 ln 比值相加。「C1 路径的终点」= 起点 × 各窗口（C1 ÷ 窗口起点）的连乘，其余类推。历史或某条臂的人均相对领土低于 0.05 的窗口不进链（除以一个接近 0 的数没有意义），这样的窗口有 3 个：A055 的 4284→5184、A003 与 A094 的 3213→4284。连乘的前提是窗口内的涨幅和起点水平无关；直接的核对是一口气放开跑、中间不回到历史，见 §4.6。

### 2.4 怎么读

- C0 在线上做不到。「通道健康」的基线是 C1；「历史 ÷ C1 路径」= 落后波 × 页面/掉线 × 残差。
- 「规则」这一段不是「规则亏了多少」，只是历史规则在即时通道下的变化量。要说规则亏没亏，得有另一套规则来比，本阶段不写新策略，能比的只有历史上已有的几个版本（§3.5）。
- 落后阶梯当作外生的：换一个版本、换一种通道状况，页面落后多少都按实录的来。

  - 实盘横向对比：按同拍批占比分档 ×0.81（R06 的区间），按「落地 ÷ 放行」分档 ×0.62（M6 全量表）。两种分档抓的不是同一批局，结果量也略有不同。
  - 这几个数落在 ×0.5–0.8 之间，没有哪一个能当真值。能说的是：通道差的局到 3213 拍比通道好的局低两成到五成，模拟器的通道模型能复现总差距的一半以上（56%–84%，看用哪种算法），复现不了的部分方向一致（历史更差）。

跨局回归（`ckpt_tables.md` 表 K）是另一种间接的核对：各局在 630 拍的起点水平不同，如果窗口内的涨幅和起点无关，跨局斜率应当是 0。630→1500 这个窗口里历史和 C2 的斜率是 0，C1 是 −0.82 ± 0.36。但同一局里的直接核对（§4.6 表 Z）在 630 这个接头上没有看到连乘的偏差（连乘 ÷ 放开跑 ×0.99）。跨局斜率混着局与局之间的差别，不能当作同一局里的因果；表 K 里按斜率修正的那一张本文不采用。

## 5. 局限

1. **对手开环。**

| 窗口 | 局数 | 其余真人的陆攻（条，各局合计） | 改打或作废（各局比例的均值）：C0 / C1 / C2 | 其余真人逐人领土 L1 ÷ 历史（各局合计）：C0 / C1 / C2 | 我方逐席领土 L1 ÷ 历史（各局合计）：C0 / C1 / C2 |
| :-- | --: | --: | :-- | :-- | :-- |
| 0→630 | 14 | 8540 | 0.1% / 0.1% / 0.1% | 0.008 / 0.005 / 0.004 | 0.35 / 0.19 / 0.04 |
| 630→1500 | 14 | 11965 | 13.0% / 11.3% / 7.5% | 0.094 / 0.081 / 0.051 | 0.53 / 0.43 / 0.11 |
| 1500→3213 | 14 | 4190 | 12.9% / 11.9% / 7.1% | 0.101 / 0.095 / 0.057 | 0.45 / 0.44 / 0.20 |
| 3213→4284 | 14 | 1875 | 4.9% / 3.4% / 3.4% | 0.022 / 0.013 / 0.013 | 0.12 / 0.07 / 0.07 |
| 4284→5184 | 12 | 1209 | 5.2% / 3.1% / 2.5% | 0.043 / 0.035 / 0.015 | 0.23 / 0.19 / 0.08 |

   我方在 C0 / C1 臂里比历史强，其余真人的录像指令有一成多对不上号。真实的对手会改打别处、会回防，这些都没有。所以 C0、C1 两条臂的终点偏高，本文所有「÷ C1 路径」的比值偏低。偏多少，§4.8 给了一个外部对照：C1 的水平比真实的通道干净局高两成上下（来源不止开环这一条）。C2 臂本身离历史近（其余真人逐人领土偏离历史 1%–6%），C2 与历史的比较不受这一条影响。
2. **C2 的阶梯是样本内的。** 阶梯就是从这一局自己的落地指令配出来的，C2 贴近历史有一部分是定义带来的。§4.2 的留一核对说明阶梯带了真信息，但闭环上没有做留一。
3. **阶梯是外生的。** 换版本、换通道状况时页面落后多少都按实录。如果落后本身和策略下令的多少有关，这里看不到。
4. **连乘是近似，放开跑有它自己的毛病。** 每个窗口都从历史局面起跑，「C1 路径」不是真的一路在 C1 下走出来的；连乘只累计窗口内的效应。一口气放开跑不回到历史，但离历史越远，开环的对手越不可信。到 3213 拍两种算法的总差距一致（×0.55 对 ×0.58），拆法不一致（通道模型复现 84% 对 56%）；3213 拍以后放开跑不能用（§4.6）。
5. **生死窗口。** 我方接近归零的 3 个窗口不进链；席位或空壳的生死是一次性的事件，3 个种子之间也会翻（§4.4）。
6. **c110。** 只有 2 局，决策层只到统计量级，签名对不上 c110 的实盘区间。
7. **种子数。** 每档 3 个种子，版本互换 2 个。噪声底在 0.01–0.04 个点，逐局逐窗口的小差别不要读。
8. **5184 拍以后没有做。** 归因的是领土、兵力、活席，不是输赢。
