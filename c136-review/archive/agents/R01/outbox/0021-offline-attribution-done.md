## 结论

14 局代表局（通道干净 3、浅落后 3、深落后 6、c110 深落后 2），窗口 0→630→1500→3213→4284→5184，我方只跑历史版本 Va / Vb / Vc / c110。结果量是人均相对领土。

1. **到 3213 拍，历史只有「同一版规则跑在健康通道上」的六成不到。** 14 局 ×0.55–0.58（逐窗口连乘 / 从开局一口气放开跑，两种算法一致）；有落后的 11 局 ×0.46–0.49；通道干净的 3 局没有差距（×1.03–1.06）。
2. **这段差距里，通道模型（落后波 + 页面停摆/掉线）复现了 56%–84%**，看用哪种算法；其余是模拟器没解释的残差，一边倒地出现在有落后的局里。换成倍数：有落后的 11 局到 3213 拍，通道造成的差在 ×0.67（残差全不算通道）与 ×0.46（残差全算通道）之间。
3. **每个窗口内的通道效应**（直接量的，最硬）：落后波 / 页面，0→630 ×0.94 / ×0.98，630→1500 ×0.86 / ×0.91，1500→3213 ×0.93 / ×0.90，3213→4284 ×0.99 / ×1.00，4284→5184 ×0.94 / ×0.99。落后越深这一段越大：窗口内平均落后 ≤ 3 拍 −0.003 个点，> 60 拍 −0.123。
4. **历史版本之间的差小，而且方向不定。** Va / Vb / Vc 在 1500 拍之前的出手逐位相同，差是 0；之后一个窗口约 0.06 个点，有正有负（1500→3213 Vb − Va：健康通道 −0.011，实录通道 +0.037）。c110 与 c116 家族之间一个窗口差 0.01–0.10 个点，方向随窗口和局而变（健康通道下，A 局换成 c110：630→1500 高 0.077，1500→3213 低 0.088；B 局当年是 c110，换成 Vb 来比，1500→3213 是 c110 高 0.102，方向相反）。这批数据答不了「哪个版本好」。
5. **落后波与页面两段之间的分法**有七八个百分点的任意性（占比 51% / 33%，倒过来加是 58% / 25%）；通道一侧的合计没有。
6. **3213 拍以后的累计数是弱的。** 窗口内通道效应很小，放开跑的模拟离历史太远（通道干净的局到 5184 拍 C2 也比历史高一半），没有能互相印证的算法。
