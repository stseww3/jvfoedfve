## 四、这一轮新看到的东西（都有代码行和引擎账）

1. **过软上限就不看价出兵**（`buyLand` L5353 / L5359）：余额超过 100×领土后，「目标每格成本 ≥ 自己的出价就停」这一判断被跳过。A033 影子里 sora_w / zero_7 / zexos1 / talon5 共 82 次约 2,067 万兵是在目标单价高于出价时发的。调度把收方推过软上限，收方再按高价打出去，是同一条链。
2. **「后方银行」留底**（`tryDonateToTeammate` L4355 / L4382 / L4386）：只要没有陆地敌邻、没有 AI 邻居、没有中立地就算 boxedIn（不看海岸、不看领土大小），协防时留底 22×或 32×领土，一次捐 37%。A033 的 zero_7（全队最大，27,810~34,341 格）五次这样捐给 sora_w，7200 时密度 33，之后被 i🍇TV 400 拍打光。源码注释写的是 76×，实际数值是 34 / 44 / 22 / 32。
3. **「没救的口袋」跳过**（L4455-4456）：队友身上的敌兵超过它余额 1.65 倍就不救。A033 的 talon5 挨打的前 150 拍比值是 2.14→1.69，没人救；比值降到 1.60 后的第一个相位拍（7615）两个号同时发出协防，逐拍吻合。
4. **捐款被收方硬上限截断，手续费照收**：A033 t=5257 那一笔名义 1,263,968、到账 248,839、手续费 252,006。进攻退兵也走同一个封顶（zero_7 5229 退兵丢 73,140）。
5. **离开的席位**：进程掉线到引擎判离开隔了约 470~490 拍（A062、A033 一致），这期间席位照常吃利息；判离开后内置 AI 把整个余额捐给正在打仗的队友（A033 ryan_m 的席位 130 拍内送出 107 万兵）。
6. **G00 的停摆**：`rnd is not a function` 的触发条件是沿海号密度过 22（走到闲置船那一段），不是随机的。
