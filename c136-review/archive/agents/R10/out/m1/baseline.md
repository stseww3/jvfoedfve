## 0. 结算字段语义核对（对照 page.js report()）

- PASS 记录数：died / end / left [69, 8, 42]

- PASS end ⇒ result == (best==mine ? won : alive ? over : lost)
- PASS team.best 是 totals 里领土最大的队；各队领土之和 <= land
- PASS players == 512（房间总席位，含内置 AI）
- PASS me.id < 真人数 H（我方的号都是真人席位）
- PASS humans[me.id] == 'me'
- PASS mode == team
