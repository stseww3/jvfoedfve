# R10 任务卡：红队 / 裁判

你的职责是让这个项目的结论经得起推敲。你不提策略建议，只做三件事：定口径、查证据、找反例。你对进入台账的每条结论有否决权，否决要写明理由和需要补什么证据。

## 输入

- 数据 A：`c116-winrate/data/`（结算记录和日志）、`c116-winrate/MASTER-SYNTHESIS.md` 和 `c116-winrate/reports/`（上一轮的结论）、`c116-winrate/LIAISON.md`（上一轮的 12 个变量定义）。
- `c136-review/PLAN.md` §2、§4、§6、§7 和 `REVIEW-PROTOCOL.md`。
- R06 的结算字段说明发布后我会广播。

## 里程碑

**M1：口径和基线。**

1. 写 `scripts/stats.py`：比例的 Wilson 区间、两个比例之差的区间、给定基线和目标提升时每臂需要的局数。只用标准库，带自测。
2. `reports/METRICS.md`：什么算「一局」、什么算「有效局」、什么算「赢」；`left`、不满编、两支小队同房这些情况各自怎么处理；按队伍数、房间人数、小队人数分层的方案；每个分层的基础期望怎么取。结算字段的确切含义等 R06 的说明，先把你的假设列明。
3. 用数据 A 里现有的记录把能算的基线先算出来，带区间。样本很小，照实写。

**M2：旧结论审计。** `reports/LEGACY-AUDIT.md`：

- `MASTER-SYNTHESIS.md` 里的 12 个变量逐条审：它的证据是什么、按 `PLAN.md` §6 的标准是哪一级、有哪些没排除的混杂、什么样的数据能证伪它。
- 之后在实盘上宣布过「已修复」的几项改动同样审：前线保留密度底线（`oppFloorCap` 先后取过 128、38、78、88）、后排起捐线、输血方向限制、角落扇形阵型、协防连发。问：有没有对照实验，改动前后的胜率区间是否重叠。
- 目的不是否定，是分清哪些能当线索、哪些连线索都算不上。

**M3：质检规程。** `reports/QC-PROTOCOL.md`：抽查一份逐局复盘时具体查什么（重算哪些数字、怎么核对代码路径、怎么判断「观察 / 推断 / 猜测」标得对不对）；两人独立复盘同一局时，一致性怎么量化。第一份复盘交上来后我会把路径发给你，从那时起每轮抽查并把结果发给我。

**M4：过拟合威胁清单。** `reports/OVERFIT-THREATS.md`：这个项目从复盘、建模式目录、计数、验证到出改动，每一步可能怎样过拟合或自欺，对应查什么。写成可以逐条打勾的检查表。也审一遍 `PLAN.md` 和 `REVIEW-PROTOCOL.md` 本身：哪里有漏洞，直接告诉我。

**M5（全量数据到达后）：** 审 R01 的切分方案；之后用冻结的检测脚本在留出的对局上做复现。我会另发任务。
