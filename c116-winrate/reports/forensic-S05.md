## 六、`cand-s05.js` 精确修复补丁（零副作用、可直接合入主线）

基于上述四步铁证，我们在 `territorial-sim/strategy/pool/cand-s05.js` 中实施了以下 3 处精准外科手术修复：

1. **修复 `tryDeterrentCounter` 围攻期失血与假桥头堡（`v33-live.js:2716-2788`）**：
   - 将 `activeHumanAtkers` 的统计窗口从“仅当前拍在途 `> 2% B`”扩展为“当前拍在途 `> 1.2% B` **或过去 200 拍内曾发兵 `> 1.2% B` 攻打过我方**（`g.t - stA.lastPokeTick <= 200`）”，彻底堵死多路围攻错峰脉冲绕过 `activeHumanAtkers >= 2` 的漏洞；
   - 将 `isFreshBeachhead` 严格限定为真正的小飞地/小玩家（增加 `&& Lq <= 25000 && Bq <= 0.40 * B`），防止将刚打通山脉/海峡接壤的 7 万地巨无霸（如 `H#12`、`H#16`）误判为抢滩桥头堡；
   - 移除 `dq > 1.25 * dMe && cntQ < 28` 中的 `cntQ < 28` 限制，并规定当我方处于软上限以下（`dMe < 105`）时，若周围有 `>= 3` 个真人邻居或目标密度 `dq > 0.95 * dMe`，严禁发射负 EV 的威慑反击刀，专心利用本土 2:1 防守优势吃复利。
2. **修复 `buyLand:5214` 线上 7 拍双连发 `20% B` 叠锤（`v33-live.js:4082, 5211`）**：
   - 在 `Policy.send` 中，只要单笔出兵 `troops >= 0.12 * balBefore` 即记录 `this.lastLandSpendTick = g.t`；
   - 在 `buyLand:5211`（非秒杀大单分支 `x < want`）增加冷却锁：`if (person && (curAtk >= 0.08 * B || g.t - (this.hitTo.get(q) ?? -999) < 25 || g.t - (this.lastLandSpendTick ?? -999) < 16) && x < want) continue;`，彻底根除线上 RTT 回包解锁导致的 7 拍双连发 `20% B`。
3. **修复 `widenFrontBoats` 与 `Policy.send` 漏加 `35,000` 船税上限（`v33-live.js:3803, 4096`）**：
   - 在 `widenFrontBoats` 入口增加 `if (B < 3000 || fee > 35000 || B < 85 * Math.max(1, g.terr[me])) return false;`，并在 `Policy.send` 第 `4096` 行增加 `fee <= 35000`，彻底消灭中后盘千万兵力下为了发 1 万兵小船白交 37 万船税的漏洞。
