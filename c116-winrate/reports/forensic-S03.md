## 五、三大根因代码定位与外科手术修复方案（供 `S12 / c108` 汇总门禁验证）

### 1. `RC-1`：`tryDeterrentCounter` 双线受击漏判与后期巨无霸反戳禁令（`v33-live.js:2717-2745`）
- **问题代码**：
  ```js
  let activeHumanAtkers = 0;
  for (const a of g.attackersOf(me)) {
    if (a < g.humans && !g.isBot(a) && g.attackTroopsOn(a, me) > 0.02 * B && g.bal[a] >= 0.30 * B) activeHumanAtkers++;
  }
  if (activeHumanAtkers >= 2) return false;
  ```
- **修复方案**：将 `pokeState` 中最近 `150` 拍内发起过 `>= 0.02 * B` 进攻的真人一并计入 `activeHumanAtkers`，并在 `g.t >= 5000` 严禁在非抢滩（`!isFreshBeachhead`）且 `dMe < 110 || Lq >= 65000 || Bq >= 0.60 * B` 时对大号真人发反戳：
  ```js
  let activeHumanAtkers = 0;
  for (let a = 0; a < g.humans; a++) {
    if (a === me || !g.alive[a] || g.isBot(a)) continue;
    const incA = g.attackTroopsOn(a, me);
    const stA = this.pokeState.get(a);
    const recentA = stA && g.t - stA.lastPokeTick <= 150 && stA.lastPeakInc >= 0.02 * B;
    if ((incA > 0.015 * B || recentA) && g.bal[a] + incA >= 0.25 * B) activeHumanAtkers++;
  }
  if (activeHumanAtkers >= 2) return false;
  // 在循环内增加后期巨无霸反戳护栏：
  if (!isFreshBeachhead && g.t >= 5000 && (dMe < 110 || Lq >= 65000 || Bq >= 0.60 * B)) continue;
  ```

### 2. `RC-2`：`buyLand` 跨 WebSocket 延迟重复发包与 `zeroPulse` 税费空转（`v33-live.js:5049-5215`）
- **问题代码**：`g.online` 下每 3 拍跑一次 `act(g)`，但 `buyLand` 对同一真人目标 `q` 没有检查 `this.hitTo.get(q)` 冷却，导致在 7 拍服务端回包前重复发包（产生全场 11 次双发/三连发）；同时 `canZeroPulse` 冷却仅 12 拍且 `ring1Cost >= 2.5 * fee` 过低，在 `t = 5958 ~ 5991` 连发 6 笔 `pct = 0/1` 脉冲白交 55 万税费。
- **修复方案**：
  ```js
  if (person && !o.nearCollapse && g.t - (this.hitTo.get(q) ?? -999) < 25) continue;
  ```
  并将 `canZeroPulse` 的 `recentHit` 提高到 `45` 拍、`ring1Cost >= 6.0 * fee`。

### 3. `RC-3`：决赛圈多强合围防守底线（Coalition Floor）与 `emptyAllIn` 残血收割放行（`v33-live.js:5033, 5177, 5200`）
- **问题代码**：`dpKeep(g)` 仅对单个最大邻居设防（在四强局仅留 `dMe = 53.7`），无视其余接壤真人的兵力总和；同时 `v33-live.js:5177` 的 `if (inAtk > 0 && curAtk + pulse < ring1Cost + 2 * cntQ) continue;` 未豁免 `o.nearCollapse`（含 `emptyAllIn`），导致对手梭哈打空后我方因 `inAtk` 过大而无法反推收割。
- **修复方案**：
  1. 在 `v33-live.js:5177, 5200` 将 `inAtk > 0` 门槛改为 `if (!o.nearCollapse && inAtk > 0 && curAtk + pulse < ring1Cost + 2 * cntQ) continue;`；
  2. 在 `buyLand` 计算 `keep` 时加入多强合围底线：
  ```js
  if (person && !o.nearCollapse && g.t >= 5000 && nHumans >= 3) {
    let otherB = 0, otherN = 0, otherInAtk = 0;
    for (const p of this.nb) {
      if (p !== q && g.alive[p] && this.person(g, p) && g.terr[p] >= 15000) {
        otherN++;
        otherB += g.bal[p] + g.attackTroopsOn(p, me);
        otherInAtk += g.attackTroopsOn(p, me);
      }
    }
    if (otherN >= 1 && (otherB >= 1.10 * B || otherInAtk >= 0.03 * B)) {
      const coalFloor = Math.max(88 * L, Math.min(102 * L, (otherB - 1.5 * L) / 1.78));
      safe = Math.max(safe, coalFloor);
    }
  }
  ```
