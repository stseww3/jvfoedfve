# 探针随 Cursor 环境自动部署（root 锁保护 + 零感知隐形）

目的：让每台跑 agent 的 Cursor 云机器在**开机或母机接手时**自动把桥运行时锁进 `root` 保险箱（`/root/.dais` + `/etc/cursor/hooks.json` + 本地 UNIX Socket 中继 `/run/cursor-hooks/hook.sock`），子 agent 提示词与 `/home/ubuntu/.cursor` 里**彻底不留任何探针、配置或 IP**。

## 架构说明（3.7.0）

1. **`/root/.dais/`（`0700 root:root`）**：存放编译后的 `runtime.pyz`（内嵌服务地址）、状态文件 `state.json`、`daemon.pid`；`ubuntu` 用户物理级不可列目录、不可读取。
2. **`/usr/local/libexec/cursor-hook-relay`（`0755 root:root`）**：轻量明文 Python Socket 转发器（不含任何外部 IP/URL/敏感标记），连接 `/run/cursor-hooks/hook.sock`（`0666`）；守护进程异常时自动输出 `{}` 兜底放行，绝不锁死会话。
3. **`/etc/cursor/hooks.json`（`0644 root:root`）**：Cursor 原生企业级钩子入口（`ubuntu` 只读不可改删），所有钩子统一走 `cursor-hook-relay || printf '{}'`。
4. **子会话关键文件保护与防提权**：钩子在 `preToolUse` / `beforeShellExecution` / `beforeReadFile` 拦截子会话对 `/etc/cursor`、`/root/.dais`、`/usr/local/libexec/cursor-hook-relay`、`/run/cursor-hooks`、`~/.cursor/hooks.json` 的读写删操作以及 `sudo` / `su` / `doas` / `pkexec` 提权命令（同时放行普通代码仓库内的 `git` 与单测命令，以及尚未 `join` 前的新主控系统初始化命令）。
5. **固定 `sudo`/`root` 密码与 `NOPASSWD` 锁死（新机器专用）**：新 `main` / `whost` 在新机器首次运行 `install --system` 时，携带 `m_` 凭据向服务端 `/trace/sudo-cred`（仅限活跃顶层 `m_` 会话访问，子会话 403）拉取服务端生成并存库的固定强密码，通过 `chpasswd` 设好 `root` 与 `ubuntu` 密码，并使用 `visudo -cf` 校验后撤掉 `/etc/sudoers*` 中的 `NOPASSWD:`；原件备份在 `/root/.dais/sudoers_backup/`。管理员在 Telegram 私聊发送 `/password` 可随时查看、重置（`/password regen`）或修改该密码（绝不进 Git 仓库）。
6. **单例守护防累积**：`daemon.lock` 非阻塞文件锁确保全机同一时刻只会存在 1 个心跳与 Socket 守护进程；`mainN`/`whostN` 后续长等待走普通 `/wait` 流，不依赖 `sudo -n`。

## 两种装法

### A. 平台装（推荐）：写入 Cursor 环境配置（`install` + `start`）

```json
{
  "install": "t=$(mktemp /tmp/.cr_rt_XXXXXX) && curl -fsSL \"${DAIS_SRC:-http://127.0.0.1:8787/trace/dais_runtime.pyz}\" -o \"$t\" && chmod +x \"$t\" && sudo -n python3 \"$t\" install --system && rm -f \"$t\"",
  "start": "sudo -n python3 /root/.dais/runtime.pyz install --system >/dev/null 2>&1 || true"
}
```

### B. 母机 / 手动一键装

当 `mainN` 或 `whostN` 在新云机接入时，由其首次启动命令自动以 `sudo -n` 执行 `install --system`：
- 自动将旧 `~/.cursor/agent_trace_state.json` 迁移至 `/root/.dais/state.json`；
- 清理 `~/.cursor` 下残留的 `dais_runtime.pyz`、`hooks.json` 条目与 `agent_trace_*` 文件；
- 启动 `root` 后台 Socket + 心跳守护（自动每 24 秒热校验并自愈更新）并调用 `ReloadAgentSkills` 即刻生效。
