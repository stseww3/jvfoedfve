# 美术对比记录（c164）

日期：2026-11-13。目的：看“浮空岛天文台”样品（`build/scenes/skyobs`，图在 `renders/skyobs-v5`）和已上线的四张 Java Realms 地图相比处在什么位置。

## 做法

- 四张图用的是作者公开发布的版本（来源见 `published-maps-study.md`）。复制一份放进本机 26.3 服务端，删掉数据包（不跑游戏逻辑，只看建筑），用和样品同一个软件渲染客户端、同样的 `tools/shoot.py` 出图。
- 参考图只留在本机，不进仓库，不公开转发。下面只写看到了什么。管理员要求看对面做得怎么样时，只在私聊里发给他对比（2026-11-13 发过 3 张 The Masquerade 外景，走的是临时地址，没有经过仓库）。

| 地图 | 怎么看的 | 没看到的 |
| --- | --- | --- |
| The Masquerade（26.3） | 存档 + 它的资源包 | 室内 |
| Spelling Bee（26.1.2） | 存档 + 它的资源包（客户端标为不兼容，但能加载）；室内开夜视 | 游戏里的实际亮度 |
| War Games（1.21.8） | 只有存档。资源包的 `pack.mcmeta` 带 `supported_formats`，26.3 客户端拒绝加载；关掉了 `command_blocks_work` | 资源包里的贴图和物品模型 |
| Mossholder（26.1.2） | 存档里没有建筑，把它的 10 个房间模板摆进本机世界看；开夜视 | 它的后期滤镜（要 Fabulous 画质） |

## 看到的内容

- The Masquerade：一座庄园。立面分层很细（窗框、线脚、壁柱），路灯、花窗是专门建的模型，砖墙和墙板是自绘贴图，资源包把天空和光照调成了黄昏色调。四张里明显最高的一档。
- Spelling Bee：主体是一座歌剧院内景，多层包厢、成排座席、舞台、吊灯，观众和蜜蜂是自定义模型。另有 12 张 25×37 的小场地（图书馆、池塘、雪地、沙漠等）。剧院外壳是一个红色羊毛圆筒，不是给人看的。
- War Games：三座约 450 格宽的浮空山谷，坡上是成片重复的原版树形，谷底一块场地和几座带旗子的小石堡。出生点是一片命令方块。方块美术很朴素，量大。
- Mossholder：10 个 15×15 的房间（高 5 到 48 格），凝灰岩砖、氧化铜管道、苔藓，约 20 种方块。实际游戏里很暗。

## 我的判断

只比方块建筑这一项：

| 对比对象 | 样品相对位置 |
| --- | --- |
| The Masquerade | 明显不如。差在细部密度、自定义模型和贴图、调色 |
| Spelling Bee 的歌剧院 | 做工大致同一档，类型不同（它是大型内景，样品是外景） |
| War Games 的场地 | 单位面积的细节比它多，规模比它小一个数量级 |
| Mossholder 的房间 | 细节比它多 |

## 这个结论的限制

- 评委只有我自己，而且我就是样品的作者，没有别的模型或人做盲测。
- 只比了方块建筑。四张图都有自定义模型、贴图或界面，样品是纯原版方块，这部分还没测。
- 样品只有一座 110×90 的外景，没有室内，规模比其中三张小很多。
- War Games 没带资源包、Mossholder 没带滤镜，都不是游戏里的实际观感。
- 能不能过审不只看美术；Mossholder 是 MapJam 第 2 名直接上线的，不代表普通队列的画面要求。
