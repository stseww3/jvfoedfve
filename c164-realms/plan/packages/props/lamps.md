# props/lamps 灯具

**目标**：方案 §7.3 灯具族、§3.2 灯光分级；细化稿 `plan/parts/A6-props.md` §2.1。一族电气时代灯具，统一「铸铁支架语 + 玻璃灯罩 + 黄铜灯头/开关键」。
**优先级**：P1（样板段入口+前庭、室内星厅都要；interiors/L7 已点名要 pendant/bracket/cage）。

**约束**
- 色板只走 `from scenes.obs.common.palette import mat`：杆/架=`iron`/`iron_dark`；灯头/颈/链=`old_copper`/`brass`/`brass_dark`；罩：乳白=`opal`、绿台灯=`phosphor`、信号=`signal_glow`；裸灯泡=`glow`。
- 16 像素一格，`px=scale`（细化稿 §1.6）。超 3 格的件取最小整数 scale（路灯 4 格→scale2）。
- 发光：罩/灯泡面 `emit=15, shade=False`（只那面亮）。**emit 面压小**——收成罩内一小粒暖灯丝/一圈灯口，不把整只罩面做成「发光贴纸」；emit 色与 A2 暖光（`#ffb45e`）对齐，保证亮区 <1/3（S3 预审 3）。真实照明由 A2 放隐形 `light` 方块；**摆放函数返回每盏灯的 light 坐标与级别**：一级 13–14（入口/路灯）、二级 9–10（壁灯）、三级 5–8（走道/台灯）。
- 拉伸件：`lamp_festoon` 电线 `between` 拉伸、贴图沿轴均匀；灯泡是单独件按固定间距摆（R1-1）。
- 实体预算：样板段每跨道具均 ≤20、整段 ≤120（与管线铁件共用）；室外共 1100。摆放函数返回实体数。

**件清单**（模型名 `prop_lamp_<件>` / 尺寸（格） / 挂法 / 光级，级别是 A2 给的数）
- `street` 铸铁路灯 1×5.06 落地 14 级：阶梯柱础+竖杆+梯档 iron，托盘 brass，球罩 opal。scale 2。前庭、大台阶。
- `bracket_a` / `bracket_b` 壁灯 墙 12 级：甲 卷涡托架（四分之一圆弧+圆环）上立乳白球罩，0.56×1.44×出墙 0.97；乙 铆钉墙板+方臂斜撑+接线盒下挂搪瓷伞罩裸灯泡，0.88×1.0×出墙 1.11。入口门两侧、室内。
- `cage_a` / `cage_b` 铁笼壁灯 墙 7 级：甲 圆底座+圆玻璃罩+十字交叉箍；乙 铆钉板+方玻璃罩+横档护栏。线管向上拐进墙。走道。
- `pendant_a` / `pendant_b` 吊灯 吊顶 8 级：甲 吊杆+黄铜托+扁乳白球罩，垂 1.53；乙 吊杆+搪瓷伞罩（enamel 外、opal 内）+裸灯泡，垂 1.08。灯头带旋钮。星厅、室内。
- `desk_green` 绿玻璃台灯 0.56×0.69 落地/台 6 级：brass 座和杆+phosphor 长罩。写字台。
- `signal` / `signal_off` 信号灯亮/灭 0.5×0.83 墙 不交光源：iron 壳+黄铜圈+红镜片+遮光檐。实体带标签 `c164_signal`，闪由 A8 换这两个模型。
- `uplight` 洗墙地灯 0.38×0.52 落地 8 级：A2 要的，离勒脚两格、朝墙斜上打光。
- 裸灯泡串 `festoon()`：`wire` 电线（一个拉伸件，整根平色）+`bulb` 灯泡（每格一只）+`hanger` 吊卡（两端和每四只灯泡一个）；每三只灯泡交一个 12 级光源。雨棚下、缆车站。

**交付物**：`build/scenes/obs/props/lamps.py`（+ 公用底座 `props/_kit.py`）；测试场景 `build/scenes/obs_props_lamps/`（`props.py`：`build_models/GALLERY/SCALE` + `shots.json`）。
**验收**：评审五项，重点「质感和像素」（近 3 格经得住、像素一致）、「风格和逻辑」（成族像一套、是电气时代、灯是暖的）、「明暗光色」（光级别对、不死黑）。视角：远看一排、近看单灯、和铸铁墙并排看接缝。
**版本**：**2 版比选（灯罩+支架母题）**。甲「乳白球罩+卷涡铸铁」偏古典；乙「棱锥搪瓷罩+直角铁架」偏工业。两版都覆盖 bracket/pendant/cage 三件，并排拍，评审挑。
**依赖**：palette（已有）、`kit.py`（本族先写）；A2 光源级别（摆放函数供料，不阻塞）；门两侧壁灯位、吊顶高用 R1 骨架数占位。**被依赖**：main 样板段、interiors 星厅、site 前庭。

  5. 线管不留断头：铁笼灯、信号灯的线管到头拐进墙（`_kit.wall_entry`）。
  6. 总场景里 `lamps.build()` 只放入口两侧壁灯（按骨架找主楼墙面，没有墙就不放）和前庭两盏路灯（离主墙面 8 格，A2）。别处的灯由建墙、建房间的线调 `lamps.place()` / `lamps.festoon()`，写法在 lamps.py 文件头。
  7. 公用底座 `props/_kit.py`（挂法、取材、铆钉、线管收口、玻璃球、灯泡）随本包交付，props 其他卡共用。
