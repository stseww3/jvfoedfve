# props/pneumatic 气动信筒

**来历**：`plan/round2.md` 丁项：「走廊和星厅里的气动信筒：黄铜的站口、沿墙和天花的玻璃管，小筒隔一阵从管里飞过去，到站『咚』一声。授时室、星图室、穹顶室、钟室各一个站口。」做 rec（c356），批 a6。细到哪一层照 `plan/fine.md`。
**是什么**：各屋之间递纸条的管子。纸条卷进小筒，小筒放进墙上的站口，气把它沿玻璃管送到要去的屋。彗星这一晚管子里一直有东西在飞。

## 一族（`build/scenes/obs/props/pneumatic.py`，模型名 `prop_pneu_*`）

每一件顺着自己的 +z 画，摆的时候 +z 顺着管走，+y 朝着所贴的面的外侧（墙、梁的侧面）。

| 件 | 样子 | 大小（像素） |
|---|---|---|
| `tube_<n>` | 一段玻璃管。玻璃只画四条棱（朝外两条用 `K.SHEEN`，贴墙两条低一级），里面飞的东西看得见。起头一只黄铜管箍坐在墙上的鞍座上（两颗螺钉、箍顶一颗紧定螺钉），离箍 1 像素一道绿环 | 管径 3，一段不超过 40；箍径 5 |
| `tube_<n>e` | 一条直段的最后一段，进弯头的那一头再加一道绿环（一个接头一道） | 同上 |
| `bend` | 黄铜弯头，把管子带进它贴着的面里；背上一只六角堵头（通管用） | 5.2 |
| `flange` | 管子正对着进天花、墙、梁靴的地方：法兰盘四颗螺钉、颈、绿环 | 盘径 6.4 |
| `plate_a1` | 号牌：米白小搪瓷牌，深色字 `A 1`（`K.letters`，全站那一套字），绿细边，两头各一颗铆钉，背后两道箍抱在管上。字小，单做成 `px=4` 的小模型（a6 13:15 的做法） | 5.75×3.25 |
| `station` | 站口，挂墙，手的高度：深色木背板（一圈线脚、四颗带槽的黄铜螺钉）；黄铜匣（门上圆窗、两只合页、把手，侧面四角铆钉，合页销，磨亮的门闩，盖板两颗螺钉）；匣顶的承口；匣下铁丝篮，里面两只到了的小筒，上面那只露出半截纸条；管右一只电铃（铃碗、锤、线圈）；篮右一只瓷钮（按了叫对面），电线上到铃、下到瓷套管进墙；管左黄铜框里一张线路卡（绿点是这条线，铅笔道是地名）；匣左粉笔记的今晚已发的数（一个五、两道：7） | 板 14×23，出墙 6.4 |
| `carrier` | 小筒：浅色毡套，两头黄铜帽 | 长 4，径 1.8 |

色环照 m3 的管表（`plan/parts/pipes.md`）：气（A）绿 `K.flat("verdigris", 1)`，环比管身大半个像素、宽 1 像素、离管箍 1 像素。号牌不画流向箭头：小筒两头都走。

## 会动的

- 一条直段一只小筒：平时藏在这一段靠站口的一头（匣里，或者弯头的铜里），飞到另一头又进了弯头或石头里。两只接着飞，看上去是一只筒走完全程，过一阵再回来。
- `MK.slide`，世界方向；一圈 `LOOP = 600` 刻（半分钟），第 60 刻出发，第 360 刻往回，第 417 刻落回站口。速度 0.3 格一刻（一秒六格，眼睛跟得上）。两只筒在一条 600 刻的链上，一圈 4 条命令，最忙一刻 4 条。
- 声音是声音线（sound c361）的：它读这里的 `LINES`、`lands(key)`、`LOOP`，到站那一刻一声 `thump`、4 刻后一声 `ting`，以后加线自动跟。**这三个名字别改。**
- `motion/travel`（a2）还没进树；它能带一只实体拐弯，进了以后可以换成一只筒走全程，屋里看上去一样。

## 三层

- 远：室内的东西，没有 60 格的事。整间屋里读得出的是「墩上一只铜匣、一根玻璃管上梁、沿梁横过天花」。
- 中（10 格）：背板、铜匣、门和圆窗、篮和筒、电铃、瓷钮、线路卡、号牌、承口；立管两道管箍、法兰；横管五道管箍、两只弯头；每道箍旁一道绿环。
- 近（2 格）：号牌的字 `A 1`、粉笔的数、卡上的铅笔道、带槽的螺钉头、磨亮的门闩和把手、合页、铆钉、篮里筒口露出的纸条、鞍座的螺钉和箍顶的紧定螺钉、弯头的堵头。

## 数

A 1 一条线 14 个展示实体（站口 1、号牌 1、玻璃 7、法兰 1、弯头 2、筒 2），都在近档（`VIEW = M.NEAR`），不占方块、不带光源、不挡路（最出墙 6.4 像素，在窗台高的墩面上；管和箍出墙 5 像素以内）。亮度写死：族 `(0, 9)`，小筒 `(0, 12)`，号牌 `(0, 10)`：管子走在屋里最暗的地方，吃所在格的光就看不见了。

## 接口

```python
from scenes.obs.props import pneumatic
n += pneumatic.build(canvas, origin)                 # 主场景：LINES 里房间进了树的每一条线
n += pneumatic.line(canvas, "time_room", origin)     # 单摆一条
n += pneumatic.carrier(canvas, pos, way="east")      # 一只不动的小筒（放在桌上；测试场景里放在管里出图用）
pneumatic.lands("time_room")                         # (落回站口的刻, 位置)：给声音线
```

加一条线：在 `LINES` 里加一个返回 `dict(number, station, plate, runs, sound)` 的函数；`runs` 是一串直段 `dict(a, b, out, start="bend", end="bend"|"flange", rest, far)`，`a`、`b` 是管轴上的两点，`out` 是所贴的面朝哪边。

## 默认（先交，谁有意见再改）

1. 用 `MK.slide` 一段一只筒，不等 `travel`。
2. 站口的号牌只写管号 `A 1`，不挂机器铭牌：铭牌 `No. 66` 是鼓风机的（见下）。
3. 粉笔的数是用小盒子摆的 7 道。a1 的 `materials/traces`（痕迹统一做法，14:00 前出）出来以后，粉笔记号换成他那一套的形状；门闩、把手的磨亮现在是亮一级的黄铜，到时候看要不要换 `T.worn`。
4. 字从 `K.letters` 取；号牌 `px=4`，检查会提醒「不是 16 像素一格」，是有意的（a6 13:15）。
