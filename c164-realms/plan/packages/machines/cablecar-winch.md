# machines/cablecar-winch 缆车和卷扬机

**目标**：方案 §7.2「缆车和卷扬机」、§5.3 缆车站；细化稿 §2.7。木壳铁架亮窗车厢、卷扬机大轮和钢缆。**V1 到站（抬头）+ V12**。
**优先级**：P2（依赖 A4 缆车站/栈桥；可占位先做车厢/卷扬机）。

**约束**
- 坐标：`S.CABLE_STATION`=(65,-40,81,-26)（下平台北半、出生点）；钢缆往下进云（A4 栈桥方向）。
- 色板：车厢壳 `dark_wood`+架 `iron`；亮窗 `glow`（emit 收小）；卷筒/导轮/钢缆 `iron`。
- 16 像素一格，`px=scale`：车厢~2.5 格→scale2、卷筒 ⌀3→scale2、导轮 scale1、钢缆 `between`。
- 发光：车厢亮窗（二级，返回 light）；亮区<1/3。
- 实体预算：本件 ≈40；`build()` 返回实体数。

**件清单**：`mach_cable_car` 车厢 2×2×2.5（木壳铁架、亮窗、走人门洞留给 A4 站台）；`mach_cable_drum` 卷扬大轮/卷筒 ⌀3（`kit.flywheel` 宽卷筒变体+缆槽，**拆件标水平轴交 A8**）；`mach_cable_sheave` 导轮组 ⌀1×2–3（转向钢缆，可转）；`mach_cable_rope` 钢缆（`between` 拉伸，往下进云）。
**交付物**：`build/scenes/obs/machines/cable.py`（+ `_kit.py` 的 `flywheel`）；测试场景 `build/scenes/obs_mach_cablecar_winch/`（盒子站台占位；`shots.json` 车厢近景、卷扬机、抬头 V1 角度）。
**验收**：五项，重点「第一眼/风格逻辑」（V1 到站一眼看懂缆车、卷扬机钢缆有来去、是电气时代）、「明暗光色」（车厢亮窗暖点、亮区<1/3）、「质感像素」（木壳铁架/缆槽近看）。视角：车厢近景、卷扬机、V1 抬头到站。
**版本**：1 版。
**依赖**：skeleton、palette；**A4** 缆车站/雨棚/栈桥/站台（可占位）；A8 卷筒/导轮（供料）。**被依赖**：看板 V1/V12。
**记录**：A5 领（牵头）。默认：车厢停站内、卷扬机在站后、钢缆沿栈桥下行。退回改法逐条记此。
