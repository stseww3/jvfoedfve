# machines/recorders 记录仪器

**目标**：方案 §7.2「记录仪器」、§8 授时室；细化稿 §2.10。转鼓记录仪（纸转笔画）、电报机和纸带、世界时钟墙。**V10 授时室（整面仪表墙）**。
**优先级**：P2（墙面用 A1 面板方块，依赖 A1；房间依赖 interiors `timeroom`；可占位）。

**约束**
- 坐标：授时室（interiors `timeroom`，北翼主层 12×16），仪器靠墙/台。
- 色板：记录鼓/电报 `brass`+`dark_wood` 座；纸/纸带 `cream`；小钟圈 `brass`；传送管口 `brass`+`old_copper`。
- 16 像素一格，`px=scale`：记录仪 scale1–2、小件 scale1。
- 发光：记录灯/指示小灯（三级，返回 light）；示波线/纸带/指示灯闪用动画贴图（A1+A8），不占实体。
- 实体预算：本件 ≈25（**整面墙是 A1 方块不占实体**，A5 只出转鼓/电报/小钟圈等立体件）；`build()` 返回实体数。

**件清单**：`mach_rec_drum` 转鼓记录仪 1.5×1×1.5（记录鼓 `tube` 慢转、cream 纸、记录笔横移，**拆件标鼓轴+笔移交 A8**；纸带轨迹动画贴图）；`mach_rec_telegraph` 电报机+纸带（电报键/响铃 + 吐纸带，纸带走动画贴图）；`mach_rec_clockwall` 世界时钟墙（**墙面用 A1 面板方块**；A5 只做墙前几个立体小钟圈/铭牌，走针）；`mach_rec_tube` 气动传送管口+弯头（干管走 A6 `pipe_`）。
**交付物**：`build/scenes/obs/machines/rec.py`（+ `_kit.py` 的 `drum/clock_face`）；测试场景 `build/scenes/obs_mach_recorders/`（盒子授时室 + A1 面板方块占位；`shots.json` 整面墙、转鼓/电报近景、V10 角度）。
**验收**：五项，重点「风格逻辑」（看得懂在记录/报时：鼓在转纸在走、电报吐带、时钟墙、是电气时代；墙用面板方块成整面）、「质感像素」（转鼓/电报/小钟近看、与 A1 面板墙接得上）。视角：整面仪表墙（V10）、转鼓/电报近景。
**版本**：1 版。
**依赖**：skeleton、palette；**A1** 面板方块（仪表墙/时钟墙）+示波/纸带/指示灯动画贴图、**interiors** `timeroom` 布局、**A6** 气动管干管；A8 鼓/笔/纸带（供料）。**被依赖**：interiors `timeroom`、看板 V10。
**记录**：A5 领（牵头）。默认：转鼓靠台、电报在侧、时钟墙占一面、A5 不重复做方块能做的面。退回改法逐条记此。

## 记录（snow / c264，11-16 接手）

**这一轮做了什么**。A5 停机后这张卡一直空着，m2（c292）接手授时室时只能用盒子占位。这一轮把它做出来，**只做授时室还需要的那三件**：`mach_rec_clockwall` 不做了——总监 #529 定的：世界时钟房间自己做五只停着的子钟，走针那一条从卡上划掉。

模块 `build/scenes/obs/machines/recorders.py`（不是卡上写的 `rec.py`：命名跟 `clock.py`、`orrery.py` 一类的整词），场景 `build/scenes/obs_mach_recorders/`（11 个机位）。

**尺寸与画法**
- 鼓 1.5 × 1.0 × 1.5 格（卡上的数），电报 1.0 × 0.8 × 0.75，传送管径 0.16 格、管体直径 0.5。
- 模型按**模型单位**画（16 单位 = 1 格，`M.display` 就是除 16），`px = 1`，所以贴图恒 16 像素/格，和方块、别的包一个密度。
- 色板只用 `brass` / `brass_dark` / `iron` / `iron_dark` / `dark_wood` / `cream` / `porcelain`，`strays()` 过。

**件的画法与读法**
- `mach_rec_drum` 转鼓记录仪：深木底座（0.44 格高）上一只**横放的鼓，直径 1.0 格、宽 1.19 格**，两端黄铜法兰、中间 cream 图纸，图上有一道深一阶的笔迹；鼓上方是滑杆和记录笔，后面是供纸卷，前面是抽屉，东侧立柱外有一只手摇曲柄。第一稿鼓只 0.33 格粗、底座占大头，图上读成“柜子上放个白盒子”；把鼓放大成主角、底座压到 0.44 格之后才读成记录仪（两稿都出了图对比）。
- `mach_rec_telegraph` 电报机：木底座、铁线圈箱黄铜箍两道、两根立柱托起衔铁（上面有止档和调整螺钉），东端一只 cream 纸卷插在黄铜叉上、纸带向东引出，西端两个接线柱（给旁边的电报键）。
- `mach_rec_tube` 气动传送管口：铁背板贴墩、黄铜管体横出墙面、载物门带把手、门上方一块瓷面指数盘（黄铜圈、四道刻度、一根不动的指针）。管子从终端脚底（台脚以上 1.2 格）一直跑到天花板（默认 6.0 格以上，即授时室的 y 14）。**管子不能塞进管体那个模型里**：一个模型最多跨 3 格（`model.shift()` 的 48 单位限制），所以管子是单独的 `mach_rec_pipe`，按 3 格一节往上叠（每节 `scale=(1, span/3, 1)`），拼接处不出盖、16 像素一格不糊。`tube(top=)` 可以改天花板的 y。

**锚点（给 A8，也是给 m2 的调用口径）**
- 三件都按 **m2 自己那张 `timeroom.SLOTS`** 接：`drum (9.5, 8.0, −23.5) south`、`telegraph (6.5, 8.0, −23.5) south`、`tube (14.0, 8.0, −9.5) west`（他的分支 `cursor/c164-m2-timeroom-80c9` @ `a14a1f37`）。`pos` 的 y 是**件站的那个面**（台顶 8.0）——`pos` 加多少由我的函数自己算，他不用做算术。
- `mach_rec_drum` 的锚点是**鼓的轴心**（底座面往上 0.95 格），轴沿 x：绕 x 转就是鼓在转。
- `mach_rec_telegraph` 的锚点是**衔铁枢轴**（底座面往上 0.75 格），绕 x 小角度摆就是衔铁在响。
- 这一版**全部静止**（总监 #505）；拆件和锚点都留好了，A8 接的时候只换实体变换，不改房间。

**发光**：鼓的图灯交给 A2（`_kit` 式 `offer_lights` → `sky/_lightkit.take`），三级 7；`_lightkit` 不在树里时退回原地摆 `light` 方块（不覆盖已有方块）。

**测试场景**：盒子授时室（x 2..13、z −25..−7、脚踩 y 7、顶棚 14、南墙开门洞），按 m2 的格子摆一张台面（x 6..10，台顶 y 9），三件按 `SLOTS` 落在台上和东墙墩上。**场景自己放一盏 14 级的工作灯**（`main/shell` 的测试场景也这么做）——不然盒子里全黑，看不出材质；房间真身的光由 `sky/_lightkit` 给。

**自查**：`check.py --scene obs_mach_recorders` PASS 0 失败 1 黄（flatwall 6 面：盒子场景的墙，本来就是平的）。`motion` 一项 PASS（什么都不动）。3 个实体。`selfshots --verify` 11/11。

**已知最弱三处**（交评审，本轮未改）
1. `v10_door`·从门口看：三件在 16 格长的房间尽头只有几个像素高，读不出是什么机器，只读得出“台上有东西在发光”。这是 V10 机位决定的（整面仪表墙才是主角，机器是配角），要改只能把机器做大，可那就挡面板墙了。
2. `drum`·鼓面：cream 图纸现在是一整片平色加一道笔迹，八格外读成一张白纸筒；纸的纤维感没有（怕加噪点读成砂纸，先不加）。
3. `telegraph`·近看：线圈箱和衔铁的比例偏“盒子”，黄铜箍只有两道，八格外读成“小木盒上两块铜”；要更像电报机得加铃铛和杠杆，实体预算还够，等评审定。

**待真机**：记录灯在真机上亮不亮（离线图里 7 级几乎看不出）；鼓和纸带以后转起来时贴图会不会走样。
