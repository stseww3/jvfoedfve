## 1. 你怎么用

```python
from scenes.obs.machines import batteryboard as BB

n += BB.place(canvas, origin)                                   # 板：8 个实体（三块板、三根指针、两根上楼的管）
n += BB.run(canvas, "west", south, hangers, origin)             # 西翼那一对铜排，从板上的夹子一直向南到 z = south
n += BB.run(canvas, "east", south, hangers, origin)             # 东翼那一对
```

- `hangers`：一串 z，每个 z 上一只吊架（铁杆从梁底吊下来，白瓷瓶，铜夹抱住两根排）。梁在 z −22、−18、−14、−10 这四行，吊架的 z 就是 −21.5、−17.5、−13.5、−9.5（格子中心）。铜排按吊架分段，每段取自己那一格的光。
- 不想从梁上吊、想用木门架托：不传 `hangers`，自己摆瓷瓶；单根排用 `BB.bus(canvas, a, b, origin)`（a、b 是排的中线两端，只能南北走），吊架单摆用 `BB.hanger(canvas, pos, origin)`。
- 模型名：`mach_bboard_panel_west/main/east`、`mach_bboard_riser`、`mach_bboard_bar_east/west`、`mach_bboard_hanger_east/west`，指针是 `mach_board_needle`（和发电房那块板共用）。都在 `machines` 这条线的 `models()` 里，你的 `models()` 不用管。
- 实体：板 8 个；一侧铜排走到 z −9，四只吊架，是 2×4 段 + 4 = 12 个；两侧 24 个。合计 32 个。
- 在动的：中板电流表的指针，慢摆（13 秒一个来回，左右各 15°）；两翼的表针轻颤。卡上「至少一处在动」这一条板已经占了，你再加气泡随你。

## 4. 光

- 展示实体的光只取实体所在的那一格。板的八个件全站在 `BB.STAND` 这一格（中板前面的空气里），所以**板亮不亮只看 (8, 3, −24) 这一格的光级**。要 6 到 8 级。
- 办法：板顶墙上那盏铁笼灯的光源放在 (8, 4, −24)（正上方一格），8 级，板面就是 7 级。光源经 `sky/_lightkit` 交出去，归你的灯。我的替身场景就是这么放的（另两盏在第一、第三道梁下的走道上，8 级、7 级）。
- 板自己发光的只有三只表盘上的夜光绿刻度（每只八个像素点），不要光源。没有指示灯，没有加新的光色。
- 铜排每段站在自己那一段的中点，取那一格的光；吊架取吊点那一格的。

## 5. 板上有什么（给你写卡的记录和对机位用）

- 中板：上面是蓄电池的电流表（指针在刻度正中附近慢摆：充电、放电），下面是充放电换向开关：两片刀中间铰接，现在扳在上面，下面一副夹口空着。
- 两翼：上面一只表（西翼电压表 V，东翼电流表 A），中间是铜排的夹子（一块铜座、两根排的头、一条压板三颗螺栓），下面一把双刀闸刀，都合着。
- 板顶：两根铜母排架在白瓷柱上，后面一根高一些；两根铁管从板后升到楼板，管脚一只铜接头，楼板下一只铁箍。
- 红线 8：没有十字。闸刀的木把横在两片刀的端头成「Π」；板上没有「+」「−」号，文字只有表盘上的 V、A。
- `int_board`、`int_aisle` 里「两只绿表加一根横把手像一张脸」（stair 草图第 6 条）：现在是三只表一排，换向开关的把手扳在上面、紧贴中间那只表的下沿，不成脸。出图以后还像的话我改。

## 6. 默认和没定的

1. 板的位置、宽度照 stair 的草稿（北墙正中，x 5.5..10.5，离墙 6 像素，铁腿）。你要挪板，告诉我新的中轴和墙面，我这边是两个数。
2. 铜排默认从梁上吊（吊架），不要你的架子出木门架；你要用门架托也行（第 1 节）。
3. 铜排一侧是一对（同一极的两片并排），两侧是正负两极。只想走一根：`BB.bus()` 单摆，夹子上另一根的头我去掉，说一声。
4. 排只会南北走。要拐弯、要竖着下到缸顶的连接条，这一版没有；连接条我建议算在你的缸模型里（铅条色，短）。要我做就说。
