# machines/radiomast 无线电桅杆

**目标**：方案 §7.2「无线电桅杆」、§4 东北角；细化稿 §2.8。铁格构桅杆、拉索、瓷瓶、顶灯闪红、通报时塔的天线。**V1、V12 天际线「一竖」**。
**优先级**：P2（依赖 A4 石台；格构/拉索可占位先做）。

**约束**
- 坐标：`S.RADIO_MAST` foot=(23,-40)、height=62；天线通向报时塔（`S.CLOCK_*`）。石台归 A4。
- 色板：格构/天线/拉索 `iron`（细）；瓷瓶 `porcelain`；顶灯 `signal_glow`。
- 16 像素一格，`px=scale`：**一节格构 ~3 格→scale1、沿 +y 分节叠放到 62 格**；拉索/天线 `between` 拉伸。
- 发光：顶灯慢闪（动画贴图 A1+计时 A8）；返回 light（警示单列）。
- 实体预算：本件 ≈30（按节数 + 少量拉索 + 顶灯 1）；`build()` 返回实体数。**62 格高务必分节+拉伸，不做整条巨件**。

**件清单**：`mach_mast_segment` 格构一节 2×2×3（四 `beam` 腿+`rod` 斜撑，叠放）；`mach_mast_guy` 拉索（`between`，三向下拉到石台/屋面）；`mach_mast_insulator` 瓷瓶绝缘子（拉索端/馈线，大号 `porcelain`）；`mach_mast_light` 顶灯 ⌀0.5（**闪，交 A1+A8**）；`mach_mast_antenna` 天线/馈线（`between`，桅顶到报时塔）。
**交付物**：`build/scenes/obs/machines/mast.py`（+ `_kit.py` 的 `lattice`）；测试场景 `build/scenes/obs_mach_radiomast/`（石台占位；`shots.json` 全高远看、格构近看、天际线 V1 角度）。
**验收**：五项，重点「轮廓」（天际线「一竖」、缩邮票大认得出）、「质感像素」（格构斜撑/铆点近看、分节接缝不乱）、「风格逻辑」（电气时代无线电桅、拉索瓷瓶有来去、无火箭/雷达禁用物）。视角：全高远看、格构近看、V1/V12 天际线。
**版本**：1 版。
**依赖**：skeleton、palette；**A4** 石台（可占位）、**A1** 顶灯闪动画贴图；A8 顶灯计时（供料）。**被依赖**：看板 V1/V12。
**记录**：A5 领（牵头）。默认：方截面四腿格构、每 3 格一节、拉索三向 120°、顶灯单点红闪。退回改法逐条记此。
