# site/outbuildings 子午仪小屋＋水塔＋气象站＋观景台

- 类别：site　优先级：P2
- 目标：ART-PLAN §4、§5.3——北坡/西北角/南坡的几座小附属建筑外壳与平台：子午仪小屋（屋顶南北开缝、黄铜子午线从门出）、铁架水塔、气象站（百叶箱＋风杆台）、南观景台/落日平台的三脚架观景位。
- 约束：
  - 子午仪小屋：中心 (35,−30)，9×9＝x 31..39 / z −34..−26（`MERIDIAN_HUT`）；屋顶沿南北开一条缝，门朝南 x=35 z=−26，`BRASS_INLAY` 子午线从门出接前庭（site/court 的 x=35 线）。
