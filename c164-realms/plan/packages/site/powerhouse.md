# site/powerhouse 发电房外壳＋烟囱＋管桥（2 版比选）

- 类别：site　优先级：P2　**比选：2 版**
- 目标：ART-PLAN §5.3、§4——下平台南端工业味最重的发电房外壳：凝灰岩砖墙、铁桁架、锯齿形天窗、大拱窗透炉火橙红；铁箍砖烟囱冒烟；管桥从屋顶架到上平台。V6 主角。
- 约束：
  - box x 67..89、z 20..42（22×22）、墙高 10、烟囱高 30（`POWER_HOUSE`），站在下平台上：脚踩 y=−6（落差 6，总监 #18763），墙从 y=−6 起算。
  - 墙 `TUFF_BRICK`；铁构 `IRON_RIVETED`/`IRON_GRATE`；拱窗洞留给炉火橙红窗（A1 窗＋A2 隐形光／A5 炉门）；烟囱铁箍 `IRON_RIVETED`；管桥铁桁架＋蒸汽管（管由 A6，我留桥身与挂点）。
  - 炉火窗要小（c199 预审第 5 条）：比入口暗一档，面积算进 A2 那条“亮区不超过画面三分之一”里；颜色是炉膛里烧出来的橙红，不是信号红，也不是一片泛暖。V1 里它在画面左下，不能比入口和那排亮窗先被看到。
  - 留在下平台南端，位置不变（总监 #18763 定了，可以盖）。下平台的铺地归 site/stair，山体的石面在 y=−7。
  - 只做外壳：蒸汽机/发电机/配电板（A5）、管线道具（A6）留洞和挂点。烟冒烟（粒子）归 A8。
  - 展示实体 0（外壳全方块）。
