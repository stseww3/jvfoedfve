# site/terrain 山体轮廓与云线＋西侧落日平台

- 类别：site　优先级：P2
- 目标：ART-PLAN §4——山顶只露一截、往下进云的山体轮廓；云线/云海的方块版与关云兜底；圆厅西侧落日平台外壳。V1 逆光剪影、V11 四分之三侧面（余晖在左）、V12 鸟瞰的底。
- 约束：
  - 地形**只做轮廓不抢主楼**（红线）；山体用原版 石头/凝灰岩/深板岩/雪（§6.2），不重画。山顶约 110×110（`SITE_SPAN`），上平台 y=0、下平台 y=−9，外圈往下收进云。
  - 落日平台：圆心 (−9,0) 半径 20（`SUNSET_PLATFORM`）半圆，贴圆厅西侧落地圆柱外缘，不进 A3 的圆（圆心(4,0)外径13）；灰白石铺地＋深板岩勒脚＋灰白石栏杆。
  - 云线与 A2 cloudsea 对齐（P2、3 做法比选）；`CLOUD` 角色＋cloud 五色阶（A0 已批、c188 加表）到位前用占位；山体＋雾要保证玩家关云也成立（§10）。西向借余晖压一道亮边让云浮起（c190 预审第 3 点）。
  - 展示实体≈0（植被/雪用方块；高山植被少量）。
- 交付物：`build/scenes/obs/site/terrain.py`（`ORDER=10`，先铺）、可拆 `cloudline.py`；测试场景 `obs_site_terrain`（含 V1/V11/V12 近似视角）。
- 验收：V1/V11/V12；山体是剪影不是主角；关云与开云两种都成立；邮票级认得出“一横一圆一竖”托在云上。
  - 加一张 V1 剪影邮票（c199 预审第 1 条）：山顶线和云线的高低在 V1 的邮票上调，不在近景里调；山顶的轮廓线压在主楼檐口那一横以下，主楼背后不出零碎起伏，云线不横切穹顶和塔身。
  - V1 的站位在东西轴线上的到站台（总监 #16242）。邮票上要认得出一横、一圆、一竖和一排亮窗，彗星在穹顶正上方。
  - 下平台标高、进深和落差在重定（见 `plan/parts/A4-site.md` 第 2 节），山体东坡跟着它走，定了再盖。
- 版本：1 版（云做法随 A2 cloudsea 比选定）。
- 依赖：A2 cloud 角色/色阶、mood 雾参数；主楼 massing 定剪影。被依赖：V1/V11/V12 整体观感。
- 记录：
  - 第一稿（3e245b97，a4=c221 接 c192）：`terrain.py`（ORDER=10）。做法：
    - 山体用高程图外壳——每列只从地表往下补到最低邻列、封住台阶，鸟瞰以下掏空（从不露底），块数小。地表＝上平台 y=−1 的平台，往外按 0.72/格下坡＋fbm 皴皱进云；全程 ≤−1，不抢主楼（红线）。山体只做西/北/南三面，东缘到court东唇（x=61）止，东坡/大台阶/下平台落差等 A0 重定再盖。
    - 石材只用占用表：tuff＋deepslate 两族混（`ROCK_HIGH`/`ROCK_LOW` 按 y 分上下），混色保证无平面（flatwall 过）。原版 石头/安山岩/雪 不在表里，没用；要更自然等 A0/materials 把它们加进表再丰富。
    - 云海＝五色阶 `CLOUD` 方块平铺，绕山（石头露头处不铺），西缘偏亮取余晖；A2 cloudsea 到位前的占位/关云兜底。
    - 西侧落日平台：灰白石铺地＋深板岩勒脚（带扶壁，防平面）＋灰白石柱铁栏，避开 A3 圆厅圆（圆心(4,0) r13）。
    - 测试场景 `obs_site_terrain`（site+main+sky，V1到站/剪影邮票、V11落日、V12鸟瞰、落日平台、云线、南北坡共 8 机位）。`check.py --scene obs_site_terrain` 过；唯一 flatwall WARN 是主楼白模（main massing，占位），terrain 自身 0 警告；块全在占用表。离线自查图 renders/obs_site_terrain/（8 张，3e245b97）。
