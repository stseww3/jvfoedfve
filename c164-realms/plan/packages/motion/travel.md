| 怎么挪实体 | 坐着的人的镜头 |
| --- | --- |
| 每刻 `tp` 一次（`teleport_duration` 0、1、3 都一样） | 一刻一跳，20 赫兹的顿。**不用** |
| 20 刻 `tp` 一次，`teleport_duration` 20 | 逐帧滑，但接缝上三四成会顿一刻 |
| 20 刻一次，`teleport_duration` 21 | 全程匀，没有站住的帧。**用这个：N 刻一次，插值 N+1** |
| 20 刻一次，23 | 更匀，但晚三刻到、起步慢 |
| 59 刻一次，59 | 全程匀 |

四趟人都一直在座上（挪座位不会把人甩下来）；旁观的客户端里人和座位同位一起走。两件要绕开的：`tp` 一个骑着的**人**会让他下座；人按潜行键会下车。

## 2. 怎么做的

- **车是真的在走的实体**。一辆车的所有件都站在同一个点上（这辆车两根轴中间、轨顶上那个点），各自的偏移写在变换里；车的朝向写在实体的 `Rotation` 上（偏航加俯仰），跟着线走。所以挪一辆车只要一条命令：`tp @e[tag=t.<名>.<车>] x y z yaw pitch`，件再多也是一条。客户端按 `teleport_duration` 把位置和朝向一起插值。
- **一步 20 刻（`step`），插值 21 刻**，每一步瞄着 21 刻以后车该到的地方。位置都是绝对坐标，丢了一步（区块没载入）下一步自己回到正确的位置，不会越走越偏，也不会散架。
- **座位是单独的实体**（光的 `item_display`，不带模型），一个座位一个，常驻，跟着车每步一条 `tp`。人骑在座位上，座位和车身用的是同一个机制、同一刻的命令，所以人和车不会错开。骑着人的座位被人带下线（原版：人下线时坐骑跟着存进他的档）以后，每一趟发车前按号补齐。
- **轮子跟着路程转**：转角 = 走过的路程 ÷ 半径，照时刻表算，车停轮停、车退轮反转；另一条 `data merge`，和别的会转的件一样靠客户端插值。
- **时刻表**是一张「第几刻、基准点在线上的路程」的表，工具把各行连成一条平滑的线（单调的三次插值：不会倒退、不会冲过头，停站的地方速度自己降到 0）。整趟是循环里的一条链：到点自己发车；`call=True` 的（火车）另有一个 `go`，车在起点歇着的时候可以提前发车。
- 不花每刻都跑的函数。火车一趟（两辆车、11 个座位、五副轮对）平均每刻 1 条命令上下。

## 3. 接口

```python
from scenes.obs.motion import _kit as MK
from scenes.obs.site import _rail as RAIL                # a4 的线（总装 cc2329ec）：路程 s 从站内车挡往外数

line = MK.route(RAIL.at, 0.0, RAIL.LENGTH)                 # 线：一个「路程 → 点」的函数（返回带 .x .y .z 的东西或三个数）和路程的头尾；
                                                           # 也可以直接给一串点 MK.route([(x, y, z), ...])，路程就是沿着点量的长度；
                                                           # 首尾相接的环线加 closed=True
train = MK.travel(canvas, "train", line,
                  table=[(0, RAIL.START), (940, RAIL.STOP), (1340, RAIL.STOP), (2280, RAIL.START)],
                                                           # 时刻表：(第几刻, 基准点在线上的路程)。两行路程一样就是停着；
                                                           # 中间可以多给几行来定各段的快慢，工具把它们连成一条平滑的线
                                                           # （起步、进站自己慢下来，不用另给加速度）。头一行是第 0 刻，末一行回到头一行的路程
                  cycle=3000,                              # 多少刻一趟
                  home=RAIL.STOP,                          # 你摆车的时候，基准点在线上的路程（一般是停在站里的样子）
                  step=20,                                 # 一步几刻（插值是 step + 1）
                  call=True)                               # True：自己一条链，带 go（火车）；不写：和同周期的别的件合用一条链

coach = train.car("coach", at=0.0, axles=(-1.0, 1.0))      # 这辆车的正中离列车基准点多远（朝路程增加的方向为正）；两根轴离车正中多远
loco = train.car("loco", at=4.0, axles=(-1.0, 1.0))        # a4 的路程往山下数，机车在下坡一头，所以是正数

n += canvas.add_entity(x, y, z, M.display(body, ...))      # 照车停在 home 的样子摆在场景里，和现在摆法一样
coach.carry(canvas)                                        # 刚摆的这一件跟这辆车走（entity=、model= 和 spin 一样）
n += canvas.add_entity(x, y, z, M.display(wheelset, ...))  # 轮对：实体摆在轴心上（和 spin 的规矩一样）
coach.roll(canvas, "z", 0.45)                              # 跟车走，并且按路程滚：轴（"x"、"-z" 或世界方向）、半径；齿轮同；反着转的给负半径
coach.seat((x, y, z))                                      # 一个座位：车停在 home 时人坐的那个点（场景坐标，y 取凳面；人的眼睛比它高 1.02）

train.run("playsound ... {x} {y} {z} ...", at=[0, 40], pos=(x, y, z), car="loco")
                                                           # 这一趟的第几刻跑一条命令。pos 是车停在 home 时的一个点（烟囱口、汽笛）；
                                                           # 写进函数的是那一刻这个点走到了哪里。不带 pos 就是一条普通命令（放屏障、标题）
train.where(tick, pos, car="loco")                         # 同一个算法：那一刻这个点在哪（场景坐标）
train.tick(RAIL.S_FOOT)                                    # 基准点头一次走到线上这个路程是第几刻；第二次 nth=1
train.at(tick)                                             # 那一刻基准点的路程
train.stops                                                # [(停稳的刻, 再开的刻, 路程), ...]
train.beats(0.45, per_turn=2)                              # 这么大的轮每转半圈的那些刻（排汽的拍子，跟着加速减速）
train.cycle, train.step
```

数据包里（`<ns>` 是数据包的命名空间，`<场景>` 是总场景名）：

| 函数或分数 | 干什么 |
| --- | --- |
| `<ns>:<场景>-motion/<名>/board` | **以玩家身份调**：给他找一个空座位坐上（离 0 号座位最近的空座）。已经骑着的、没有空座的，什么也不做 |
| `<ns>:<场景>-motion/<名>/go` | 车在起点歇着（分数是 0）就立刻发这一趟；在路上就什么也不做。只有 `call=True` 的有 |
| 分数 `#t.<名>`（记分项 `c164m`） | 0 在起点歇着；1 第一段在走（上行）；2 第一站停着；3 第二段在走（下行）…… |

标签：整列车 `t.<名>`；一辆车的件 `t.<名>.<车>`；座位 `t.<名>.seat` 和 `t.<名>.s0`、`s1`……。

## 4. 给各家的话

- **cable、m1（车）**：车照停在站里的样子摆，`carry`、`roll`、`seat` 三样。同一辆车里的件随便多少，挪车的命令还是一条；轮对一副一条 `data merge`（每五六刻一次）。车上的件不要再登记 `spin`、`blink` 这些（它们按位置找实体，车一走就找不到）；炉火、车头灯的闪用贴图动画。连杆（曲柄半径、杆长、相位）和不跟车走、只跟着路程转的件（卷筒、导向轮、托辊）是下一步：`coach.rod(...)`、`train.turns(canvas, 轴, 半径)`，先把数留着。车的件请写明 `brightness`：光是在实体站的那个点上取的，车在云里的时候那个点在方块里，是黑的。
- **a4（线）**：`_rail.py` 的 `at(s)`、`STOP`、`START`、`LENGTH` 我直接用，不另画。车身的朝向取的是前后两根轴所在两点的连线（和你的 `pose()` 一个算法），过折点、过坡顶是慢慢转过去的。各段的快慢（你提的站内 1.5、陡坡 2.5、石桥 4.5 格每秒）写成时刻表里的几行。**坐着的人的头不能穿过实心方块**（会窒息、画面会被方块的贴图盖住）：云里那一段沿线留一条净空，座位以上 2 格、左右各 1.5 格，或者用不挡人的方块。
- **mast、outb（开场）**：新来的人 `execute as <他> run function …/train/board` 就上车了，车在哪他就在哪上。车在起点歇着时调一次 `…/train/go` 立刻发车。到站对骑着的人 `ride @s dismount` 再送到站台；**座位不要 kill**（常驻的，kill 了下一趟发车前才补）。出云、到站的刻用 `train.tick(路程)`、`train.stops[0][0]`，命令用 `train.run(...)` 挂在这一趟上。沿线的区块由导出强制加载（outb 12:40 说的，范围读 `_rail.py`），函数里不自己 `forceload`。`c164map:back` 的两条（脚低于 y 170、踩着云）对骑着的人要放过。
- **smoke、sound**：烟、汽、汽笛、排汽声用 `train.run(..., pos=烟囱口, car="loco")`，坐标是生成的时候照时刻表算好写死的，线改了重新生成就跟着改。不要用 `execute at @e[tag=…]`：服务端的实体比客户端画出来的车超前最多 21 刻（两格）。排汽的拍子用 `train.beats(驱动轮半径, per_turn=2)`。车在跑、在停、在云里：照 `train.stops` 和 `train.tick(出云处的路程)` 分。
- **lamps**：信号臂的落和回先用两条 `train.run("data merge …", at=…)`，时刻读 `train.stops`。
- **cloud（鸟群）、rec（小筒）、ashlar（煤斗车）**：不带 `call=True`，`cycle` 就是来回一趟或者一圈的刻数；一只鸟、一只小筒是一辆只有一件的车（`axles` 不写）。
