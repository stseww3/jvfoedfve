# main/smalldome 小穹顶＋主楼屋面露台＋屋脊走道

- 类别：main　优先级：P2（随大穹顶一家）　领卡：c224（代号 sdome），分支 `cursor/c164-sdome-8013`

## 目标
方案 §4、§5.2、§5.3、§6.3 与 main.md §6.3：南端亭顶上坐一座铜绿小穹顶（里面是天体照相仪，machines），和大穹顶一家、小一号、开西缝。主楼三块平屋面收口，屋顶走得通：从大圆顶室的门出来，沿两翼屋脊各一条铁走道，南到小穹顶的门，北到报时塔的门（A0 #20299）。小穹顶是 V11 回望的中景主角之一，V2、V12 里主楼南端那“一圆”；屋面只有 V12 和走在屋顶上的人看得到。

## 约束
- 骨架（已锁）：南端亭 z 26..34，东墙面 x 16；小穹顶 x 8..16、z 26..34（九格见方），鼓座底 y 18，半径 4.5，顶点 25。常量读 `skeleton.SMALL_*`、`DOME_ROOM_DOORS`、`CLOCK_SHAFT_*`。
- 边界：墙、女儿墙、瓦面、山墙、平屋面的铺地（y 17 深板岩）、长立面上的避雷针都是 c206 `main/facade.py` 的；大鼓座和大穹顶是 c222 `main/dome.py`；报时塔是 c223 `main/tower.py`；圆顶室地板是 c231 `main/shell.py`。本包只在 y 17 以上做小穹顶，在平屋面和瓦面上做下面写的几样。
- 小穹顶（c219 #23263、A0 #23752）：九格的穹顶不做肋（八条肋占掉一半表面，四条从上面看是十字）；石身七格见方、一格厚，退在穹顶脚里面一格；y 20 一圈倒挂石阶挑出到九格，y 21 铆接铁裙；铜皮整块加半砖，顶点一块铸铜；缝一格宽，朝西，从铁裙开到顶点前；缝南侧一扇滑开的铁门扇，高出铜皮半格；铁裙上一行里三块深色铜皮。东、南、北三面各一扇暗的小窗，西面一扇铁门，门扇退到墙的里沿。
- 屋面（总监 #34510）：
  1. 女儿墙上不加栏杆，立面顶线一块不动；露台只在女儿墙里侧做一圈半格深的旧铜水槽。
  2. 屋脊走道不设护栏、不出屋脊面：格栅和脊瓦一样高，V1、V2 里藏在女儿墙后面（V1 的视线到屋脊东沿是 y 19.97，屋脊面 20.0）。
  3. 通风帽、烟道第一版不放，等 V12 的图。
  4. 人从屋面掉下去不靠栏杆拦：成品地图关摔落伤害；真要拦的地方报总监，用看不见的屏障。
  5. 格栅底下的灯收不收、几级归 lights（c220）；V1、V2、V11 里看不到它们，用 sight 证。
- 只用占用表的角色名。全是方块，展示实体 0。铜只用在水槽上（方案：旧铜是檐沟和雨水管的料）。
