# main/shell 平面、楼板、楼梯和室内空壳

- 类别：main　优先级：**P1**（星厅、大圆顶室、星图室、授时室四间，行星仪、母钟、望远镜三件，都等它）
- 目标：ART-PLAN §5、§8 的室内骨架落成方块。星厅和西 apse 连成一间通高的大厅；西大楼梯上主层；回廊绕着天井；绕墩的环梯上大圆顶室；两翼主层各一间空房；大圆顶室的地面。每间给室内线一个干净的壳和一个登记好的盒子。缩成邮票读到的是：正门进来一条浅石中轴带、两侧黑白格，正前方一根通顶的石墩，墩后三连拱和两跑楼梯，头顶两侧是铁栏回廊。
- 分工（总监 #207、#215）：墙、窗、门洞、屋面归 main/facade（c206），鼓座和穹顶归 main/dome（c222）。本包只盖在 `facade.shell().core` 里；墙线和内叶里只铺门洞的地面。护墙板、壁柱、灯、家具归 interiors，栏杆件和门扇归 props，行星仪、母钟、望远镜归 machines。
- 约束：
  - 数全读骨架：净宽 x 2..13；地面 y 0，主层楼板 y 6（脚 7），屋面板 y 17（脚 18）；星厅 z −6..6 通高到 14，天井 z −3..3（行星仪吊心 (11.5, 0.5)、直径 5），回廊 z=±5、栏杆 z=±4；墩 3×3（x 3..5、z −1..1），墩帽 5×5 在 y 17（顶 18.0），包络 x 1..7、z −3..3；墩东面 y 1..5 留给母钟。
  - 墩不碰楼：墩脚一圈铁格栅，下面是墩自己的基础坑；回廊层墩前留一格缝；顶棚和圆顶室地板各开 7×7 的洞。除格栅、挑檐、墩帽外，没有方块和墩身面对面贴着。母钟挂在墩上，也站在墩的基础上：墩东面前的三格 (6, −1..1) 在地面那一行是墩的石头（`layout().seat`，星厅的母钟石台站在它上面），格栅绕着墩身和这三格走一圈（`layout().joint`：x 2..7、z −2..2 的外圈 18 格）。星厅的地面不盖这 30 格。
  - 一层不放楼梯（总监 #207）。西大楼梯两跑在第 8、10 跨（z −5..−3、3..5），踏步 x 1..−5（脚 1..7），平台 x −6；横廊下三连拱对着入口三拱，中间一拱是通西门的拱顶过道。拱头跟入口走：`facade.CROWN` 开着（总监 11-15 定封口），三连拱和过道的拱顶在两块倒阶之间各挂一块上半砖，3 宽、2 宽、封口；关着就是两块倒阶。
  - 主层的栏杆（`layout().rail`）只立在有落差的地方：回廊和横廊的板边、让开石墩的那一圈、两跑梯井的东头（横廊压在梯上的那三格）和南北两侧墙顶上梯面比楼面低一格起的那一段（x −4..−1）。梯井两道栏杆在 (−1, ±2) 拐角：栅杆和铁板是薄的，角对角不相连，拐角那一格不立，人能从两根杆之间走进梯井（自查第 5 条查这种角）。
  - 环梯（总监 #31594：出口在墩帽北侧，退路南侧，东侧不许，那里归目镜和观测位）：包络外圈逆时针一整圈，22 级半砖加三处转角平台。从北回廊正中的小桥 (4, −4) 上，第一级 (4, −3)；北侧向西、西侧向南、南侧向东、东侧向北、北侧再向西，末级回到 (4, −3) 这一列（踏面 18.0），向北下到圆顶室地面 (4, −4)，在上去的那一格正上方 11 格。平台在西北角 8.5、东南角 14.0（和顶棚底面齐平）、东北角 16.5；西南角是一级。东侧一段全在圆顶室地板下面（墩东三格踏面 15.0 到 16.0，人头不过 17.8）。出口格和它上方三格不许进东西。
  - 环梯的栏板和吊杆（`stair_panels()`、`stair_hangers()`）：两侧铁板栏杆。内侧的立在踏步自己那一格里，一行高（放进环缝就贴墩了）。外侧的立在踏步旁边那一格里，两行高：踏板上面那一行和踏板自己那一行；每两级共一行，一对压着下一对一格，从北回廊到边梁是连续的一条阶梯形铁带，梯梁和栏板合成一件，厅里看环梯读的就是这条带。梯的两头各用下一格里的铁板封住（脚下那头两行高，顶上那头一行）。北段站在北回廊的板边上，南段收在边梁底下；西段横跨天井七格，离下面的横廊四格，从开口西边那道梁（x 0）往下吊四根细杆（`IRON_ROD`），落在外侧铁带顶上，隔一格一根，越往上越短：(0, 10..13, −3)、(0, 11..13, −1)、(0, 12..13, 1)、(0, 13, 3)。
  - 环梯两个口的灯柱（`stair_posts()`，评审 #16）：梯的起点在北回廊上只是栏杆里一格宽的缺口，终点在圆顶室里也是。每个口在栅杆那一侧的栏杆头上立一根黄铜柱（`BRASS_RAIL` 单根，旁边没有东西和它相连：一根带柱头和脚箍的细铜管），比栏杆高一格：回廊 (5, 8, −4)，在小桥东边；圆顶室 (3, 19, −4)，在出口西边。缺口的另一侧是铁带的端头。两个口都用黄铜（评审定的，见记录）：整部环梯只有这两根是黄铜，手扶的地方用黄铜合美术方案的规矩。栅杆不换成柱：栅杆和柱不相连，换了会留出人能钻过去的缝。柱顶上面那一格，(5, 9, −4) 和 (3, 20, −4)，本包不放东西。灯归 sky/lights（c331 定的，#66687）：回廊口放 props/lamps 的 `post`（女儿墙墩上那种矮灯，脚心 (5.5, 9.0, −3.5)，光源在灯自己那一格，8 级）；圆顶室口不放灯，那一格空着，黄铜柱光着当望柱（总监：圆顶室全室只一盏目镜旁的小红灯）。
  - 环梯脚下（`layout().plinth`、`HEADROOM`）：头三级和西北角平台离主层楼面不到两格。梯板底离楼面正好一格的有两格，西北角平台 (1, −3) 和第三级 (2, −3)：那一格（y 7）里各立一块主层墙脚那种嵌板石（`ASHLAR_PANEL`），平台落在石墩座上，不是悬在一圈栅杆上。第四级 (1, −2) 的板底离楼面一格半，那一格本来就是让开石墩那圈栅杆里的一格。楼面上人走的格子（`layout().walk`）头顶两行不许有实心方块；外侧铁带下面那一行，在走人的格子上方不到两格的地方不装。横廊在 z −3 这一行因此只剩 x 0 一格宽。
  - 窗龛（`layout().niches`）：立面在星厅东面两个转角把自己的内衬切成窗龛，(14..15, ±5) 四格，y 7..13；y 6 是龛底，和回廊板同料同高，y 14 是过梁。`room_at()` 在这几格答「star hall」；`ROOMS["star hall"]` 的盒子不变，说明里写了这一句。
  - 端亭、apse 两侧的夹角是封死的空腔。两翼底层在它的房间进总装以前也封着；进了就列进 `shell.LOWER`，本包从星厅的侧廊给它开门洞（现在：南翼的底片库）。
  - 只用占用表的角色。墙照立面的分带：勒脚 `SLATE_BRICK`、基座 `ASHLAR_ROUGH`、主层 `ASHLAR_FINE`，主层上下各一道 `ASHLAR_PANEL`。大厅地面照总监给星厅定的铺法（#30479）：中轴一条 3 格宽的素浅石带（`ASHLAR_FINE`），从正门到西门；两侧各一道 `SLATE_SMOOTH` 线，落在壁柱线 z ±2 上（三连拱的墩和楼梯侧墙站的那两条线）；再外面是 2×2 的黑白格，从入口墙数起。星厅搬进来以后它那一段由 interiors/starhall 自己的地面盖掉，壳只留楼梯厅那一段。门洞里是勒脚石。主层的板 `ASHLAR_FINE`；悬空的板边是 `IRON_RIVETED` 梁，栏杆 `IRON_BARS` 立在梁上。两翼和圆顶室地板 `FLOOR_WOOD`，两翼房的顶棚是整块 `DARK_WOOD`。环梯踏板 `IRON_RIVETED`、栏板 `IRON_HATCH`、吊杆 `IRON_ROD`、两个口的灯柱 `BRASS_RAIL`、脚下的石墩座 `ASHLAR_PANEL`，墩脚 `IRON_GRATE`。
  - 大厅的顶棚（总监 #35810，照 c219 预审的改法）：`IRON_RIVETED` 的梁只有南北向的，从环梯开口的边梁起每 3 格一道，西边 x 0、−3、−6，东边 x 8、11、14，从一道横墙通到另一道；开口四周一圈边梁。z 0 没有脊梁。x 11 那一道过行星仪吊心，吊点 (11, 14, 0) 在这道梁上，吊心上没有第二道梁穿过。望板是 `DARK_WOOD` 上半砖，搁在梁上：板底 14.5，梁底 14.0（`S.ORRERY_HANG_Y` 不变）。壳和星厅用这同一套线（`layout().beams`），星厅不另画。往顶上挂东西挂在梁上；板是半砖，托不住吊灯。
  - 展示实体 0，不写资源包。`ORDER = 60`（立面 20 之后，搬进来的房间 80 之前）。
