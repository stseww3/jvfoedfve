# main/shell 平面、楼板、楼梯和室内空壳

- 类别：main　优先级：**P1**（星厅、大圆顶室、星图室、授时室四间，行星仪、母钟、望远镜三件，都等它）
- 目标：ART-PLAN §5、§8 的室内骨架落成方块。星厅和西 apse 连成一间通高的大厅；西大楼梯上主层；回廊绕着天井；绕墩的环梯上大圆顶室；两翼主层各一间空房；大圆顶室的地面。每间给室内线一个干净的壳和一个登记好的盒子。缩成邮票读到的是：正门进来一条浅石中轴带、两侧黑白格，正前方一根通顶的石墩，墩后三连拱和两跑楼梯，头顶两侧是铁栏回廊。
- 分工（总监 #207、#215）：墙、窗、门洞、屋面归 main/facade（c206），鼓座和穹顶归 main/dome（c222）。本包只盖在 `facade.shell().core` 里；墙线和内叶里只铺门洞的地面。护墙板、壁柱、灯、家具归 interiors，栏杆件和门扇归 props，行星仪、母钟、望远镜归 machines。
- 约束：
  - 数全读骨架：净宽 x 2..13；地面 y 0，主层楼板 y 6（脚 7），屋面板 y 17（脚 18）；星厅 z −6..6 通高到 14，天井 z −3..3（行星仪吊心 (11.5, 0.5)、直径 5），回廊 z=±5、栏杆 z=±4；墩 3×3（x 3..5、z −1..1），墩帽 5×5 在 y 17（顶 18.0），包络 x 1..7、z −3..3；墩东面 y 1..5 留给母钟。
  - 墩不碰楼：墩脚一圈铁格栅，下面是墩自己的基础坑；回廊层墩前留一格缝；顶棚和圆顶室地板各开 7×7 的洞。除格栅、挑檐、墩帽外，没有方块和墩身面对面贴着。
  - 一层不放楼梯（总监 #207）。西大楼梯两跑在第 8、10 跨（z −5..−3、3..5），踏步 x 1..−5（脚 1..7），平台 x −6；横廊下三连拱对着入口三拱，中间一拱是通西门的拱顶过道。拱头跟入口走：`facade.CROWN` 开着（总监 11-15 定封口），三连拱和过道的拱顶在两块倒阶之间各挂一块上半砖，3 宽、2 宽、封口；关着就是两块倒阶。
  - 环梯（总监 #31594：出口在墩帽北侧，退路南侧，东侧不许，那里归目镜和观测位）：包络外圈逆时针一整圈，22 级半砖加三处转角平台。从北回廊正中的小桥 (4, −4) 上，第一级 (4, −3)；北侧向西、西侧向南、南侧向东、东侧向北、北侧再向西，末级回到 (4, −3) 这一列（踏面 18.0），向北下到圆顶室地面 (4, −4)，在上去的那一格正上方 11 格。平台在西北角 8.5、东南角 14.0（和顶棚底面齐平）、东北角 16.5；西南角是一级。东侧一段全在圆顶室地板下面（墩东三格踏面 15.0 到 16.0，人头不过 17.8）。两侧铁板栏杆，内侧的立在踏步自己那一格里；梯的两头各用下一格里的铁板封住。出口格和它上方三格不许进东西。头三级和西北角平台离主层楼面不到两格：楼面上凡是梯底净高不足 2 格的格子都立栅杆（现在是 (2, −3)、(1, −3)、(1, −2)），人走不到梯底下去；横廊在 z −3 这一行因此只剩 x 0 一格宽。
  - 两翼底层、端亭、apse 两侧的夹角是封死的空腔（没有房间卡）。
  - 只用占用表的角色。墙照立面的分带：勒脚 `SLATE_BRICK`、基座 `ASHLAR_ROUGH`、主层 `ASHLAR_FINE`，主层上下各一道 `ASHLAR_PANEL`。大厅地面照总监给星厅定的铺法（#30479）：中轴一条 3 格宽的素浅石带（`ASHLAR_FINE`），从正门到西门；两侧各一道 `SLATE_SMOOTH` 线，落在壁柱线 z ±2 上（三连拱的墩和楼梯侧墙站的那两条线）；再外面是 2×2 的黑白格，从入口墙数起。星厅搬进来以后它那一段由 interiors/starhall 自己的地面盖掉，壳只留楼梯厅那一段。门洞里是勒脚石。主层的板 `ASHLAR_FINE`；悬空的板边是 `IRON_RIVETED` 梁，栏杆 `IRON_BARS` 立在梁上。顶棚 `DARK_WOOD` 望板加 `IRON_RIVETED` 梁。两翼和圆顶室地板 `FLOOR_WOOD`。环梯踏板 `IRON_RIVETED`、栏板 `IRON_HATCH`，墩脚 `IRON_GRATE`。
  - 展示实体 0，不写资源包。`ORDER = 60`（立面 20 之后，搬进来的房间 80 之前）。
