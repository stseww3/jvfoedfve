# main/facade 主楼石壳（立面）

- 类别：main　优先级：**P1**（墙优先批：V1、V2、V3、V4 都靠它）
- 目标：ART-PLAN §5.1 的立面语法做成一个能复用的引擎，再用它立起主楼的石壳：四面墙从勒脚到女儿墙、圆厅西半圈、两翼的石板坡屋顶和山墙、避雷针、入口的石作。缩成邮票读到的是：一道暗的基座托着一排亮暗相间的大拱窗，壁柱一根一根把它分成 17 跨，正中三跨往前凸、下面是三连拱门廊。
- 分工（总监 #19274.2）：本包管 `_order.py`、`_plan.py`、`facade.py`。鼓座、大穹顶、圆厅外壳以上归 main/dome（c222，y=16 起，`_dome.py` 从 fce2fbb0 起是他的）；报时塔、小穹顶、三个端亭屋面以上、平面和楼板、室内空壳各有各的包。下层的人留占位，上层的人用更大的 `ORDER` 盖过去。
- 约束：
  - 数全读骨架：开间 4（壁柱 1 + 窗 3）、17 跨、各层的行（勒脚 0..1、基座 2..5、腰线 6、窗下墙 7、大窗 8..13、饰带 14、檐口 15、女儿墙 16..17）、三层进深（玻璃 −1、壁柱 +1、檐口 +2）。哪一列是墩、哪一列是窗读 `_plan.py`（c178 的逐格平面）。
  - 只用占用表的角色名：勒脚 `SLATE_BRICK`，基座 `ASHLAR_ROUGH`，主层、线脚、女儿墙 `ASHLAR_FINE`，窗下墙和饰带的凹板 `ASHLAR_PANEL`，壁柱头上的小台徽 `ASHLAR_EMBLEM`，檐沟 `OLD_COPPER_CUT`，坡屋顶 `SLATE_TILE`，避雷针 `IRON_ROD`，基座小窗的铁栏 `IRON_BARS`，勒脚通风口 `IRON_GRATE`，窗是窗族五个角色。材质长相归 materials。
  - 玻璃是整块，站在墙面后一格；玻璃后面那一格留空给光线的隐形光源。哪扇亮由 `sky/_lightkit.window_lit` 定（进了总装就读它）；它没进来以前用 `facade.ROWS`，那是它对本包窗表的回答抄下来的。
  - 任何面不出现超过 5×5 的平墙（`check.py` 的 flatwall）。
  - 入口三版可切换（总监 #19274.1），`facade.ENTRANCE`，默认 B：A 正中一跨单门洞，拱顶穿过腰线；B 三连拱门廊，中央三跨（8、9、10）从地面开到腰线下，正中通星厅，两侧各一樘铁栅门（现在是玻璃层的一层铁栏方块占位，铁件开了由 props/ironwork 清掉换成门）；C 正中门洞和上面的大拱窗连成一个通高的拱，腰线和窗下墙在两根壁柱处断开，门上一道石横档。拱券石都在整格线上，用粗琢面，跟基座的横带一个节拍；B 的拱心石是腰线里的一块整石。
  - 正中一跨的大台徽座：壁柱那一层的 3×3 石板（y 14..16，z −1..1），檐口和檐沟在它前面断开，上面一道压顶。台徽本身（铸铜件或钟面）归 props/electrics-signs，挂在 `facade.emblem()` 报的面上。其余壁柱头的小台徽不动。
  - 入口后面的墙是占位（`SCREEN`）：门洞后 6 格一道细琢面的墙加星厅两道横墙，高到腰线，让门洞灯有一块浅色的面可打，也挡住从门洞看穿到楼后的天。main/shell 和星厅进总装后删。
  - 管桥进楼的口（总监 #21090）：南端亭转角墩脚的铁格栅 `facade.PIPE_INLET` = (17, 0, 33)，东立面上不走立管。
  - 展示实体 0。往整座楼上铺东西的包（铁件、管线、灯、标识）各带 `DRESS` 开关，不归本包。
- 交付物：
  - `build/scenes/obs/main/_order.py`：立面语法引擎。`Plan`（脚印、墩和跨的分类、门洞）、带 `Plinth / Storey / Course / Frieze / Cornice / Parapet`、窗型 `Window`、`bays()`（给规则的盒子自动分跨）、`build()`；不用游戏看图的 `drawing / elevation / section`。塔、发电房、车站、别的包的真墙样板都用它。
  - `build/scenes/obs/main/_plan.py`：平面（c178 的细化稿）里墙的那一半，加两张给别的线读的表：`windows()`（窗表）和 `doors()`（门洞表）。
  - `build/scenes/obs/main/facade.py`（`ORDER = 20`）：石壳本身。给别人的入口：`table()` / `windows()`、`doors()`、`terraces()`（三块平屋面和圆顶室地面的格子）、`emblem()`、`sample()`（单独立几跨翼墙，给铁件、灯、管线的样板）、`PIPE_INLET`、`crowned()`。
  - 测试场景 `build/scenes/obs_main_facade/`（B 版，8 个机位：V2 正轴、V4 入口、V1 机位、门廊近看、V3 两跨近景、斜看、俯看屋面、西面）和 `obs_main_facade_a`、`obs_main_facade_c`（另两版入口，各 4 个同名机位）。按总场景的顺序整条建 site、main、props、sky。
  - 细化稿 `plan/parts/main.md`（c178）。
- 验收：V2 正轴看得出五段式和三层进深，基座是一道暗带；V3 近看两跨墙有勒脚、基座、腰线、窗下墙、拱窗、饰带、檐口；V4 入口靠形不只靠光；V1 距离上节奏还在。技术：`check.py --scene obs_main_facade`（和 `_a`、`_c`、`obs`）全过，flatwall 里没有本包的面；`python -m scenes.obs.main.facade check` 对三版入口查五件事（三层进深、檐口和台徽座、窗和平面一致、总监的三条亮窗规矩、门洞通而不穿）。
- 版本：墙 1 版；入口 3 版比选（A、B、C），默认 B。
- 依赖：骨架；占用表；`sky/_lightkit`（没有也能建）。被依赖：main/dome、clocktower、smalldome、shell 站在它上面；sky/lights 读窗表；props/ironwork 读窗表、门洞表，props/lamps 看入口立着的壁柱，props/pipes、electrics-signs 用 `sample()` 和台徽座；site/court 的中路和分带对着它的壁柱线；site/powerhouse 的管停在 `PIPE_INLET` 东边一格。
