# 蓄电池室（battery room）— 工作包卡片

类别：室内。包名：`batteryroom`。优先级 P3（第二批房间，第一批五间不等它）。比选：1 版。总监 11-16 立。

## 目标
北翼底层，授时室的正下方。授时不能停电，所以楼下有一屋子蓄电池：发电房来的电在这里充进电池，再稳稳地送上楼去走钟、发报、放报时球。主角＝成排的玻璃缸蓄电池，架在木架上，顶上走铜排。进门的人一眼看懂「电存在这里」。

## 约束
- 位置：北翼底层，`shell.ROOMS["time room"]` 那只盒子的正下方，脚踩 `S.GROUND`，净高到主层楼板底。现在是封死的空腔（`main/shell` 的卡：两翼底层、端亭、apse 两侧的夹角都封着，要用的时候他开门洞和楼板）；门洞和楼板由 shell（c325）开，开在哪里由领卡的人和他、和 hall（c348，星厅的北墙）一起定，报总监。
- 这间没过审以前门洞不开，星厅那一面照旧是一扇关着的门。
- 基座层的窗是带铁栅的暗窗，立面的规矩是基座层一道暗带：从外面看不许变亮。窗后不放光源，屋里的光到不了窗。
- 光：冷底暖点。铁笼灯两三盏，三级（5–8）；配电板的表盘可以有夜光绿，只上表盘。不加新的光色。
- 只用占用表的角色和色板。地面读得出耐酸（石板，或铅皮色的铁板），不用木地板；顶就是主层楼板的铁梁。
- 实体 ≤250；单视角 ≤400。

## 件清单
主角由本卡自己做，照 machines 的规矩。

- 蓄电池：玻璃缸（读得出是玻璃：亮边、液面线、里面的极板）、两层木架、瓷垫脚。成排成列，中间留一条走道。一种模型多摆。
- 铜排和连接条，从电池顶上汇到墙上的大理石配电板：闸刀、电流表、电压表、充电和放电的换向开关。
- 来电和去电讲得通：一路粗缆从发电房的方向进墙（和 pipes 的管线对上），一路细线穿楼板上授时室（和 timeroom 对上位置）。
- 小件：比重计和量杯的架子、装蒸馏水的大玻璃瓶、挂着的橡胶手套和围裙、记录板、「严禁烟火」的搪瓷牌（文字照 `props/electrics-signs` 的规矩）。
- 至少一处在动：电流表的指针慢摆，或者电池里偶尔冒的气泡（动画贴图）。

## 交付物
`build/scenes/obs/interiors/batteryroom.py`；测试场景 `build/scenes/obs_int_batteryroom/`（盒子占位壳）＋`shots.json`＋`mood.py`。**先交一页草图**（平面、主角、三个机位各看到什么）给总监看过，再铺开。

## 验收（五角度＋技术）
第一眼是成排的玻璃缸和上面的铜排；读得出电从哪来、到哪去；没有 5×5 以上的平墙、平顶；从前庭看这一段基座层没有变亮；实体 ≤250。

## 要拍的视角
`int_door`（进门第一眼）、`int_aisle`（顺着走道看过去）、`int_board`（配电板近看）、`ext_base`（从前庭看这一段基座层，和没有这间时并排）。

## 依赖
shell（门洞、楼板）、hall（星厅北墙的门）、timeroom（楼上的接线位置）、pipes 和 `machines/switchboard-boiler`（来电的缆）、props（灯、牌、小件）、lights（定级）、s2（搬入）。

## 记录（astro c360，11-16 第一版）

分支 `cursor/c164-astro-batteryroom-f3-e786`。接 stair（c337）留在 `cursor/c164-stair-batteryroom-f3-b330` 的草图和三处接口；草图不单交（cr4 同意），第一版带图交。

**平面**（空腔 `x 2..13`、`z −25..−7`，脚 `y 0`，净高到 `y 5`）
- 走道在长轴上，两格宽（`x 7..8`），从门直通配电板。
- 电池两组，一边一组（`x 5..6`、`x 9..10`，`z −22..−10`）：每组两排背靠背，两层木架、瓷垫脚，一格两缸，共 208 只缸；一个模型（`cells`）摆 52 次。缸壁上半截是空的（透），亮边、亮角、液面线；液面下是棕、灰相间的极板。
- 四道铁梁下各一副木门架跨在每组上，门楣上的瓷瓶托铜排；每组南端从末一只缸引一根铅条上铜排。
- 配电板和铜排是 mast（c346）的 `machines/batteryboard`：`BB.place()` 摆板，`BB.run()` 铺排（按门架分段取光）。
- 粗缆：从南墙 `(5.5, 1.5)`（星厅配电板背后）出墙，沿墙裙顶 `y 2.125` 走南墙、西墙、北墙，瓷夹板固定，进配电板西翼背后（`BB.FEED_IN`）。上楼的两根细线是板自带的两根管（`x 6.5`、`9.5`），对着授时室的 `DUCT_X = (6, 9)`；西南角那根立管是子钟的，没用。
- 小件：西墙根三只装蒸馏水的大玻璃瓶（带木筐）；东墙末一扇窗下的比重计架子（比重计、两只量杯、一只陶瓶）；南墙门东边的记录板、挂钉上的橡胶围裙和手套；第二道梁上的「严禁烟火」搪瓷牌（只有图：一团火加一道红杠，没有字）。
- 窗：每个窗格里侧一整块铁百叶（`B.PANELS["louvre"]`），东墙五开间、西墙北边三开间。
- 地面：石板；电池架下是铁板托盘；走道上一道地漏格栅。顶：四道铆钉铁梁，梁间看得到授时室的楼板和线槽底。

**光**（都走 `L.suggest`，三级；笼灯三盏）

| 灯 | 光位 | 级 |
|---|---|---|
| 第一道梁南面的笼灯（进门头顶） | `(7..8, 1, −9)`；`(7..8, 1, −10)`、`(7..8, 1, −8)`、`(7..8, 3, −9)` | 8；7 |
| 第三道梁南面的笼灯 | `(7..8, 1, −17)`；`(7..8, 1, −18)`、`(7..8, 1, −16)`、`(7..8, 3, −17)` | 8；7 |
| 线槽底南面的笼灯（配电板上方） | `(7..8, 4, −24)`（板取 `(8, 3, −24)` 的光，得 7；mast 要 6 到 8）；板前站人的地方 `(7..8, 1, −23)` | 8；7 |
| 两灯之间的补光（没有灯） | `(7..8, 2, −13)`、`(7..8, 2, −21)` | 7 |

一共 24 个光位。沿走道的地面（`y 0`）：灯下 7，两灯之间 4 到 5，门里第一格 5，板前 5 到 6。电池的模型都提在 `y 1` 那一格取光（`HELD`）：靠走道的一排 4 到 7，靠墙的一排 3 到 6；门架提在靠走道的那一排。牌子那一格 4。

**实体**：107（电池 52、门架 8、引上条 2、板 8、铜排 16、缆 4、夹板 6、出墙口 1、小件 7、灯 3）；卡的上限 250。

**在动的**：配电板上三只表的指针（mast 的 `MK.swing`，110、150、260 刻一个来回）。

**从前庭看**：`renders/obs_int_batteryroom/ext_base.png`（有房间）和 `renders/obs_int_batteryroom_bare/ext_base.png`（空腔；同一段楼、同一机位、天光线给的光源一样，外面 5 个，逐格比过）。窗里侧是整块百叶（不透光的整块方块），四面墙是实的，屋里的光到不了玻璃。

**门**：`HALL_DOOR = (7, −6)`（星厅读这个名字），`MOVED_IN = False`。第一版进总装以后 cr4 通知 shell 开洞；洞开了，打磨轮在真楼里核一遍再打开开关。

**最弱的三处**
1. 缸的玻璃感只靠亮边和液面线：极板是画在缸壁上的，缸里没有真的体积，斜着看没有视差；近看是「蓝框里一块棕」。
2. 屋子偏暗：电池架背后的两条侧道几乎没有光，小件只有南头灯下那几件看得清；离线图的光照表又平，要对着真机图再核一次级别。
3. 门架上的瓷瓶是方块，近看又大又白；铜排（黄铜色）和木架、缸的冷色之间只有每组南端那两根铅条，缸和缸之间的连接条只画了缸顶一条。

**还没做**：缸里的气泡（动画贴图）；侧道的光和小件再细一轮（比重计、量杯还粗）；`ext_base` 的并排拼图（现在是两个场景同机位各一张）；门洞开了以后搬入。
