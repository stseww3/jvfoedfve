## 4. 这一稿的安排和理由

- 走道两格宽（x 7、8），在中轴上；两组架子 x 5、6 和 x 9、10，各两排背靠背，z −22..−10 十三格；两边各留三格检修道。进门的人站在 x 7.5，东边一组的正面看得开，西边一组先看到南头的端面。
- 主角：一格一段的模型（四只缸连架子），摆 52 次，三个变体；缸 7×9×11 像素，上层缸沿 1.8，液面线在眼高。隔一格一根立柱，梁下的四根升上去成木门架（Π 形，不出十字），白瓷瓶托一对铜排（y 2.5..2.75），铜排从南头最后一只缸引上、向北直接进配电板两翼。电的走向：粗缆（星厅配电盘背后穿墙，贴墙裙顶沿西墙、北墙）→ 板 → 缸；缸 → 铜排 → 板 → 两根细管上楼。
- 配电板：北墙正中三块大理石（x 5.5..10.5，离墙六像素，铁腿），中间一块和走道一样宽，两只夜光绿表盘正在走道的尽头。在动的是电流表指针。
- 灯三盏，8、7、8 级：走道上两盏吊在第一、第三道梁下，一盏在板顶墙上。光照表在天光 0 时：0 级 (0.18, 0.21, 0.35)，4 级 (0.39, 0.37, 0.44)，8 级 (0.63, 0.51, 0.46)，没照到的地方是暗蓝不是黑，两盏灯之间也有 2 到 4 级。
- **窗从外面不许变亮**：暗窗（`WINDOW_DARK`）是不透明的画，从外面看不到屋里；会让它变亮的只有照进玻璃那一格的块光。办法是每个窗里侧一只铁窗罩：最外一列（东 x 13，西 x 2）在 y 3、y 4 各放一块 `IRON_RIVETED` 楼梯（下一块 `half=bottom`、上一块 `half=top`，实面朝玻璃），八个窗 48 块。楼梯的实面挡光，游戏和离线渲染器（`artkit/blockfacts`）都按形状算，核过。交付时 `ext_base` 带屋、不带屋两张并排核。
- 实体估计一百上下（上限 250）。
