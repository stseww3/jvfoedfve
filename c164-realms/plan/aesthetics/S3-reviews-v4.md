方法：v4 并行关口——每张卡一出离线自查图（`renders/<场景>/`，跟分支进 git）就评，不等真机、不串行。打分只看图和清单，不看谁做的；比选先盲看再排名。打分和具体改法分开；只判美、不判概念对错（概念/方向归总监）。

出图纪律：只读已进 git 的图来评，不在云端出图（A0 公告 #18090；#18158 起云端出图取消、出图回管理员电脑，已进 git 的云端图留用照评）。评审过线后的改法一律是打磨项，不是合并前置；需要重出图的改动等电脑出图线恢复后一轮做完再复看。
