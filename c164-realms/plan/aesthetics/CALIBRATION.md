## 批次 cal-01：旧样例场景 a0-t1（已被管理员否，作反例 / 负向锚点）

来源：`/agent/realms-study/inbox/a0-t1-*.jpg`（旧样例离线渲染，非本项目设计）。方向错在 ART-PLAN §1 列的几条：浮空岛、白天全景、画面大半是自然地形、力气摊得太开、没有自己的造型语言。按 RUBRIC 应整批低分、整批退。用来确认"标准能把被否的方向打成低分"。

### a0-t1-hero（看板整体）
分数：第一眼 1/5｜轮廓构图 2/5｜明暗光色 1/5｜质感像素 3/5(参)｜风格逻辑 1/5
红线：#1 奇幻·浮空岛；#7 主体是自然地形/默认游戏感；#6 亮区铺满（整片白天蓝天最亮且最大）
结论：退
最弱三处：
  1. 全图·天空与地形：白天亮蓝天占画面大半、草地树木是主角 → 锁死日落后蓝调（天最暗），主体换成一座建筑，地形只做轮廓并进云。
  2. 大形·轮廓：浮空岛＋散落的塔/小屋/飞艇，邮票大小认不出主体 → 立"一横(主楼)一圆(大穹顶)一竖(报时塔)"，山顶落地、不做岛。
  3. 题材·风格：樱花、飞艇、原木小屋是奇幻温馨路子 → 换铆铁/铜绿/黄铜、外露管线、看得懂的机械。

### a0-t1-dusk_hero（看板整体）
分数：第一眼 2/5｜轮廓构图 2/5｜明暗光色 2/5｜质感像素 3/5(参)｜风格逻辑 1/5
红线：#1 浮空岛；#7 默认游戏感/自然地形主体
结论：退
最弱三处：
  1. 明暗·天空：整片天橙粉发亮、是全图最亮也最大的面 → 只在西边留一条余晖带，其余天压成冷靛蓝，亮区（窗/灯）不超三分之一。
  2. 冷暖·缺对比：暖色铺满全场，没有"冷处发蓝、暖处发金"的灰白石 → 冷底＋局部暖灯，对比落在浅石墙上。
  3. 同 hero 的浮空岛与奇幻题材。

### a0-t1-aerial（看板整体/鸟瞰）
分数：第一眼 1/5｜轮廓构图 2/5｜明暗光色 1/5｜质感像素 3/5(参)｜风格逻辑 1/5
红线：#1 浮空岛；#7 自然地形主体；#6 白天亮区铺满
结论：退
最弱三处：
  1. 鸟瞰全是草地树木、建筑只是点缀 → V12 鸟瞰要读得出建筑群布局（主楼/前庭/子午线/下平台），地形退为背景。
  2. 岛形轮廓零碎、没有主次和轴线 → 整理成有东西主轴、有明确主体的山顶平台。
  3. 白天平光 → 蓝调。

### a0-t1-dusk_scope（建筑/看板）
分数：第一眼 2/5｜轮廓构图 3/5｜明暗光色 2/5｜质感像素 3/5(参)｜风格逻辑 2/5
红线：#7 题材偏默认/奇幻（飞艇、樱花背景）
结论：退
最弱三处：
  1. 天上一轮大太阳是全图最亮最大 → 按方案把天体重画成彗星、挂穹顶上方、彗尾朝上，体量小、不抢穹顶。
  2. 穹顶是阶梯状方块堆的半球、面大而糙 → 换铜绿分瓣＋凸肋＋检修走廊/栏杆的做法，近看有结构、有水痕。
  3. 背景飞艇＋樱花拉回奇幻 → 去掉，背景只留山体轮廓和云海。

### a0-t1-scope_in（室内/模型近景）
分数：第一眼 3/5｜轮廓构图 3/5(参)｜明暗光色 2/5｜质感像素 3/5｜风格逻辑 3/5
红线：无（全批最接近题材的一张，但方向仍偏）
结论：退（可借鉴但须重做：望远镜"一眼看懂是台望远镜"、开缝对着星空的构图）
最弱三处：
  1. 明暗反了：缝外冷蓝天光最亮、室内没有暖灯 → 室内以暖灯为主光（台灯/壁灯），缝外冷、室内暖，形成冷暖对比。
  2. 镜筒黄铜箍沿筒身被拉长、像素比别处粗（疑似拉伸件）→ 箍/环单独成件、按固定间距摆，保持 16 像素一格。
  3. 绿光吊灯当环境光、蓝玻璃发平光、星图是普通画框 → 荧光绿只给仪表；窗用自发光暖窗＋细窗棂；星图做成发光底片台或搪瓷星图。
