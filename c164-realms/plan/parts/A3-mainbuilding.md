## 2. 立面语法模块

目标：**一套规则，换参数出不同的楼**。主楼、报时塔、发电房、缆车站都走它（第 5.4 节）。

### 2.1 参数表

一座楼 = 一套 **Order（做法/柱式）** + 若干 **Wall（墙段）** 调用。

**Order（竖向做法，整栋通用）**

| 参数 | 含义 | 主楼取值 | 备注 / 给附属建筑留的口子 |
|---|---|---|---|
| `bay` | 开间总宽（格） | 4 | 发电房可取 5–6（大拱窗更宽） |
| `pier` | 壁柱宽（格） | 1 | 窗宽 = `bay − pier` = 3 |
| `storeys` | 从下往上的楼层段列表 | 见下 | 发电房单层高拱窗；车站可 0 层（只柱+梁） |
| `courses` | 横向线脚带列表 | 勒脚/腰线/柱础/柱头/饰带/檐口/女儿墙 | 车站可只留檐口 |
| `planes` | 三层进深偏移 | `{pier:+1, wall:0, glass:-1, cornice:+2}` | 见 2.3，可整体缩放 |
| `mats` | 角色→方块名（取自占用表） | 见第 5 节 | **只认角色名**，方块由 A1 定 |
| `rod` | 壁柱顶是否立避雷针 | 是 | |

**Storey（一个楼层段）**

| 字段 | 含义 | 基座层 | 主层 |
|---|---|---|---|
| `y0,height` | 起始 y、层高 | 2,5 | 7,8 |
| `wall` | 墙材角色 | 粗琢面 | 细琢面 |
| `window` | 窗型（见下） | `small` | `arched` |
| `panel` | 窗下凹板角色 | — | 凹板 |

**Window（窗型）**

| 字段 | `small`（小窗） | `arched`（大拱窗） |
|---|---|---|
| `w×h` | 3×2 | 3×6 |
| `head` | 平（铁栅） | 拱（拱肩+键石） |
| `glass` | 暗窗/格栅角色 | 亮窗角色（黄/橙/白） |
| `sill` | 有（泄水台阶） | 有 |
| `grille` | 有（铁栅） | 无（细铁窗棂在贴图里） |
| `lit` | 多为暗 | 按比例点亮，留 2 成暗 |

**Course（线脚带）**：`{at_y, kind, project, mat, recipe}`。`kind∈{勒脚,腰线,柱础,柱头,饰带,檐口,女儿墙}`，`recipe` 指向第 3 节的拼法。`project` = 相对所在进深平面再挑出几格。

### 2.2 接口

材质无关（只传角色名），形状和开间由引擎算。附属建筑复用同一引擎。

```
# build/scenes/obs/mainbuilding/order.py
class Order: ...                       # 上面的参数，纯数据

def wall(c, order, *, base, axis, lo, hi, facing, nominal,
         pier_phase=0, openings=(), lit=None):
    """沿 axis('z'或'x') 从 lo 到 hi 生成一道立面，base 之上。
       facing: 立面朝向（'east'…），决定三层进深往哪挑、泄水台阶朝哪。
       nominal: 立面名义面在朝向轴上的坐标（主楼东墙=15，前凸段=17）。
       逐列判壁柱/窗（按 bay/pier 和 pier_phase 对齐），逐 course/storey 落块。
       openings: [(a0,a1,y0,y1,kind)] 覆盖掉某段改成门洞/过道。
       lit: 可调函数 (bayindex)->0..1，决定该窗亮度，交给 A2 的规则。"""

def corner(c, order, *, at, dirs, base, top):   # 转角壁柱/转角石（转角处两墙交汇）
def opening(c, *, box, kind):                     # 门洞、过道、楼梯口（挖洞+收边）
def roof_parapet(c, order, *, ring/line):         # 檐口+女儿墙+压顶收口
```

**调用姿势**（示意，主楼东立面）：
```
od = Order(bay=4, pier=1, storeys=[BASE, MAIN], courses=MAIN_COURSES, mats=STONE_ROLES, rod=True)
wall(c, od, base=0, axis='z', lo=-34, hi=34, facing='east', nominal=15,
     openings=[(-1,1, 0,4, 'door')], lit=A2_lit)   # 中央门洞
```
**附属建筑复用**（给 A4 的口子）：发电房 = 同引擎，`Order(bay=6, storeys=[TALL_ARCH], courses=[勒脚,檐口], mats=INDUSTRIAL_ROLES)`，墙材换成凝灰岩砖+铁桁架、窗换成透炉火的大拱窗、顶换锯齿天窗（锯齿天窗我再给一个 `sawtooth()` 辅助）。缆车站 = `Order(storeys=[], courses=[檐口])` 只出柱+梁+玻璃雨棚。接口不变，只换 Order 和材质角色。

### 2.3 三层进深怎么生成（验收：三层进深到位 / 无 >5×5 平墙）

名义墙面在 `nominal`。朝向 `facing` 决定“向外”的方向（东立面向外=+X）。三个平面，每层差一格：

```
平面（俯视，↑=向外/朝到达，→=沿立面 z）  东立面 nominal=15：
  x=16  ■■            ■■            ■■      壁柱面（+1，最前）        plane pier
  x=15  ■■ ········· ■■ ········· ■■      墙面（0，居中）/ 窗洞侧壁   plane wall
  x=14  ░░ ▒▒▒▒▒▒▒▒▒ ░░ ▒▒▒▒▒▒▒▒▒ ░░      玻璃（−1，最后，退进 2 格）  plane glass
        壁柱  —窗 3 宽—  壁柱  —窗 3 宽—  壁柱
```
- **壁柱**在最前（x=16），**墙面**居中（x=15），**玻璃**退到 x=14，窗从壁柱面算退进 2 格 → 深窗洞，侧壁（x=15 的返璧）在光下落一道阴影。檐口再挑到 x=17（见第 3 节）。
- 引擎按 `planes` 偏移把每个 course/窗分别落到对应平面，所以**进深是生成出来的、不是手摆的**，换 `planes` 数值就能整体加深或减浅。
- **为什么没有 >5×5 平墙**：横向每 4 格一道壁柱打断；竖向被勒脚(0–1)/腰线(6)/柱础(7)/柱头(13)/饰带(14)/檐口(15) 切成窄带；进深上壁柱/墙/玻璃三层错开。最大的连续平面是“窗下凹板”约 3 宽 × 2 高，和壁柱身 1 宽 × 5 高，都不到 5×5。测试场景出一张正交立面图量给 A0 看。

### 4.3 圆厅与大穹顶，怎么和主楼相接（第 5.2 节；对 V2、V8、V12）

圆心 (x=4, z=0)，外半径 13。它是“一横一圆一竖”的**圆**。

**竖向叠法**：
```
侧剖（→=+X 向东/入口，↑=y）：
 y37            ◜■■■■■■◝            穹顶顶点（铜绿攒尖/半球）
               ◜        ◝
 y24  ──────◜  起拱线 y24  ◝──────   穹顶起拱＝鼓座顶
 y18..24  ║ 鼓座(石)6高, 一圈小圆窗 ║   drum
 y18  ─ 铁走廊+栏杆绕一圈 · 检修梯 ─   室外环廊
 y18  ====大圆顶室地面 y18, 内径22====   dome room floor
 y0..17  主楼中段：基墩(石)+环形楼梯     base pier + ring stair（在主楼里）
        —— 东侧前凸段=星厅(通高) ——
```
- **楼下（y=0–17）**：鼓座不是落地的；y=0–17 这段是**基墩**（圆心附近的厚石墩）+**环形楼梯**，藏在主楼中段里。基墩外侧东边让给星厅（通高门厅），西边和北、南墙咬住主楼。
