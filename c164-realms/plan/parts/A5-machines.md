### 1.2 画法、16 像素一格、放大件

- **16 像素一格，几个平色加一像素明暗，不用渐变**（方案第 6.1、7.1 节）；用 `pixelart.Mat`（已由 `palette.mat()` 统一配好 kind/noise/bevel）；手画面（表盘、刻度、台徽、星图）用 `pixelart.Sprite`。
- **保 16 像素/格的规则**（同 A6 稿 §1.6）：模型以「单位」画，`scale=1` 时 16 单位 = 1 格；令 **`px = scale`**，则贴图密度恒 `16×px/scale = 16` 像素/格，与方块、与 A6 道具完全一致。元素坐标限 −16..32（48 单位 = `scale=1` 时 3 格）。
- **大件选 scale**：取**最小整数 `scale` 使「该件最大 real 尺寸 ≤ 3×scale 格」**，画图用单位数 = `real格数 × 16 / scale ≤ 48`。因为 `px=scale` 时各 scale 的像素密度都是 16/格，**同一台机器的不同子件可用不同 scale，拼起来像素大小仍一致**（这是大件能既大又不糊的关键）：
  - 镜筒 15 格 → `scale=5`（3×5=15，画 48 单位）；赤道仪支架/叉臂 ~5 格 → `scale=2`；配重、箍、寻星镜 ≤3 格 → `scale=1`。
  - 飞轮 ⌀5 → `scale=2`；行星仪 ⌀7 → `scale=3`；桅杆一节 ~3 格 → `scale=1` 叠放。
- **超 6 格的长件/高件**：拆成「一节模型 + 沿轴 `between()` 拉伸或分节摆放」（镜筒除外，镜筒整条一个件保证连续铆钉）。桅杆、长钢缆、长皮带、长蒸汽管这样做。

### 1.3 发光

- 件自身发光用 `box(..., emit=15, shade=False)`（元素 `light_emission`），**只那一面亮、不照亮周围**，且 **emit 面收小**（炉门只亮炉膛口一圈、亮窗只亮窗格、记录灯只亮灯头），emit 色与 A2 暖光 `#ffb45e` 对齐，保证全场亮区 < 1/3（评审明暗项）。
- **真正照明由 A2 放隐形 `light` 方块**。A5 的摆放函数**连带返回每处光的坐标与亮度级**（炉门/亮窗=二级 9–10，记录灯/指示灯=三级 5–8，桅杆红灯=警示单列）交 A2 统一摆、统一定级；`item_display` 贴实心件的锚点留空气格或用 `brightness` 指定，免得变黑。

## 5. 模型怎么做（技术答复）

### 5.1 现有原语够不够

`models.py` 现成的：`box`（任意姿态盒，可单面换料/自发光）、`tube`（偶数边正棱柱）、`taper`（变径管=锥/喇叭/箍）、`ball`（棱柱叠球/穹/压扁，可取片）、`rod`（两点圆杆）、`beam`（两点方杆）、`hose`（折线闭合圆管）、`ring`（绕轴圆环/圆弧）；`moved/turned/aimed` 搬动与朝向；`Sprite` 手画面；`display`/`between` 摆放与拉伸。

**结论：原语够用，不需要新增 artkit 基元。** 机械的形都能拼：镜筒/锅炉/卷筒=tube，刻度环/轨道环/钟面圈=ring，齿轮=ring+齿 box，飞轮=ring 轮缘+辐 rod+毂，行星臂/连杆=beam/box，行星球/报时球/日球=ball，格构=beam 腿+rod 斜撑，拉索/钢缆/皮带/天线=between，表盘/星图/纸带=Sprite。

### 5.2 需要的组合 helper（放 `build/scenes/obs/machines/_kit.py`，纯拼原语，不碰 artkit）

- `gear(teeth, r, w)`：齿轮（`ring` 盘 + 一圈齿 `box` + 轮毂）。
- `flywheel(r, spokes, rim_w)`：飞轮/卷筒（轮缘 `ring` + 辐 `rod` + 毂 `tube`）。
- `grad_circle(r, ticks, sprite)`：刻度环（`ring` + 刻度 `Sprite`）；望远镜/子午环/配电板大表共用。
- `governor()`：调速飞球（立轴 `tube` + 两臂 `rod` + 两球 `ball`）；蒸汽机、转仪钟共用。
- `lattice(seg)`：桅杆/桁架一节（四 `beam` 腿 + `rod` 斜撑），分节叠。
- `riveted_tube(len, r, scale)`：铆接铁筒（`tube` + 铆钉行 + 两端 `taper`/`ring` 黄铜箍）；镜筒、锅炉、照相仪筒共用。
- `dial(sprite, r)` / `clock_face(r, hands)`：表盘/钟面（圈 + 面 Sprite + 指针件）。
- `cradle()` / `fork_mount()`：望远镜叉架/摇篮（两版比选各取一）。
- `pendulum(len)` / `weight_drive()`：钟摆、转仪钟重锤（拆件给 A8）。

其中若 `gear`、`flywheel`、`grad_circle`、`lattice` A4/A6/interiors 也用得上，**单独一个提交**提给 A0，建议并进 `artkit` 公共层（公共工具只 A0/S2 改）。默认先放自己 `_kit.py`，零风险。

### 5.3 放大件保 16/格、贴图与 A1 对齐

- 见 §1.2：`px=scale`，密度恒 16/格；按「最小整数 scale 使最大尺寸 ≤3×scale 格」选 scale；一个模型一个 px；超 6 格分节/拉伸。
- 贴图走 `palette.mat()`（同 A1 同 A6 的唯一真源），铆钉行距、受光方向（artkit `LIGHT`）与 A1 铁板一致，使镜筒铆钉、机壳铆钉接 A1 铁板墙不断行。手画面（表盘、刻度、台徽）用 `Sprite`，每张过 `palette.strays()` 自查无色板外色。
