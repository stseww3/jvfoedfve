### 1.2 画法（和方块材质同一套）

- **16 像素一格，几个平色加一像素明暗，不用渐变**（方案第 6.1、7.1 节）。用 `pixelart.Mat`：一条色阶 `ramp` + `kind`（metal/wood/stone/glow/cloth…）+ `bevel`（一像素高光/暗边）。手画的面（表盘、铭牌、星图、台徽）用 `pixelart.Sprite`。
- **和 A1 对齐靠三件事**：① 同一套色阶（上表）；② 同一个 `Mat` 工厂（见第 5 节，A1/A0 发布统一色板模块，A1 画方块、A6 画模型都 import 它）；③ 同样的母题参数（铆钉间距、石缝宽、斜角受光方向都已固定在 artkit，共享）。这样一件铁件挂在铆接铁板墙（A1）上，接缝连得上。

### 1.3 发光

- 模型自身发光用 `box(..., emit=15, shade=False)`（元素的 `light_emission`，原版发光花就是这字段），只决定**那一面自己亮**，不照亮周围。
- **真正的照明由 A2 放隐形 `light` 方块**（方案第 3.2 节）。A6 的摆放函数会**连带返回每盏灯建议的 light 方块坐标和亮度级**（一级 13–14 / 二级 9–10 / 三级 5–8），交给 A2 统一摆、统一定级。
- `item_display` 取所在格亮度；贴墙件锚点要留在空气格，或用 `brightness` 指定，免得贴进实心方块变黑（README 实测）。

### 1.4 可动部件

- 会动的件按方案第 7.1 节拆开：转/摆的部分单独做一个模型、标好轴，静的部分另做，由 **A8** 用展示实体的变换插值驱动。
- 道具里真会动的很少：精密钟/摆钟的钟摆（摆动）、旗和风向袋（飘动，可用动画贴图或小幅插值）、信号灯/指示灯（闪，走动画贴图归 A1+A8）。其余一律静件。清单里逐件标“可动”。

### 1.5 挂法

每件标明：**落地**（站在地面/台面，锚点在脚下空气格）、**挂墙**（锚点在墙前空气格，背面贴墙）、**吊顶**（锚点在吊点，向下垂）。立面外露件多为挂墙；灯具三种挂法都有。

### 1.6 放大模型如何保证 16 像素一格

- 规则（README 实测 + `models.py`）：模型以「单位」画，`scale=1` 时 16 单位 = 1 格；贴图密度 = `16×px/scale` 像素每格。**令 `px = scale`，密度恒为 16 像素/格**，和原版、和方块一致。
- 元素坐标只能在 −16..32（共 48 单位 = `scale=1` 时 3 格）。更大的件：取**最小的整数 `scale`**使「最大real尺寸 ≤ 3×scale 格」，再令 `px = scale`。画图时用的单位数 = `real格数 × 16 / scale`，必 ≤ 48。
  - 例：4 格高的铸铁路灯 → `scale=2, px=2`（可画到 6 格，灯画 32 单位）；3 格的拱窗框 → `scale=1, px=1`；小吊灯 → `scale=1`。
- **一个模型只用一个 `px`**：细节靠多给texel，不靠在同一模型里混用不同 scale，免得出现大小不一的像素（方案第 7.1 节红线）。超 6 格的少数件（长管、长栏板）拆成「沿 +z 的一段 + `between()` 拉伸」或分段摆放。

### 1.7 命名、预算、文件

- **命名**：按族加前缀 `lamp_ / pipe_ / iron_ / elec_ / inst_ / furn_ / paper_ / sign_`，便于 A0 归并、A8 查找。
- **实体预算**（方案第 7.4、12 节）：全图展示实体 ≤ 3000、任一视角 ≤ 600。道具多为 1 件 = 1 实体，可动/多段件 2–3 实体。A6 先按「总装分到 A6 的额度」铺，具体额度请 A0 在骨架里给（第 5、7 节）。能用方块解决的不做模型（栏杆用 `oxidized_copper_bars`，仪表墙用面板方块）。
- **文件**（只在 A6 的地盘）：
  - `build/scenes/obs/props/`：模型库，按族分模块（`lamps.py pipes.py ironwork.py electrics.py instruments.py furniture.py paper.py signs.py`）+ `kit.py`（共用小helper）+ `__init__.py`（`build_models()`、`MODELS`、`SCALE`、`place()`、`stretch()`）。
  - `build/scenes/obs_a6/`：我自己的陈列架测试场景（`props.py` 给 `gallery.py`/`makepack.py` 用的 `build_models/GALLERY/SCALE`，再加分族的陈列图）。每做一件先在这里单独出图，过了再交。

## 4. 模型怎么做（技术答复）

### 4.1 现有原语够不够、缺什么

`models.py` 现成的：`box`（任意姿态盒，可单面换料/自发光）、`tube`（正多边棱柱，偶数边）、`taper`（变径管=锥/喇叭）、`ball`（棱柱叠成的球/穹/压扁罩，可取片）、`rod`（两点间圆杆）、`beam`（两点间方杆）、`hose`（折线圆管，拐弯闭合）、`ring`（绕轴圆环/圆弧）；加 `moved/turned/aimed` 整体搬动与任意朝向；`Sprite` 手画像素面；`display`/`between` 摆放与拉伸。

**结论：原语够用，不需要新增 artkit 基元。** 道具里的形都能拼出来：竖杆/臂=tube/box，灯罩/风帽/球仪=ball/taper，管路=tube/hose，法兰/刻度环/钟圈=ring，拱头/卷涡=ring 弧，铁笼/栅栏/百叶=循环摆 box/tube，表盘/铭牌/星图/台徽=Sprite。

**缺的是几个「组合 helper」**（纯拼现有原语，放我自己的 `build/scenes/obs/props/kit.py`，不碰 artkit）：
- `arch_frame(w,h,r,…)`：圆角拱窗/拱门框（拱头 ring 弧 + 框 box + 窗棂）。
- `grille(w,h,pitch)` / `louvre(w,h,n)`：铁栅、百叶、格栅。
- `handwheel(r,spokes)`：阀门/摇机手轮（红或黄铜）。
- `flange() / elbow() / tee() / union()`：管件套件，保证三档管径对接一致。
- `insulator(ribs)`：瓷瓶脊环。
- `knob() / dial(sprite)`：旋钮与表盘总成。

若其中某个（如 `arch_frame`、`grille`、`louvre`）A3/A7 也用得上，我会**单独一个提交**把它提给 A0，建议并进 `artkit/models.py` 公共层（按方案第 11 节，公共工具只有 A0 改）。

### 4.2 贴图怎么按材质规则生成、怎么和 A1 保持同一套

- 每个模型导出时自动生成**一张图集**（`models.py` 的 `export`：按面尺寸排格子，用 `Mat.paint` 画，边缘外扩 1 像素防漏色）。贴图不手画、可重复生成（方案第 6.1 节）。
- 材质用 `pixelart.Mat(ramp, kind, noise, bevel)`：铸铁=metal、木=wood、石=stone/plain、发光罩=glow、布=cloth。手画面用 `Sprite`（表盘、字符、星图、台徽），范例见 `plan/figs/draft.py` 的 `tex_gauge/tex_switches/tex_door` 等（草样，不是定稿）。
- **和 A1 同一套颜色和画法**，靠统一色板模块：
  - **请 A0/A1 发布一个共享色板模块**（建议 `build/artkit/palette.py` 或扩 `pixelart.py`），导出第 1.1 节 11 族色阶 + 一个 `mat(name)` 工厂（给定名字返回约定好 kind/noise/bevel 的 `Mat`）。A1 画方块、A6 画模型都 import 它——这是「同一套颜色和画法」的唯一真源（方案第 11、13 节把色板列为 A0 维护的对接物）。
  - 现状：`pixelart.py` 已有的 `IRON/BRASS/BRASS_DARK/VERDIGRIS/DARK_WOOD/WOOD/LAMP_GLOW` 的色阶与色板**一致**，可直接用；但 `STONE`（偏灰，应为暖灰白石）、`COPPER`（偏红，应为斑驳旧铜）与色板**不一致**，且缺 **荧光绿/信号红/搪瓷蓝/瓷白** 四族。这几项建议并进共享色板，由 A1 统一定稿。**在 A0/A1 发布前，我先在 `kit.py` 里按第 1.1 节色阶临时定义同名材质占位，发布后改为 import，不改色值**，保证切换零改动。
  - 母题参数对齐：铆钉间距、石缝、斜角受光方向（artkit 的 `LIGHT` 向量）都已固定共享；我按和 A1 相同的铆钉间距画铁件，使模型铁板与方块铁板墙接缝连续。

### 4.3 放大的大模型怎么保证 16 像素一格

见第 1.6 节：`px = scale`，密度恒 16 像素/格；按「最小整数 scale 使最大尺寸 ≤ 3×scale 格」选 scale；一个模型只用一个 px；超 6 格的长件拆段或用 `between` 拉伸。会在 `obs_a6` 陈列架上逐件把模型面放到和旁边方块墙并排出图，核对像素大小一致（方案第 7.1 节红线、第 6.4 节验收口径）。

### 4.4 陈列架与摆放函数（交付物）

- **陈列架**：`build/scenes/obs_a6/props.py` 提供 `build_models/GALLERY/SCALE`，用现成 `build/gallery.py` 排成一排单看（每格 8 格宽、素背景），`makepack.py obs_a6` 出资源包，离线 `render.py` 或真机 `shoot.py` 出图。按族分架出图，交 A0/管理员审。
- **摆放函数**（交付物「摆放用的函数」）：在 `build/scenes/obs/props/__init__.py` 提供
  - `place(canvas, name, x, y, z, **opts)`：按锚点摆一件；
  - `stretch(canvas, name, a, b, …)`：沿两点拉伸（管、灯串、檐沟）；
  - 族级便捷函数：`facade_lights(...)`、`downpipe(top,bottom)`、`festoon(a,b)`、`pipe_line(points)` 等，**连带返回建议的 light 方块坐标与亮度级**交 A2，并返回占用的实体数便于 A0 记预算。

### 4.5 验证到什么程度（对应方案第 10 节）
