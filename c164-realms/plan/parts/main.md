## 3. 立面语法引擎（卡 main/facade-engine）

一套规则换参数出不同的楼；site 的发电房、缆车站复用。材料无关（只认角色名），进深/开间/形状由引擎算。

### 3.1 参数表

**Order（竖向做法，整栋通用）**

| 参数 | 含义 | 主楼取值 | 给附属建筑的口子 |
|---|---|---|---|
| `bay` | 开间总宽 | 4 | 发电房 5–6 |
| `pier` | 壁柱宽 | 1 | 窗宽 = bay−pier |
| `storeys` | 楼层段表 | [BASE, MAIN] | 发电房单层高拱窗；车站可 [] |
| `courses` | 线脚带表 | 勒脚/腰线/柱础/柱头/饰带/檐口/女儿墙 | 车站可只檐口 |
| `planes` | 进深偏移 | pier +1, wall 0, glass −1, cornice +2 | 可整体缩放 |
| `mats` | 角色→Family（取自 blocks.py） | ASHLAR_* / IRON_* / … | 换角色即换材质 |
| `rod` | 壁柱顶避雷针 | 是（隔跨一根） | |

**Storey**：`y0,height,wall(角色),window(窗型),panel(凹板角色)`。主楼 BASE=(2,4,ASHLAR_ROUGH,small,—)，MAIN=(7,8,ASHLAR_FINE,arched,ASHLAR_PANEL)。
**Window**：`small`=3×2 平头带铁栅（DARK/BLIND 窗）；`arched`=3×6 拱头（拱肩倒楼梯+玻璃通到顶），玻璃用 LIT/CURTAIN/FROSTED，留两成暗窗（DARK）**打断节奏、不棋盘**（c190-1）。
**Course**：`at_y,kind,project,mat,recipe`，recipe 指向 §4 拼法。

### 3.2 接口

```
# build/scenes/obs/main/order.py
class Order: ...                       # 纯数据
def wall(c, order, *, base, axis, lo, hi, facing, nominal,
         segments=(), openings=(), lit=None): ...
    # 沿 axis('z'/'x') 从 lo 到 hi 画一道立面；facing 决定进深朝向与泄水台阶朝向；
    # nominal: 名义墙面坐标；segments: [(lo,hi,project)] 给五段式不同前凸；
    # openings: [(a0,a1,y0,y1,'door'|'pass')] 挖洞收边；lit(bayidx)->0..1 交 A2。
def arc_wall(c, order, *, cx, cz, r, base, a0, a1, facing='out', ...): ...
    # 沿圆弧画立面（圆厅落地圆柱、西 apse 用它）。
def corner(c, order, *, at, base, top): ...     # 转角壁柱/转角石
def opening(c, *, box, kind): ...               # 门洞/过道/楼梯口
def parapet(c, order, *, line/ring): ...        # 饰带+檐口+女儿墙+压顶收口
```


### 3.3 三层进深怎么生成（验收：进深到位 / 无 >5×5 平墙）

名义墙面 `nominal`；`facing` 定“向外”。三平面每层差 1 格（东立面 nominal=15）：

```
俯视（↑向外/朝到达，→沿立面 z）：
 x=16  ██          ██          ██      壁柱面 +1（最前）
 x=15  ██ ──────── ██ ──────── ██      墙面 0 / 窗洞侧壁
 x=14  ▓▓ ▒▒▒▒▒▒▒▒ ▓▓ ▒▒▒▒▒▒▒▒ ▓▓      玻璃 −1（退 2 格）; ▓=壁柱列实心(室内平墙)
       壁柱  —窗3宽—  壁柱  —窗3宽—  壁柱
```
- 引擎按 `planes` 把每个 course/窗落到对应平面，进深是**生成**的；换 `planes` 即整体加深。
- **室内平墙**（R1-8 / c191）：壁柱列在 x=14（东）和 x=1（西）做实心，和玻璃面齐平，给室内一面平墙。室内净空 x=2..13。
- **无 >5×5 平墙**：横向每 4 格一壁柱；竖向被勒脚/腰线/柱础(7)/柱头(13)/饰带(14)/檐口(15)切成窄带；进深三层错开。最大连续平面是窗下凹板约 3×2、壁柱身 1×5。M2 出正交立面图量给 A0。
- **檐口纪念性**（c190-4）：进深只差 1、檐口挑 2，冷光下阴影线可能偏弱。M2 就在定稿冷光下出图量阴影；不够则檐下再加一道暗饰带（ASHLAR_PANEL 挖 1 格暗缝）或檐口再挑半格。此为 M2 待定项。
