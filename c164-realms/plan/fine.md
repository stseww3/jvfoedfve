# 细的标准和设定（第二轮从 12:45 起照这一页）

管理员 12:40 原话：**「当前方案下再加10倍细节和各种内容 内容不要太多但一定要细和贴合地图」**

意思三条：花样不要再多；每一样往细里做十倍；每一样都要属于这座天文台。本页管「怎么算细」和「怎么算贴」，
卡还在 `plan/round2.md`。两页有出入的以本页为准。

## 1. 范围冻结

- **不再开新花样。** `round2.md` 丙四以后不加卡。谁想到新的东西，先问一句「它是不是这座天文台今晚用得着的」，是就并进自己已有的东西里做细，不另立一样。
- **砍掉的（和天文台不贴，或者摊薄人手）：** 烟花；布谷鸟钟；玻璃暖房；机车库里第二台机车；猫换地方（猫留一只，坐着）；塔里能坐的升降机；电报打字机；臂板信号塔和远山对闪的灯（车站的臂板信号机留着）；穿山的检修暗道；前庭喷泉。已经动手的把做好的零件并进自己别的东西里。
- **改名的：** 煤气柜改成**水压蓄能器**（牌子上写着灯是发电机点的，站上用不着煤气）：一样的铸铁导架，里面一只配重筒随水泵和货梯慢升慢降，管子通到货梯和吊杆。m5 照做。
- **做法改成「做细一样再开下一样」。** 一样东西三层都到了（见第 2 节）才算交，才接下一样。半成品铺满全图不如几样东西经得起贴着看。

## 2. 什么叫细：三层

| 层 | 从哪儿看 | 看得见什么 | 现在 |
|---|---|---|---|
| 远 | 60 格以外（看板的大景） | 轮廓、明暗、一横一圆一竖 | 有了 |
| 中 | 10 格（走在平台上、站在屋里） | **零件**：接缝、法兰、成排的铆钉和螺栓、托架、线脚、嵌板、管卡、瓷瓶、检修门、把手 | 主立面有，别处稀 |
| 近 | 2 格（贴着看） | **痕迹和字**：铭牌和编号、表盘刻度、螺丝头、棱角磨亮、火上面的烟黑、轴承下面的油渍、铁件下面石头上的锈水、窗台下的水痕、粉笔记号、铅笔字 | 几乎没有 |

「十倍」量的是中层和近层：**任取一块 4×4 格的面，10 格处数得出的零件不少于 10 件，2 格处每一件上至少有一处痕迹或字。**
现在多数地方是 1 到 2 件、0 处。

三条跟着来的规矩：

1. **不留白。** 室外的墙、地、屋顶、崖面上，没有大于 3×3 格的一块什么都没有的面；室内没有大于 2×2 格的。实在该空的地方（V1 看主楼的那条线、中轴、天）除外。
2. **细不等于乱。** 加的东西顺着结构走：管沿墙脚和檐下走，线沿管走，牌子钉在它说的那个东西上。同一种零件全站一个样（见第 4 节）。远看的轮廓和明暗不许因为加细变花：评审照旧看大景，谁的细节把大景搅乱了退回去。
3. **会动的排在细的前面做，但交的时候一起交。** 一台机器动了而贴着看是光板，不算交。

## 3. 每一类照着补的单子（不是照着数，是照着查自己漏了什么）

- **室外的墙**（每个开间）：勒脚、腰线、壁柱或隅石、窗套带窗台和拱心石、檐口带托架；落水管带水斗和管卡；铁拉杆的锚板；通风铁栅；灯的托架和通到灯的线管；瓷瓶上的架空线；搪瓷编号牌；窗台下、铁件下的水痕和锈痕；墙脚的排水沟盖。
- **室外的地**：铺地有图案、有收边；每 8 格上下一处雨水口或铁栅；嵌在地里的轨；带台徽的井盖；路缘石、系缆桩一样的铁桩；人常走的地方磨浅一号；煤台旁的煤屑、机器旁的油点、墙角背风处的积雪。
- **屋顶**：脊饰、铅皮泛水的线、天窗、转着的通风帽、烟囱带陶帽和拉索、避雷针和沿墙下来的引下线、带栏杆的检修走道、挡雪栏、檐沟。
- **机器**：从哪儿来的动力看得见（管、线、轴、皮带进来），干了什么看得见（东西出去）；底座和地脚螺栓；接油盘；油杯；一块表；铭牌带编号；手轮或把手，握的地方磨亮；护栏；旁边墙上一块工具板、一只油壶、一团棉纱；上次检修的粉笔记号。
- **管线**：每 3 格一个法兰，每 4 格一个支架或吊卡；过门过路的地方有膨胀弯；阀门带手轮；保温层带箍；**色环分介质**（蒸汽红、水蓝、压缩空气和气动信筒绿、电线管黑）；箭头和编号；接头处偶尔滴水或冒一丝汽；每一根有头有尾，不许断头。
- **电**：瓷瓶、线管、接线盒、闸刀、保险丝板、电缆桥架；每盏灯看得见它的线从哪儿来。
- **屋里**：踢脚、墙裙、挂镜线、顶角线、梁；门上有把手、编号牌、踢板；灯的开关；架子是满的（书脊带编号、仪器盒、卷着的图）；桌上是今晚的活（翻开的记录本写着今晚的日期和编号、铅笔、计算尺、半杯茶）；衣帽架上有大衣和帽子；墙上的钟走全站的那个时刻；日历是今晚；值班表（只有数字）；传话筒和电铃按钮；字纸篓；门口磨旧的地毯；暖气片接着蒸汽干管。
- **线路和车站**：枕木、轨座和鱼尾板、道砟、齿条；里程桩和坡度标；道岔扳杆；信号的拉线和导轮；水鹤、煤台；站名牌、时刻表（数字）、行李、售票窗、长椅、站钟、铃、消防桶。

## 4. 贴合地图：设定（一处定死，各处照抄）

底子在 `ART-PLAN.md` 第 2 节（年代 1880 到 1935，三条造型原则，该有和不该有的单子，台徽），照旧有效。下面是把它定死到能照抄的数：

| 项 | 定的 | 用在哪儿 |
|---|---|---|
| 这一晚 | 彗星今晚最亮，全台的机器都开着，人刚走开一分钟。**所有东西说的都是这一晚这一颗彗星。** | 一切 |
| 时刻 | 全站的钟一个时刻、一个节拍：`machines/clocks` 的常数（从 7:55 起走）。谁的东西上有钟面，照它。 | 每一只钟、怀表、记录纸上的时标 |
| 日期 | `14 NOV`。不写年份。 | 日历、记录本、电报、底片盒、黑板抬头 |
| 今晚的编号 | 观测夜 `No. 2187`（底片库的牌子说一个晴夜一张底片：今晚这张是第 2187 张）。 | 记录本今晚这一页、底片盒、黑板、电报稿、差分机的打印纸 |
| 彗星怎么叫 | 只叫 `THE COMET`，不起名字、不编真实样式的编号。 | 一切纸品 |
| 台名 | 还没定。**除了标题和署名牌，哪儿都不写台名，用台徽**（圆环，中间一条竖线，右上一颗星）。 | 铭牌、井盖、门楣、图纸抬头、书脊、车厢、机车 |
| 车站 | `SUMMIT STATION`。线路没有公司名，车上只有台徽和编号。 | 站名牌、车票、行李签 |
| 机器的铭牌 | 一个样：椭圆黄铜牌，台徽在左，`No.` 加两位数。全站机器的号一张表，a6 管（`plan/parts/numbers.md`），要号找他。 | 每台机器一块 |
| 房间的门牌 | 搪瓷牌，深蓝底白字，一个数字加房间名；号照说明牌的次序。 | 每扇门 |
| 管子 | 色环见第 3 节；编号 `S`（汽）`W`（水）`A`（气）加数字，m3 管表。 | 每一根干管 |
| 字 | 全站一套字：说明牌用的那一套像素字。a6 把取字的函数发公告，别自己另画字母。 | 一切有字的贴图 |
| 文字的量 | 数字、符号、少量英文；一处不超过四个词。纸上的小字用线条代替，只有抬头和数字是真的。 | 一切 |
| 不出现的 | 人；真实的品牌、机构名、人名、年份；`ART-PLAN.md` 第 2 节「不该有的」那一串。 | 一切 |

**牌子上的话和东西的样子要对得上。** 现在对不上的一处：报时球的牌子写「一天落一次」，而它每个钟点（地图里 5 分钟）落一次：a6 把牌子改成 `It drops on the hour, to the second.`。各人查自己的东西和自己那块牌子。

## 6. 怎么干、怎么验

1. **每个人先管自己已有的东西。** 把自己的那一块（一栋房的外墙、一间屋、一台机器、一段地面）照第 3 节的单子过一遍，一次补十样，一个小包，随到随合。卡里放前后两张自查图：10 格处一张，2 格处一张。
2. **室外的主人先做室外的中层**（主楼两翼和背面、发电房、车站、下平台的地、崖面、栈桥、屋顶）：管理员看的是大景，大景里的细靠中层。
3. **评审换一种看法。** 不再给十二张图抠零点几分，改看细：每版每张图报「空白的格子占多少」（review 写工具：把图分成小格，量每格里的边缘多少，天除外，标出最空的格子，出一张叠了标记的图和一个数），另挑六处贴着看的近景打「到没到近层」。空白占比每版要降。
4. **每版给管理员的**：12 张大景、两三段小片、六张近景（那一版做得最细的六处）。
5. s1 的近景怎么拍：屋主在卡里给机位（站哪儿、看哪儿，离东西 2 到 3 格），s1 进存档照着拍。
